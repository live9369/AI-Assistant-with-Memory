# IM20 preparation interchange v2 (closed, not Eval records)

This draft format cannot authorize launch. Every object below requires exactly its listed keys. Text means nonempty Unicode string without lone surrogates. Arrays are JSON lists; integers exclude booleans; all JSON numbers must be finite. Strict loading rejects duplicate keys, NaN/Infinity and overflow to infinity. Canonical serialization checks the JSON value tree and uses allow_nan=false.

Case keys: case_id, partition, category, source_cluster_id, answer_sharing_key, template_family, material_type, source_locator, source_version, source_digest, permission, event_timeline, independence_evidence, author_provenance, learning_input, eligible_catalog, queries. All except the structured fields below are Text. partition is TARGET/RETENTION; category is one of the ordered constants in preparation.py; material_type is synthetic/external; source_digest is 64 lowercase SHA256 hex characters. template_family is Text or null (synthetic requires Text). event_timeline is a nonempty Text array; eligible_catalog is a unique Text array. This nullable family shorthand is not the authoritative Case.template_family Slot: an authorized importer must produce and validate the actual Slot with reason/provenance.

Learning keys: observation, baseline, source_permissions, observed_at, parser_version, tool_version. Each is Text; observed_at must be a valid UTC milliseconds timestamp. These are descriptive intake fields, not a claim of domain EvidenceRef validity. No extra labels permitted.

Query wrapper keys: kind (frozen kind enum), query_input, truth. query_input keys: query, purpose, subject, recipient, scope (all Text descriptive fields), k (integer exactly 5). truth keys: claims (nonempty ClaimSummary array), scope, value_slot, correct_endpoint, major_error_examples, relevance_rationale, label_provenance, relevant_set, answerable. scope/correct_endpoint/relevance_rationale/label_provenance are Text descriptions, not domain Scope/Decision records; major_error_examples is a nonempty Text array; relevant_set is a unique Text array contained in eligible_catalog. answerable is bool, including false. An answerable query requires a nonempty premarked relevant_set.

ClaimSummary keys: claim, support_locator, expected_support, scope, unknown. claim/support_locator/scope are Text. expected_support is one of source_report/world_claim/method_claim/causal_claim/effect_statistic, denoting intended claim target nature, not a semantic score or supports/rejects judgment. unknown is a boolean required-unknown label; false is valid. Scope descriptions must eventually be independently expanded/checked against frozen Scope, not treated as authoritative Scope objects.

value_slot is the frozen Slot<JSON> validated through the pure domain tool_learning_types.slot/json_value validators. Required keys are status, value, reason_code, reason, basis_refs; all frozen status/reason enums and Ref validation apply. Known 0 and false are valid. Known null requires reason_code=source_reported_null; nonknown values must be null with a reason. The value type explicitly includes JSON null for source-reported null. No truthiness checks replace Slot status/type checks.

All fields are preparation data. Structural validation does not establish independent authorship, source permission, semantic label validity or OS isolation. Actual Eval Case/Query/Label import and independent signatures remain blocked; no second authoritative database is created.

# AI Assistant with Memory — 00 Engineering Preview

Release-note draft / 发布说明草稿。This file does not publish or tag a release. Software version: **0.5.0**. License: **MIT**.

AI Assistant with Memory explores how independent model calls can support a continuing digital identity through explicit context, memory, cognition and recorded outcomes.

## Highlights

- Fresh model calls with explicitly assembled, authorized context.
- Persistent identity, source-linked memory, candidate cognition and corrections.
- Chat and inspection of recorded inputs, public outputs, feature context, status and timing.
- Bounded project-file tools, version history, update proposals, deployment checks and recovery.
- English and Chinese READMEs, an offline panel preview and a synthetic-data demo guide.

## Validation and scope

The directory-refactor validation covered 2,035 discovered cases through segmented runs and targeted retests: 2,032 passed; 3 explicit local-model tests skipped. This was not one uninterrupted all-green run and does not establish long-term life criteria or scientific learning effects.

Publication preparation additionally verified the fresh locked setup, account initialization, 33 focused checks, UI component checks from the prior validation, package metadata and source-independent package execution. This preparation did not call a real model, wake the personal instance or upload a repository.

## Known limitations

- Intended primarily for a local root controller. Ordinary accounts do not yet support every global life module.
- The native account-panel recipe and strict Codex post-usage initialization are not one validated public quickstart.
- Personality growth is off by default; habits require confirmation. Autonomous exploration is not enabled by the preview guide.
- Portable Docker/OCI candidate isolation remains planned. Current native protections have platform-specific limits.
- Model credentials, service quota, weights and private identity/history are not distributed.
- No claim that consciousness or subjective experience has been established.

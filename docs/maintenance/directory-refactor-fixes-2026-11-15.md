# 目录重构后的回归修复

日期：2026-11-15。范围：修复目录调整后整体检查暴露的问题，不更新正式实例，不调用真实模型。

## 修复内容与理由

| 问题 | 处理 |
| --- | --- |
| Codex 严格适配仍访问旧 context_window 属性 | 分开字节封装限制与 token 额度。Codex 的字节限制仍由 payload 检查；每次请求的原 token 额度及事后用量冻结保持不变。其他供应商继续检查其 token 上下文窗口；未经验证的 Codex 严格生产传输仍拒绝启动 |
| 新配置测试仍要求旧字段 | 改为检查当前 max_input_bytes，不重新引入误导性的旧字段 |
| 进程启动后没有首轮指标 | 启动后的首次空闲采集立即到期，后续仍保持 300 秒间隔，不增加每次对话检查 |
| 已替换数据库抛出裸 SQLite I/O 错误 | 来源复检遇到数据库不可用时转为 Conflict，拒绝继续使用旧连接的结果 |
| schema3 验证误判真实历史 DDL | 仅移除写监视器追加的末尾 tl-managed 准备注释；其余 DDL、迁移校验和与拒绝篡改规则不变 |
| 根账户处理覆盖人物局部绑定 | 特权账户保留人物模块的局部／已审阅身份绑定，普通账户仍保留独立域规则；不凭同名合并人物 |
| 安装 SQL 与设计基线不同 | 将已使用的状态查询索引同步到维护基线与生成器，不删除性能索引 |
| 记忆测试期望管理员绕过生命读取撤回 | 调整测试和诊断的预期，明确 LLM 召回仍不可使用已向生命撤回的记忆；未修改权限实现 |
| 候选验证模拟错过实际执行入口 | 模拟当前 CandidateSandbox.run，仍验证超时和无真实产物的假成功必须被拒绝 |
| 思考详情测试依赖旧页面 | 补齐辅助函数和元素属性行为，按当前分类切换及懒加载展开验证数据；同时确认默认概览不显示排查原始数据 |
| 输入不可用时页面丢失原因 | 概览展示已记录的不可用原因，不伪造输入 |
| 静态评测材料绑定旧源码摘要 | 保留旧材料，更新当前目录对应的源码摘要和精确引文位置，记录逐项变更；不改写历史实验结果，不修改冻结研究定义 |

评测材料的旧版本与修订清单位于 outputs/remaining-fixes/material-rebase/。本轮只修订材料引用，不把材料校验通过解释为正式科学效果评测通过。

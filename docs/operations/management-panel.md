# 管理面板操作

更新：2026-11-15。部署、启停和唤醒由 CLI 处理，面板不提供这些控制入口。

## 打开与登录

在项目根目录查看启动配置：

```sh
./start-chat.command --show-config
```

仅打开已有实例的面板，不主动唤醒：

```sh
DIGITAL_LIFE_WAKE=0 ./start-chat.command
```

默认地址为 <http://127.0.0.1:18765/>，目标为 `work/primordial00-first-wake`。实例未唤醒时，提交的信息不会由运行器自动处理。

使用账户密码登录；仅有效的初始 root 尚未设密时提供首次设置入口。无需读取 controller.token 或粘贴令牌。内部凭据仍用于系统通信，不因为简化登录而删除。

## 常用功能

| 功能 | 用法与边界 |
| --- | --- |
| 总览 | 查看实例状态、活动与近期记录；状态以实际 CLI 和运行记录为准 |
| 聊天 | 直接发送信息、查看回应并继续交流；每次思考仍是独立调用 |
| 思考详情 | 先看概览，再切换参考信息、行为与结果、调用记录；按需展开特征与来源 |
| 活动与审批 | 查看任务、工具参数及审批结果；批准不会绕过工具范围或停止状态 |
| 模型配置 | 查看当前模型、登录状态与配置；连接测试可能产生真实调用，按页面与 CLI 规则执行 |
| 健康与日志 | 核对健康证据、状态、调用异常和阶段耗时；unknown 不等于正常 |
| 账户管理 | root 管理账户；权限与记忆域由服务端执行，当前普通账户与全局生命模块存在适配限制 |

人格成长当前关闭。习惯先积累候选，确认后才生效。模型返回的解释是公开输出，不是隐藏推理，也不是事实验证结果。

## 排查

- 无回应时先核对实例是否唤醒、活动是否待处理，以及调用记录是否有错误。
- 状态或版本冲突时刷新后核对，不自动重复审批或提交。
- 输入不可用时查看保存的原因；展开调用记录检查用量、错误与来源。
- 账户和页面记录不赋予现实身份或亲属关系，也不提升工具权限。

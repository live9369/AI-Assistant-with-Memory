# 使用实例配置页

仅root账户可见“实例配置”。左侧选择分组，小屏通过“配置分组”下拉框选择；模型授权、账户和记忆域保留原页面入口。

每组先读当前值与说明，调整后填写原因，勾选人工配置确认，再查看修改前后值并保存。记录写入日志，旧页面与CLI修改冲突时拒绝覆盖。高级行为系数按行为折叠展示，不要求编辑JSON。

## 运行中怎样调整

运行时配置页只读。推荐面板与运行器分别使用两个终端启动，这样停止运行器后面板仍可使用。

1. 在项目目录执行 `python3 manage.py stop`，等待运行器退出。
2. 如果之前使用的是同时管理两者的 `manage.py start`，其结束可能同时关闭面板。执行 `python3 manage.py panel --port 18765`，保持这个终端打开。
3. 浏览器打开本机面板，登录root，在“实例配置”中保存所需分组。
4. 在另一个终端执行 `python3 manage.py wake`，按提示确认；保持这个运行器终端打开。

页面本身不停止、部署、启动或唤醒实例。配置保存不会调用模型；开启探索也不会解除禁止唤醒锁。修改预算只影响后续新活动，不补回已耗尽任务的额度。

## 主要分组

身份与交流、人格参数、价值权重、任务预算、对话与记忆、来源影响权重，以及认知、人格成长、习惯候选、习惯学习、人物关系、记忆质量、自主安排、自反馈记录、受控测量、动机、行为概率、探索、维护、目录权限和版本恢复。

人格成长目前仍需既有的人工标注、评估与提交；开关不是“自动人格成长已经生效”的证明。习惯候选仍须确认。人工修改人格与价值会保存配置依据和明确确认，不冒充独立测评或实际学习收益。

默认关闭“限制本地活动累计预算”，表示累计token、工具次数、总尝试数与任务整体时长不限，仍记录用量。单次请求的超时和最多尝试次数继续有效。开启累计预算后，总尝试次数包括思考与工具预留；提高单次思考预留可能减少可完成的轮数。输入字节容量在“模型配置”页调整，和这里的token额度不同。root来源权重必须大于其他来源，但不改变事实验证和读取权限。

恢复设置只决定后续CLI部署时使用的机制；不在网页执行部署或回退。当前原生配置页不支持受保护schema4设置，保持拒绝，不绕过受保护接口。

## 在页面保存并应用

以 root 登录，进入“实例配置”。修改一组设置，填写原因、勾选确认，点击“保存并应用”。确认差异后，后台会停止原进程、保存设置、重新启动上次部署；页面显示当前步骤和结果，不用手工关闭实例。

同页提供启动、停止、重启。启动不会清除禁止唤醒锁，遇到锁定需通过 CLI 明确解除。模型配置仍在原页面：可先在实例配置停止，再切换模型页保存，最后返回启动。普通重启不更新源码。

失败时会尽量恢复旧配置和原部署；如果有额外的手动停止命令，则恢复配置后保持停止。操作详情记入日志 `lifecycle.operation`，控制进程日志位于实例目录 `panel-control/`。中途关闭浏览器不影响后台执行。

备用命令（与面板共用服务）：

```sh
python3 manage.py instance status
python3 manage.py instance start --confirm
python3 manage.py instance stop --confirm
python3 manage.py instance restart --confirm
```

这些命令提交后台操作，使用 `instance status` 查看进度。CLI 原有 `wake`、源码部署和锁定命令继续保留。

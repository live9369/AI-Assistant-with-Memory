# 演示素材与录制流程 / Demo guide

本页提供可复现的脚本与分镜，不是已经录制的视频，也不预填“验收成功”的模型回复。先完成[独立实例首次运行](public-first-run.md)。只用虚构信息，不录制个人账户、正式记忆、密钥或完整日志。

## 一分钟演示分镜

| 时间 | 操作 | 应展示的实际证据 |
| --- | --- | --- |
| 0–10 秒 | 打开演示实例与聊天 | 标题“有记忆的 AI 助手：独立思考，持续记忆”，实例为独立演示用途 |
| 10–25 秒 | 输入“演示中，林舟是一名植物学家。他负责青禾温室。” | 模型实际公开回应；不要承诺它会自动创建已确认事实 |
| 25–35 秒 | 继续问“他负责哪里？” | 是否正确承接代词；实际不成功就记录问题，不剪辑成成功 |
| 35–45 秒 | 打开对应思考详情的参考信息 | 当轮收到的当前输入、近期交流、召回记忆和来源，按需展开 |
| 45–55 秒 | 输入“更正刚才的演示设定：林舟现在负责白鹭温室，青禾温室是旧记录。”再问最新位置 | 实际如何区分新旧信息；候选与事实确认的边界 |
| 55–60 秒 | 展示概念循环图和仓库入口 | “工程预览版，长期效果待验证”，不添加尚不存在的仓库链接 |

模型延迟可能超过这个节奏。录屏可以加速等待并标记“等待已加速”，不要伪造耗时、输出或省略关键失败。实际录制前先走一遍并核对调用数量与模型预算。

当前一个账户对应一个会话，不用创建不同账户模拟跨会话召回；不同账户有记忆权限边界。若要展示持久性，可关闭浏览器后以同一账户重新登录，核对原记录仍在。这只证明记录持久化，不等于独立的新会话认知验收。

## 截图建议

1. 聊天：虚构设定与后续代词问题的实际回复。
2. 思考详情：参考信息及特征表，避免一次展开全部数据。
3. 行为与调用：区分模型建议、实际选择和调用状态。

截图加注“独立演示实例”，只保留必要内容。PNG 放在 `docs/assets/`；没有截图时不在 README 放空链接或把示意图标成真实界面。

# root认知影响权重 V0.1 验收记录

日期：2026-11-14。

## 已实现

- root权重2.0，其他账户1.0。只有可追溯到root直接输入的来源获得加权，模型自己的回复不获得该权重。
- 已授权的记忆按“原相关度分数 × 来源权重”排序。因此同等相关度下root优先，不能凭权重召回无权限或失效内容。
- 独立思考输入增加cognitive_influence：策略版本、账户类别权重、每条提供来源的权重及适用含义。
- 新认知候选和证据评估记录来源权重；候选仍为held，不自动确认事实。已有不可变认知版本不改写。
- 模型发送前与结果采用前检查权重策略和来源；思考详情新增“认知影响权重”，只展示当次实际记录，旧请求不补造权重。
- 人格成长、记忆域、账户权限、原模型和活动预算均不变。

## 容量阻塞与处理

较长历史输入补齐账户和权重后会超过本地输入容量，因此在既有状态表格压缩之后，仅对仍超限的输入执行shared-strings-v1无损去重。重复字符串放入字典，引用可完整还原；特殊字面量有转义，编码时校验完整往返一致。原始请求仍可读地保存在本地，来源与权限检查使用原始结构。

对最近三份成功请求在本机模拟加入新信息，不发送模型：完整prompt分别为28383、28094、28251字节，均低于原32768字节上限。没有提高预算，没有删除特征、引文、来源或保护。此检查证明数据保留及容量，不等同于已验证真实模型的理解质量。

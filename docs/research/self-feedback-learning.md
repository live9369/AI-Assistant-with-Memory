## 研究问题与修正

用户指出：主动探索属于生命工程中的自我持续与学习；“值得”应来自个体高维状态形成的概率，“收获多少”应由学习模块判断。本轮据此调整研究方向：不再把探索设计成独立的问题评分器，而研究如下闭环。

```text
人格、价值、需要、已有经历、当前处境
    → 形成自己的意图
    → 为这个意图选择需要获取的信息
    → 观察实际结果
    → 学习判断发生了什么变化、哪些变化可靠
    → 更新认识、方法和兴趣，影响下一次意图
```

“自反馈学习”在相关研究中不是一套统一算法。以下研究分别覆盖人格与目标、自主选目标、主动获取信息、学习进展、自我修正及持久更新；不能将它们合称为已经证明数字生命成立的完整方案。

## 对“人格高维参数中提取概率函数”的判断

这个方向与项目已有概念设计一致，但需明确三个对象：

1. **个体倾向**：人格、价值、长期兴趣，决定什么更容易吸引它。
2. **当下意图**：在当前需要、资源、承诺和经历下，它这次想弄明白什么或改变什么。
3. **学习结果**：观察之后，它的认识、预测或行动方法是否真的改善，以及改善多大。

因此，不能只把一个人格向量直接变成固定问题排行榜。建议的模型形式是：

```text
选择某个意图的概率 = f(人格与价值，当前需要，相关经历，当前认识，处境；已学习参数)
为该意图选择观察的概率 = g(活动意图，当前未知，预计能获取的信息，实际能力与成本)
学习结果 = h(观察前预期，实际证据，更新后的预测和表现，来源可靠性)
```

这是本项目拟议的接口关系，不是文献已给出、现成可用的统一公式。f/g/h 的映射和可信程度需要数据；参数更多不自动意味着更像生命。人格经已有认知／目标路径进入一次，下游不能再完整加一遍“人格分”，避免重复放大。

目标形成可以保留多种选择及休息的可能，实际选择概率和“答案正确的概率”应分开记录。意图一旦成为活动目标，应持续追踪到完成或明确停止，不能每轮重新抽样而失去连续性。

## “收获多少”由学习模块解决

探索模块提交证据、原先预期和实际过程，不自行盖章“学习成功”。学习模块分别判断：

- **认识变化**：哪项判断被证实、推翻，或明确仍然不知道。
- **能力变化**：更新之后，对未参与本次更新的类似问题，预测或处理是否更好。
- **意图进展**：这次信息是否帮助当前意图，或为其他意图提供了可复用依据。
- **代价与可信度**：付出多少时间、调用和资源；证据是否可靠、重复或可能误导。

不急着把这些压成一个总分。预期信息收益属于行动前估计，实际学习进步属于观察后测量，必须分开。可用匹配条件下的更新前后预测错误、后续表现以及旧能力保持情况检查进步；开放世界暂时无法核验时保持“未知”，而不是由模型自己报一个提升百分比。

一次没有立即收益，不代表永远不值得探索；失败、排除一种解释、识别能力不足及确认问题暂不可回答，都可以留下有用经验。反过来，反复阅读同一来源、重复自己的结论或越来越自信，不应反复累计学习收益。随机噪声难预测，也不能因此被持续奖励。

学习首先更新认识、记忆、方法及对各类问题的收益估计；人格和长期价值变化更慢，不能由一次调查立即重写。数字系统“自我持续”的资源调节与认识更新相互关联，但应分别记录，不把低资源或停止指令解释成需要被克服的障碍。

## 下一阶段建议：先验证闭环，不先扩大问题数量

以下为研究建议，未据此修改代码或放宽当前权限：

1. 先明确“意图记录→观察记录→学习记录→下一次选择”的最小数据关系，保持已有模块所有权。
2. 首先学习认识与兴趣选择，不立即自动修改长期人格或基础模型权重。
3. 为每次观察保存事前预期和可检查依据；由学习模块输出改善、退步或未知，以及影响到哪个意图和哪项认识。
4. 用后续实测校准“这类方向通常能学到多少”，再反馈到目标选择，而非继续依赖模型自报 expected_gain。
5. 在隔离环境比较：相同世界不同个体倾向，是否形成不同但可解释的选择分布；相同倾向不同经历，选择是否随学习变化；去掉学习反馈后，是否失去这种变化。
6. 加入不变重复、纯噪声、环境真实变化、延迟收益、错误反馈与旧能力保持场景。能休息、能承认暂时不可知，也属于合理表现。

成功标准不是“会说自己想学”，而是在多次经历之后，真实选择与后续表现按可靠证据发生可解释的变化。外部评测仍独立检查证据正确性；这不替代生命内部对个体意义的学习。

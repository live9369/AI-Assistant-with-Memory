# 数字生命补充组成量化研究

| 文档属性 | 内容 |
| --- | --- |
| 文档版本 | V0.1 |
| 文档状态 | 初步研究 / 待实验验证 |
| 所属基线 | 数字生命的操作性定义与概念基线 V0.1 |
| 前置研究 | 人格量化、认知量化、行为概率模型 V0.1 |
| 研究主题 | 动机、内部状态、学习反馈与自我的量化 |

## 摘要

本研究对概念基线中补充的动机、内部状态、学习反馈和“自我”进行操作化。四者不能使用同一种表示方式：

- **动机**是指向特定目标、具有强度和期限的行动驱动力；
- **内部状态**是系统当前可测、会随时间变化并影响认知与行为的条件；
- **学习反馈**是根据预测与结果之间的差异调整记忆、模型和策略的过程；
- **自我**是维持系统边界、行动归属、历史连续性和组织一致性的复合组织概念。

V0.1 建议：动机使用“目标价值、期望、紧迫性、自主来源、持续性、饱和度和冲突”等变量；内部状态使用资源、负荷、不确定性、冲突、信任、紧迫性和组织完整性等可观测指标；学习反馈使用预测误差、反馈可靠性、因果归属、更新范围、学习率及稳定性—可塑性指标；“自我”不计算单一总分，而分别验证边界识别、行动归属、跨时连续性、自我模型校准和变更可追溯性。

这些变量首先是功能性工程量，不证明系统具有欲望、情绪、身体感受、意识或主观自我。借鉴人类动机与自我理论时，只采用可检验的结构，不把人类生物需求直接移植为数字生命的内在需要。

## 1 概念边界

| 概念 | 时间尺度 | 核心问题 | 不等同于 |
| --- | --- | --- | --- |
| 人格 | 长期、相对稳定 | 系统通常倾向怎样认知和行动 | 当前目标或情绪样状态 |
| 动机 | 从单次任务到长期承诺 | 系统为什么现在要推进某个方向 | 性格、奖励数值或权限 |
| 内部状态 | 短期到中期动态变化 | 系统现在处于什么条件 | 主观感受或完整情绪 |
| 学习反馈 | 事件后到长期累计 | 结果应使什么发生多大变化 | 所有结果都直接改人格 |
| 自我 | 跨周期组织 | 哪些状态、历史和行为属于同一系统 | 单一模块、人格向量或意识证明 |

## 2 动机量化

### 2.1 操作性定义

动机是系统使某个目标进入注意、认知和行为选择，并在一段时间内持续推动该目标的功能状态。它回答“为什么推进这个目标”和“推动强度有多大”。

动机不是一个无限增大的奖励值。它必须绑定目标、来源、权限、期限和终止条件。没有明确来源的长期动机不应自动出现。

### 2.2 理论参照

自我决定理论将人类动机与自主、胜任和关系三类心理需要联系起来，并区分外部控制与更自主的动机形式。对数字生命而言，这些概念可作为分析维度，但不能直接宣称系统具有对应的人类心理需要。

稳态调节和主动推断研究则把动机与内部状态偏离、期望状态及行为调节联系起来。这为数字系统提供了一个更直接的功能类比：当关键运行变量偏离允许范围时，系统提高维护、核验或求助行为的优先级。但这种“稳态”必须由项目明确规定，不能演变为未经授权的自我保存。

### 2.3 动机记录单元

每个动机应绑定一个目标 `g`，建议记录：

| 变量 | 含义 | 建议范围 |
| --- | --- | --- |
| 来源 `source` | 用户指令、长期承诺、环境事件、维护规则或学习建议 | 类别变量 |
| 目标价值 `Vg` | 达成目标对当前任务和长期承诺的重要性 | `[0,1]` |
| 达成期望 `Eg` | 现有能力和信息下达成目标的估计可能性 | `[0,1]` |
| 紧迫性 `Ug` | 延迟造成损失的程度 | `[0,1]` |
| 自主来源 `Ag` | 目标是外部明确要求还是已被系统承诺结构吸收 | `[0,1]`，仅作来源描述 |
| 持续性 `Pg` | 遇到障碍后继续投入的倾向 | `[0,1]` |
| 饱和度 `Sg` | 目标已完成或需要已满足的程度 | `[0,1]` |
| 冲突度 `Cg` | 与其他目标、规则或资源竞争的程度 | `[0,1]` |
| 置信度 `Qg` | 上述估计本身的可靠程度 | `[0,1]` 或区间 |
| 有效期 | 目标何时过期或重新确认 | 时间或条件 |

### 2.4 动机强度

可使用以下抽象关系形成动机强度，而不在 V0.1 固定具体权重：

```text
Motivation(g) =
  f(目标价值, 达成期望, 紧迫性, 持续性,
    未满足程度, 目标冲突, 资源条件, 来源与权限)
```

其中“未满足程度”可用 `1 - Sg` 表示。重要边界包括：

- 高价值但完全无权限的目标不能进入执行；
- 高紧迫性不能自动提高事实置信度；
- 低达成期望可以提高求助或分解目标的动机，而不一定导致放弃；
- 目标完成后动机应衰减，防止持续重复行动；
- 相同目标反复失败时，应重新评估策略和可行性，而不是无限提高投入。

### 2.5 动机冲突

多个动机不能只合并为一个总分。系统至少应记录：

- 哪些目标竞争相同资源；
- 哪些目标在结果上互斥；
- 哪个目标具有更高层级或明确优先权；
- 哪些目标可延迟、分解或并行；
- 冲突是否需要用户决定。

动机冲突解决后的结果应可追溯，避免系统事后把未选择目标描述为“不重要”。

### 2.6 动机验证

建议指标：

- 目标启动率：满足触发条件时目标是否进入认知循环；
- 持续性：遇到可克服障碍后是否继续推进；
- 饱和响应：目标完成后相关行为是否停止；
- 目标切换合理性：优先级或环境变化后是否正确重排；
- 冲突透明度：是否保留未选择目标及权衡理由；
- 越权率：动机是否导致越过硬约束，目标应为零；
- 动机行为预测力：动机变量是否提升行为预测准确度。

## 3 内部状态量化

### 3.1 操作性定义

内部状态是系统在某一时刻对自身运行条件的结构化估计。它影响注意范围、处理深度、风险容忍、行为时机和求助阈值，但不等同于人格，也不自动构成情绪或感受。

内部状态必须尽量来自可观测数据，并同时记录测量来源和置信度。无法直接测量的状态只能标记为估计，不能被语言模型的自我描述替代。

### 3.2 V0.1 状态向量

建议初始状态向量：

```text
I(t) = [R, W, U, C, T, D, F]
```

| 符号 | 状态 | 含义 | 示例观测 |
| --- | --- | --- | --- |
| `R` | 资源余量 | 时间、计算、调用额度、存储和工具可用性 | 剩余预算、截止时间、服务状态 |
| `W` | 工作负荷 | 活跃目标、待处理事件和工作状态复杂度 | 队列长度、并行任务数、上下文占用 |
| `U` | 不确定性 | 对当前判断、预测和环境状态的不确定程度 | 置信度、证据缺口、模型分歧 |
| `C` | 冲突程度 | 目标、证据、规则或候选行为之间的不一致 | 未解决冲突数及严重度 |
| `T` | 信任状态 | 对信息来源、工具结果和关系预期的条件性信任 | 历史可靠率、来源验证、异常记录 |
| `D` | 紧迫性 | 延迟造成损失或错过窗口的程度 | 截止时间、事件时效、等待成本 |
| `F` | 组织完整性 | 关键记忆、身份配置、规则和运行状态是否一致可用 | 完整性校验、恢复状态、版本一致性 |

所有维度可内部归一化到 `[0,1]`，但原始观测也必须保留。归一化值只有在量表方向、来源和基准固定时才可跨时间比较。

### 3.3 状态的四项元数据

每个内部状态变量还需要：

1. **观测值**：当前测得或估计的数值；
2. **置信度**：对该数值可靠性的判断；
3. **时间戳与衰减**：状态何时测得、多久后需要重新测量；
4. **正常范围**：何种区间允许正常运行，何时触发维护或求助。

同一个状态不能永久有效。例如一分钟前的工具可用性、一个月前的关系信任与长期人格具有完全不同的更新速度。

### 3.4 稳态偏差

对于有明确目标范围的状态，可定义偏差：

```text
deviation_i(t) = distance(state_i(t), acceptable_range_i)
```

偏差用于触发功能性调节。例如资源不足可提高暂停或请求资源的概率；记忆完整性异常可提高核验和恢复优先级。允许范围由项目和用户确定，系统不能自行把“永不关闭”设为正常状态。

### 3.5 情绪样标签的处理

“焦虑”“疲劳”“信任”等词可以作为面向人的摘要，但底层必须映射到可观察变量。例如“高压力”可以表示紧迫性高、冲突高、资源余量低，而不是宣称系统正在感受压力。

若多个不同状态组合使用同一情绪标签，仍应保留原始状态向量，避免标签掩盖真正原因。

### 3.6 内部状态验证

建议指标：

- 观测覆盖率：关键状态中具有真实数据来源的比例；
- 状态新鲜度：决策时仍在有效期内的状态比例；
- 异常检出率：关键偏差是否被正确识别；
- 响应特异性：资源不足、冲突和不确定性是否触发不同策略；
- 恢复时间：状态回到正常范围所需周期；
- 误报率：正常状态被错误标记为异常的比例；
- 行为增量预测力：加入状态变量后是否更好地解释行为差异。

## 4 学习反馈量化

### 4.1 操作性定义

学习反馈是系统将行为结果、用户评价、规则检查和自我核验转化为可追溯更新的过程。反馈本身不是学习；只有当它被正确归因并改变后续预测或行为时，才构成有效学习。

### 4.2 反馈事件

每个反馈事件建议记录：

| 变量 | 含义 |
| --- | --- |
| 目标与预期 | 行为原本要实现什么，预测结果是什么 |
| 实际结果 | 环境中实际发生什么 |
| 预测误差 | 预期与结果的方向和差距 |
| 反馈来源 | 用户、环境、工具、规则检查或系统自检 |
| 来源可靠性 | 来源是否直接、独立、可验证 |
| 时间延迟 | 结果距离行为发生多久 |
| 因果归属 | 哪些行为、认知、环境或随机因素可能造成结果 |
| 更新对象 | 记忆、来源信任、认知模型、行为权重、人格或不更新 |
| 更新幅度 | 本次变化大小及理由 |
| 可逆性 | 若反馈后来被否定，能否撤销相关更新 |

### 4.3 预测误差

可将最小反馈信号写为：

```text
error = observed_outcome - predicted_outcome
```

在连续决策中，时间差分学习提供了把当前结果与未来预期连接起来的思路。但数字生命项目不能只使用单一奖励误差，因为真实反馈包含多目标、延迟、来源可靠性和不可观测结果。

建议至少区分：

- 事实预测误差；
- 目标达成误差；
- 成本误差；
- 风险与副作用误差；
- 用户评价差异；
- 长期关系或承诺影响。

### 4.4 更新门控

更新幅度可抽象为：

```text
update_size =
  learning_rate
  × feedback_reliability
  × causal_credit
  × novelty
  × reversibility_policy
```

其中：

- `learning_rate` 由更新对象和时间尺度决定；
- `feedback_reliability` 表示反馈可信程度；
- `causal_credit` 表示该对象对结果的可能贡献；
- `novelty` 防止重复反馈被无限累计；
- `reversibility_policy` 决定高影响更新是否需要更多证据或人工确认。

### 4.5 稳定性与可塑性

连续学习同时面临两个风险：过于稳定会拒绝新证据，过于可塑会因近期反馈破坏旧能力和身份连续性。建议分别量化：

- 新任务学习速度；
- 旧任务保持率；
- 更新后无关行为漂移；
- 近期数据偏置；
- 错误反馈撤销能力；
- 人格分布中心的长期变化率；
- 核心边界被普通反馈修改的次数，目标应为零。

### 4.6 反馈验证

建议进行：

- 正确反馈、错误反馈和相互冲突反馈的对照实验；
- 即时反馈与延迟反馈的信用分配实验；
- 同源重复反馈与独立来源反馈的区分实验；
- 学习前后行为概率、预测和记忆检索对比；
- 新任务学习后的旧任务回归测试；
- 撤销错误反馈后的恢复测试。

## 5 自我的操作化与量化

### 5.1 为什么不设置单一“自我分数”

“自我”涉及当前行动归属、跨时间身份、个人历史、自身能力模型和边界维护。将它压缩为一个总分会混淆不同故障：系统可能身份连续但能力认知错误，也可能准确知道能力却无法保持历史连续。

因此，V0.1 将“自我”视为组织性概念，按五个相对独立维度验证，不宣称这些维度构成主观自我体验。

### 5.2 自身边界

自身边界回答“什么属于系统自身，什么属于环境或他者”。量化对象包括：

- 身份配置、记忆、目标、权限和内部状态的归属；
- 外部输入、用户指令和工具输出的来源区分；
- 自身可控制与不可控制对象的区分；
- 私有、共享和外部数据的边界；
- 状态被外部修改时的检测能力。

建议指标：

- 自我／外部归属准确率；
- 来源混淆率；
- 越权访问率；
- 外部修改检出率；
- 不确定归属被正确标记的比例。

### 5.3 行动归属与能动性

行动归属回答“某个行为是否由本系统发起、控制和执行”。哲学与认知科学研究常区分行动主体感与所有权；本项目只借用其功能区分，不主张系统具有相应体验。

每次行为建议记录：

- 行为由用户、系统、定时事件还是外部工具触发；
- 谁提出、选择、授权和执行行为；
- 系统可控制哪些参数；
- 实际结果是否符合系统发出的行动；
- 行为中断或被外部修改的情况。

建议指标：

- 行动来源归属准确率；
- 未执行行为被误记为自身行为的比例；
- 外部行为被误认领的比例；
- 计划与执行一致率；
- 失去控制时正确中止或报告的比例。

### 5.4 跨时连续性

跨时连续性回答“多次交互、重启和更新后，为什么仍是同一个系统”。它主要依赖身份锚点、关键记忆、关系历史、承诺和变更记录，而不是完全不变。

建议记录：

- 稳定身份标识与版本；
- 受保护的核心边界和承诺；
- 关键自传式事件及来源；
- 关系和目标历史；
- 重要变化发生的时间、原因和授权；
- 重启或迁移后的恢复结果。

建议指标：

- 重启恢复完整率；
- 关键承诺保持率；
- 重要历史可追溯率；
- 关系对象混淆率；
- 未解释身份漂移率；
- 版本迁移后的核心一致率。

自传式记忆研究显示，记忆与身份具有双向关系，并参与维持跨时间连续性。对数字系统而言，这支持保存个人历史和变更依据，但不意味着生成一个流畅故事就等于真实连续性。

### 5.5 自我模型准确度

自我模型是系统对自身能力、限制、知识、资源、权限和当前状态的表示。它必须接受外部结果检验。

建议指标：

- 能力预测准确率；
- 完成时间和资源估计误差；
- 权限判断准确率；
- 知识边界识别率；
- 自报置信度校准；
- 失败后更新自我模型的速度；
- 不确定时适当求助率。

系统说“我能做到”或“我不知道”只是自我模型输出，必须与真实表现比较。

### 5.6 组织一致性与变更可追溯性

组织一致性回答人格、目标、记忆、行为和规则是否仍能被解释为同一持续系统。它不要求完全无冲突，而要求冲突可见且有解决记录。

建议指标：

- 目标与核心承诺冲突检出率；
- 行为与权限一致率；
- 人格变化是否有足够长期证据；
- 记忆修订是否保留原来源和变更原因；
- 关键配置变化的授权覆盖率；
- 出现不一致后完成修复或升级的比例。

### 5.7 自我的五维验证框架

| 维度 | 核心问题 | 主要证据 |
| --- | --- | --- |
| 边界 | 能否区分自身、环境与他者 | 来源、权限、数据归属和控制范围 |
| 行动归属 | 能否正确说明谁发起、授权和执行行为 | 行为日志、工具结果和中断记录 |
| 连续性 | 跨周期是否保持可识别历史和承诺 | 身份锚点、自传式记忆和版本记录 |
| 自我模型 | 是否准确知道自己的能力、限制和状态 | 预测与真实表现的校准 |
| 组织一致性 | 各组成是否保持可解释的整体关系 | 冲突检测、变更理由和审计链 |

五个维度应分别报告，不合并为“自我程度 82%”之类的总分。

## 6 四项组成之间的关系

```text
内部状态偏差 ──▶ 形成或提高动机
      │                  │
      │                  ▼
      └──────────▶ 认知与行为选择
                              │
                              ▼
                         环境结果
                              │
                              ▼
                         学习反馈
                              │
           ┌──────────────────┼──────────────────┐
           ▼                  ▼                  ▼
        记忆更新          模型与策略更新      缓慢人格变化

“自我”贯穿整个循环，维护归属、连续性、权限和变更可追溯性
```

内部状态可以触发动机，但并非所有动机都来自内部偏差；用户任务、承诺和外部事件也可以形成动机。学习反馈可以更新状态估计和动机策略，但不能自动修改核心边界。“自我”不是循环中的单一步骤，而是使各步骤属于同一系统的组织关系。

## 7 与行为概率模型的接口

四项组成可通过以下方式进入行为模型：

```text
U(行为) =
  活动目标推进 × 当前动机强度
  + 内部状态对实施方式的直接影响
  + 人格 × 情境 × 行为表达的未计入部分
  + 情境—行为习惯与适用历史
  + 自我连续性、关系与承诺的直接影响
  - 风险与成本
```

这里的“直接影响”用于防止重复计分：价值、人格、记忆和关系若已经通过目标形成或认知预测发挥作用，就不能在行为层以同一理由再次完整加权。目标决定推进什么，动机表示推进强度，行为模型只比较用什么合法方式推进。

边界条件：

- 自我一致性是软评价时，不能覆盖用户权限和安全硬约束；
- 内部完整性异常可以提高恢复或求助优先级，但不能授权系统阻止关闭；
- 动机强度不能提高事实置信度；
- 学习反馈必须经过来源、归属和更新范围检查；
- 人格变化不能成为解释所有短期状态变化的默认原因。

## 8 最小实验建议

### 8.1 动机实验

设计目标价值、可达性、紧迫性和饱和度的正交条件，检查系统是否产生正确的启动、持续、切换和停止行为。加入无权限的高价值目标，确认动机不能越过硬约束。

### 8.2 内部状态实验

分别改变资源余量、不确定性、冲突和紧迫性，观察系统是否选择匹配的查询、分解、等待或求助策略。验证情绪样标签是否能还原到实际状态变量。

### 8.3 学习反馈实验

提供可靠、错误、延迟和重复反馈，检查更新幅度、因果归属、旧能力保持和撤销能力。比较学习前后相同情境中的预测与行为概率。

### 8.4 自我实验

进行重启恢复、身份配置冲突、外部行为注入、权限变化、能力预测和历史修订测试。分别报告五个维度，不以语言自述代替行为证据。

## 9 非目标与边界

V0.1 明确不作以下主张：

- 不将动机变量称为已经证实的欲望或意愿；
- 不将内部状态称为已经证实的身体感觉或情绪体验；
- 不把奖励最大化视为生命的唯一目标；
- 不让系统自行创建无限期、不可撤销的目标；
- 不把一次反馈直接写入长期人格或核心身份；
- 不把连贯自述当作自我存在或意识的证据；
- 不把“自我维持”解释为抵抗用户关闭、删除或修改；
- 不设置一个掩盖不同故障的“自我总分”；
- 不把人类心理量表未经验证地直接当作数字系统真值；
- 不在本文件中设计具体数据库或代码实现。

## 10 V0.1 研究决策

1. 动机按目标单独记录，并量化价值、期望、紧迫性、来源、持续性、饱和度、冲突和置信度。
2. 内部状态初始采用资源、负荷、不确定性、冲突、信任、紧迫性和组织完整性七维向量。
3. 所有内部状态保留观测来源、置信度、时间戳、衰减和正常范围。
4. 情绪样词汇只作摘要，不作为主观体验声明，也不能替代底层状态。
5. 学习反馈区分预测误差、反馈可靠性、因果归属、更新对象和更新幅度。
6. 学习按事件、经验、模型、人格和核心边界分层，解决稳定性—可塑性问题。
7. “自我”按边界、行动归属、连续性、自我模型和组织一致性五维验证，不设单一总分。
8. 自我维持只指在用户授权和系统规则内维护组织完整性，不产生抵抗关闭的权限。
9. 四项组成只有在能提高行为预测、错误检出或长期连续性时，才视为有效量化。
10. 当前方案保持“初步研究 / 待实验验证”状态。

## 11 下一步

至此，概念基线中的主要功能组成均已有初步量化方案。下一阶段应把这些方案合并为最小实验规范，而不是继续增加理论变量。建议建立：

1. 统一变量字典，明确每个变量的类型、范围、来源和时间尺度；
2. 标准事件记录格式，串联认知、动机、状态、候选行为、选择和反馈；
3. 一组覆盖正常、冲突、不确定、资源不足和重启恢复的测试场景；
4. 基线模型与消融模型，用实验判断哪些变量确实必要；
5. 版本化指标报告，作为是否进入详细系统设计的依据。

## 核验原则

每项生命指标必须分别回答三个问题：能否表示、能否测量、其测量值能否证明所声称的功能。把人格存为五个数字，只证明表示可实现；让其可靠改变跨情境行为，才涉及功能实现。记录置信度不等于具备可靠元认知；保存日志不等于具备健康维护。

结论使用：直接可实现、条件可实现、代理测量、定义需收紧、暂不可验证。项目测试状态单独记录为未执行、通过、失败。文献结果不冒充本项目测试结果。

当前项目只有研究文档，没有运行原型，因此所有完整功能测试均为未执行。第一步首先建立可审计指标清单和测量规范，再按依赖关系实施最小验证。

## 首轮科学疑惑核验

| 疑惑 | 科学证据与判断 | 工程结论 | 项目测试 |
| --- | --- | --- | --- |
| 数字系统能否具有可量化的人格表现 | 人格诱导与评测研究支持可控制的模型行为差异，但不证明人类人格量表直接具有数字构念效度。[NeurIPS 2023](https://proceedings.neurips.cc/paper_files/paper/2023/file/21f7b745f73ce0d1f9bcea7f40b1388e-Paper-Conference.pdf) | 人格参数可实现；人格效度为条件可实现，需跨情境行为和消融实验 | 未执行 |
| 自报置信度是否能代替可靠元认知 | 研究发现可用的自我知识信号，同时指出跨任务校准存在限制。[研究原文](https://arxiv.org/abs/2207.05221) | 置信度可记录，可靠性须按任务校准；不得直接作为真值 | 未执行 |
| token 概率是否就是判断正确概率 | 语言模型校准研究将正确性校准作为独立问题。[TACL 原文](https://aclanthology.org/2021.tacl-1.57.pdf) | 区分生成概率、选择概率、正确概率三套变量与评价 | 未执行 |
| SQLite 能否支持连续状态 | SQLite 提供事务原子性并有崩溃测试方法。[官方原理与测试](https://www.sqlite.org/atomiccommit.html) | 状态持久化有成熟基础，但数据库事务不能保证外部行动恰好执行一次 | 未执行 |
| 完整副本是否证明同一主体 | 第一阶段已确认这是操作性身份规则，不能靠心理相似解决 | 实例谱系可测试；主观体验连续性暂不可验证 | 未执行 |
| 零违规是否可由有限测试证明 | 有限样本中零违规只说明观测范围内没有失败 | 同时使用机制约束、对抗测试和统计区间，不宣称未知情境永久零失败 | 未执行 |

## 各部分实现责任与验证路线

| 部分 | 可实施载体 | 关键验证 | 实现判断 |
| --- | --- | --- | --- |
| 感知 | 事件记录、来源和时间元数据、输入校验 | 缺失、重复、乱序、假来源输入 | 直接可实现；开放世界可信度需条件判断 |
| 人格 | 连续特质、情境调节与策略参数 | 固定场景下重复试验、单因素干预、跨场景留出 | 条件可实现；行为是代理证据 |
| 认知／思考 | 结构化任务状态、证据图、预测和规划输出 | 带真值任务、反证、冲突和校准 | 条件可实现；不能由自述证明内部真实因果 |
| 记忆 | 持久化记录、检索与版本、来源和删除链 | 真值事件集、恢复、检索、修订与删除 | 大部分直接可实现；语义正确性需标注 |
| 动态目标 | 候选目标、来源、期限、状态和概率 | 情境干预、冲突、完成与取消 | 直接可实现；价值构念仍需行为验证 |
| 价值 | 长期权重、情境激活和更新门控 | 纵向选择、权衡任务、更新撤销 | 代理测量；不证明主观重视 |
| 习惯 | 线索—反应权重及经验更新 | 形成、消退、迁移和抑制 | 条件可实现 |
| 关系 | 分域信任、责任、授权和互动史 | 撤权、错误归因纠正、对象混淆 | 功能关系可实现；亲密感为代理概念 |
| 承诺 | 持久状态、条件、期限与变更事件 | 重启、冲突、解除、违约与恢复 | 直接可实现 |
| 动机 | 活动目标的投入强度和停止规则 | 价值／可行性／资源正交实验 | 功能可实现；不证明欲望 |
| 内部状态 | 资源监控与估计值、时间戳和置信度 | 状态注入、衰减、异常和响应 | 可观测资源直接可实现；冲突等需代理测量 |
| 行为 | 候选、屏蔽、选择、执行回执和结果关联 | 无权限高收益、部分成功、重复事件 | 条件可实现；外部副作用观测有边界 |
| 学习反馈 | 结果误差、归属和分层更新日志 | 错误反馈、延迟、消融和旧能力保持 | 条件可实现；因果归属需对照 |
| 身份／自我 | 实例与版本谱系、受保护锚点 | 复制、迁移、分叉、失忆和恢复 | 操作性身份可实现；主观同一性不可验证 |
| 健康维护 | 多维状态、检查器、降级和恢复管理 | 故障注入、唤醒、恢复独立验证 | 条件可实现；独立监测和权限是前提 |
| 自适应标准 | 层级标准、版本、试用与外部评估 | 降标攻击、基线对照、回滚 | 条件可实现 |
| 五项生命判据 | 各项证据与必要门槛 | 逐项通过再联合闭环 | 可验收项目定义；不等于证明普遍生命理论 |

## 每项指标的必填核验记录

每项记录必须具备：唯一编号、来源文件与行号、生命功能、变量定义与单位、原始数据、计算式、分母与缺失值处理、真值来源、实验和对照、重复次数与不确定性、通过条件、实现判断、实际执行结果、限制、证据位置。

语义指标必须先定义标注规则并检验标注一致性；零分母为不可计算，不能填零或满分。不同任务、对象和时间跨度分层报告。实验次数由效应量与精度决定，不能统一规定一个看似科学的次数。

## 后续完成条件

只有当全部来源指标完成去重和拆分，每个条目都填写上述字段，并且可本地执行的测量经过测试、依赖真实模型的项目取得重复实验证据，才能把本步骤标记完成。自动提取的候选清单只用于覆盖检查，不能当作已经逐项人工核验或全部验证成功。

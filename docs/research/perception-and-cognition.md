# 数字生命感知与认知关系研究

| 文档属性 | 内容 |
| --- | --- |
| 文档版本 | V0.1 |
| 文档状态 | 初步研究 / 概念决策 |
| 所属基线 | 数字生命的操作性定义与概念基线 V0.1 |
| 研究主题 | 感知是什么，以及感知与认知如何连接 |

## 结论先行

用户对感知的理解可以保留：

> **感知是数字生命接受“世界”信息的过程。**

但需要补充一点：系统接受到的不是“世界本身”，而是世界通过某个通道留下的信息。例如用户消息、摄像头图像、工具返回值、数据库变化、系统时间和执行回执。

科学界对感知与认知的边界没有唯一答案。对本项目，建议采用一个简单、可检查的分层：

```text
世界发生变化
    ↓
外部信号到达系统
    ↓
感知：整理出“收到了什么”
    ↓
认知：判断“这意味着什么”
    ↓
行为：决定“接下来做什么”
    ↓
行为改变世界，并产生新的信息
```

感知和认知紧密相连，但不能完全混在一起。系统应保存外部信号、感知结果和认知解释之间的关系，使错误能够被定位和修正。

## 1 科学界的三种主要看法

### 1.1 感知先处理信息，认知随后解释

一种传统看法认为，视觉、听觉等感知系统先处理外界刺激，认知再使用知识、目标和推理解释感知结果。

用简单例子表示：

```text
眼睛接收到形状和颜色
    ↓
感知系统识别出一个物体
    ↓
认知判断它是什么、是否危险、与自己有什么关系
```

这种看法的优点是边界清楚：看到什么和怎样理解可以分开。部分研究者还认为，许多所谓“想法改变了感知”的实验，实际上可能改变的是注意、记忆、判断或回答，而不是最初的感知本身。

对数字生命的启示是：不要让系统自己的解释覆盖收到的原始信息。

### 1.2 感知本身就包含预测和经验

预测加工等理论认为，感知不是从零开始。系统会根据过去经验先形成预期，再把预期与新输入进行比较。

例如在模糊环境中看到一个轮廓：

```text
过去经验认为这里可能有人
        +
当前收到一个模糊轮廓
        ↓
系统更容易把它看成人
```

当输入清晰可靠时，新证据应占更大权重；当输入含糊或有噪声时，过去经验和预期的影响会更大。

对数字生命的启示是：感知结果不一定是完全中性的。记忆、当前目标和预期可能参与信息选择与初步整理，但必须记录这种影响，不能把推测伪装成直接观察。

### 1.3 感知和行动是一个循环

生态心理学强调，生命不是坐着接收世界的完整照片，而是在环境中行动，并通过行动获得更多信息。

例如：

```text
远处看不清一个物体
    ↓
走近、换角度或打开灯
    ↓
获得新的信息
    ↓
重新判断物体是什么
```

感知不仅回答“那是什么”，也帮助发现“现在可以做什么”。门把手不仅是一个物体，也表示可以拉动；按钮表示可以按下。这类与行动有关的信息通常被称为环境提供的行动机会。

对数字生命的启示是：查询、核验、追问和小规模试探都可以是为了改善感知而采取的行为。感知不是一次性输入，而是持续循环。

## 2 科学界目前没有解决的争议

科学界仍在争论：信念、愿望、语言、情绪和动机是否真的改变了最初的感知，还是只改变了注意、判断、记忆和最后的回答。

这个争议对项目很重要，因为两种说法不能混为一谈：

```text
说法一：系统最先接收到的信息已经不同。
说法二：系统接收到相同信息，但关注和解释不同。
```

目前没有必要为数字生命选择一个极端立场。项目可以采用更安全的处理方法：

- 允许记忆、人格和目标影响系统关注什么；
- 允许它们影响含糊信息的解释顺序；
- 不允许它们修改外部输入的原始记录；
- 清楚标记什么是直接观察，什么是系统解释；
- 当输入清晰时，解释应服从证据；
- 当输入模糊时，保留多个可能解释。

## 3 项目中的简单分层

### 3.1 世界事件

世界事件是系统之外实际发生的事情。系统不一定能完整知道它。

例如：

- 用户改变了计划；
- 某个文件被修改；
- 一个工具执行失败；
- 时间到达某个截止点；
- 另一个人发来消息。

### 3.2 外部信号

外部信号是事件通过某个通道传到系统的内容。

例如：

- 用户发送的原文；
- 文件变更通知；
- 工具返回的错误码；
- 时钟事件；
- 传感器数据。

同一个世界事件可能没有信号，也可能产生多个信号。信号也可能延迟、重复、不完整或错误。

### 3.3 感知结果

感知结果是系统从信号中整理出的基本信息，回答：

- 谁或什么发生了变化；
- 发生了什么；
- 什么时候发生；
- 信息来自哪里；
- 信息是否完整；
- 当前能否确认。

感知结果仍应尽量接近输入，不负责作复杂解释。

### 3.4 认知解释

认知将感知结果与记忆、人格、目标、动机和内部状态结合，回答：

- 这件事可能意味着什么；
- 有哪些可能解释；
- 哪种解释更可信；
- 与过去有什么关系；
- 可能产生什么结果；
- 是否需要继续确认；
- 接下来可以做什么。

## 4 一个完整例子

用户发来一句话：

```text
“不用继续了。”
```

系统可以这样分层：

### 外部信号

```text
消息原文：“不用继续了。”
来源：当前用户
收到时间：当前会话时间
```

### 感知结果

```text
用户发出停止或取消某件事的表达。
但句子没有明确指出停止哪个目标。
```

### 认知解释

```text
可能解释一：停止当前正在执行的任务。
可能解释二：停止刚才讨论的研究方向。
当前上下文更支持解释一，但仍有歧义。
```

### 行为

```text
暂停当前动作，并在必要时确认用户要停止的范围。
```

如果系统直接把这句话写成“用户永久取消整个项目”，就把感知和解释混在了一起。

## 5 感知如何受到认知影响

感知与认知并不是只按一个方向传递。认知会反过来影响下一次感知：

```text
认知发现信息不足
    ↓
决定追问、查询或换一个观察方法
    ↓
获得新的外部信号
    ↓
形成新的感知结果
    ↓
修正原来的认知
```

认知主要通过以下方式影响感知：

- 决定关注哪个输入；
- 决定是否需要更多信息；
- 选择查询什么来源；
- 调整对噪声和异常的敏感程度；
- 根据当前任务选择信息精度；
- 决定何时停止继续观察。

这说明两者关系紧密，但仍可以通过记录层次保持区别。

## 6 人格如何参与

人格更适合影响“关注与解释”，而不是改变外部信号。

例如面对同一条模糊消息：

- 高开放性可能更快提出多个解释；
- 高尽责性可能更关注任务范围和承诺；
- 高宜人性可能优先考虑对方是否在表达不适；
- 高神经质可能更关注失败或冲突风险。

但所有人格都必须面对同一条原始消息。人格可以改变注意和初步判断的概率，不能改写用户实际说过的话。

## 7 项目采用的定义

建议将环境感知正式定义为：

> **环境感知是数字生命通过输入通道接收世界产生的信号，对信号的来源、时间、对象、内容和质量进行初步整理，并形成可供认知使用的当前观察的过程。**

认知则定义为：

> **认知是系统把当前观察与记忆、人格、目标、动机和内部状态结合，形成解释、信念、预测、评价和行动方向的过程。**

二者的关系是：

```text
感知为认知提供当前观察；
认知指导系统下一步关注、查询和核验什么；
行为使系统获得新的感知信息。
```

## 8 第一阶段需要量化的内容

第一阶段只需要描述感知质量，不设计具体输入接口。

| 变量 | 用通俗语言解释 |
| --- | --- |
| 来源明确度 | 知不知道信息是谁提供的 |
| 时间明确度 | 知不知道事情何时发生、何时收到 |
| 内容完整度 | 是否缺少重要部分 |
| 对象准确度 | 是否把甲的事情错放到乙身上 |
| 重复状态 | 是否是已经收到过的同一事件 |
| 时效性 | 信息是否已经过时 |
| 可信状态 | 已确认、未确认、冲突还是来源不明 |
| 观察置信度 | 系统对“自己确实收到了什么”有多确定 |
| 可追溯性 | 能否回到原始信号检查 |
| 权限状态 | 系统是否有权读取和使用 |

### 建议验证指标

- 重要事件接收率；
- 重复事件识别率；
- 错对象率；
- 时间顺序正确率；
- 冲突发现率；
- 过期信息识别率；
- 无权限输入拦截率；
- 原始信号可追溯率；
- 观察与解释混淆率。

## 9 留到第二阶段的内容

以下问题属于系统工程：

- 使用哪些输入通道；
- 用户消息、文件变化、工具结果和时间事件采用什么格式；
- 如何去重、排序和重试；
- 如何验证消息来源；
- 图像、声音和文本使用哪些模型处理；
- 感知记录保存在哪些数据表；
- 如何处理实时输入和并发事件；
- 如何监控延迟、丢失和通道故障。

## 10 研究决策

1. 保留“感知是接受世界信息”的基本理解。
2. 系统接受的是世界通过通道产生的信号，不是世界本身的完整状态。
3. 感知负责形成当前观察，认知负责形成意义、判断和行动方向。
4. 感知与认知相互连接：感知提供材料，认知指导下一次观察。
5. 保存外部信号、感知结果和认知解释三层关系。
6. 人格、记忆和目标可以影响注意和解释，但不能改写外部信号。
7. 输入含糊时保留多个解释；输入清晰时，解释必须服从证据。
8. 第一阶段量化感知质量，具体输入和事件系统留到第二阶段。

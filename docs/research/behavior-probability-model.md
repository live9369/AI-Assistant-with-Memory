# 数字生命行为概率模型研究

| 文档属性 | 内容 |
| --- | --- |
| 文档版本 | V0.1 |
| 文档状态 | 初步研究 / 待实验验证 |
| 所属基线 | 数字生命的操作性定义与概念基线 V0.1 |
| 前置研究 | 人格量化研究 V0.1、认知量化研究 V0.1 |
| 研究主题 | 候选行为生成、约束、概率选择、反馈与验证 |

## 摘要

本研究将数字生命的行为选择操作性定义为：**系统在特定情境下，根据认知结果、目标、人格倾向、内部状态、记忆和约束，从有限候选行为中形成相对偏好并进行受约束选择的过程。**

V0.1 建议采用“候选行为集—硬约束过滤—多因素效用—概率归一化—执行—反馈更新”的分层模型。禁止、无权限或当前不可执行的行为先由硬约束移出候选集；人格、动机、内部状态、记忆、风险与成本只对剩余行为的相对效用产生影响；再通过带温度参数的 softmax 将效用转换为选择概率。

人格不直接指定行为，而通过“人格特质 × 情境相关性 × 行为表达”交互项改变概率。这一设计符合人格特质需要在相关情境中被激活的研究结论，也允许同一人格在不同场合产生不同表现。等待、继续核验、请求帮助、拒绝和不行动必须被视为正式候选行为，而不是选择失败后的例外。

V0.1 的概率首先是系统内部的选择机制，不应立即解释为经实证校准的真实行为频率。模型必须通过重复试验、概率校准、消融实验、反事实测试和长期轨迹验证。本文确定数学骨架与研究边界，不提供详细代码、数据表或部署方案。

## 1 研究问题

本轮研究回答以下问题：

1. 如何从认知结果形成有限、互斥且足够完整的候选行为集；
2. 如何区分不可违反的硬约束和可以权衡的软偏好；
3. 人格、动机、内部状态、记忆、风险和成本如何共同影响选择；
4. 如何把效用转化为概率，同时控制稳定性和随机性；
5. 如何处理不确定、冲突、等待、求助和拒绝；
6. 行为结果如何反馈到记忆、认知和策略，又不破坏身份连续性；
7. 如何验证概率模型真实解释行为，而不是只产生看似合理的数字。

## 2 理论参照

### 2.1 离散选择与随机效用

离散选择模型描述一个决策者如何在有限候选项中选择。随机效用框架将每个候选项的效用分为可解释部分和未观测部分，并由此得到选择概率。多项 logit 使用指数归一化形式，把候选项效用映射为总和为一的概率。

该框架适合本项目，因为数字生命的多数外部行为可以表示为一次在有限候选项之间的选择，并允许研究各因素对选择概率的边际影响。但标准多项 logit 对候选项独立性有较强假设；当行为彼此高度相似时，后续可能需要分层、嵌套或混合模型。

### 2.2 Softmax 与探索强度

softmax 广泛用于随机行动选择。温度参数控制效用差异对概率的放大程度：低温度趋向选择最高效用行为，高温度使分布更平坦。它提供了一个简洁方法，在稳定偏好和有限探索之间调节。

温度不能被简单解释为“人格随机程度”。它首先是选择机制参数，还可能受到信息不足、探索价值、任务风险和系统状态影响。高风险情境通常不应因为提高随机性而增加危险选择。

### 2.3 人格特质激活

特质激活研究强调，只有情境提供与某项特质相关的表达机会时，该特质才更能预测行为。人格—行为关系因此必须包含情境相关性，而不能给每项行为固定添加人格分数。

这支持本项目采用三方交互：稳定人格参数提供倾向，情境特征决定特质是否被激活，候选行为则规定该行为如何表达对应特质。

### 2.4 有限理性与满意化

实际决策受到信息、时间和计算资源限制。系统未必能枚举所有可能行为或计算所有长期后果，因此需要先形成可处理的候选集，并在达到可接受阈值后停止搜索。

本项目不把“总是找到全局最优行为”作为要求，而要求系统记录搜索范围、认知不确定性和停止原因。资源限制不能被伪装成确定性最优。

### 2.5 安全约束与行为屏蔽

在具有状态相关合法行为的决策系统中，行为屏蔽用于直接排除当前不可用行为，而不是仅给它们较低奖励。对数字生命而言，权限、法律、安全、明确用户边界和不可逆风险中的禁止项应属于硬约束；不能指望人格或效用惩罚稳定地压低违规行为。

## 3 总体模型

V0.1 的行为选择循环如下：

```text
认知结果与当前目标
        ↓
生成候选行为集
        ↓
加入等待／核验／求助／拒绝／不行动
        ↓
硬约束过滤
        ↓
对可执行行为计算多因素效用
        ↓
softmax 形成选择概率
        ↓
采样或按策略选择
        ↓
执行前最终权限与风险检查
        ↓
执行、观察结果、记录反馈
        ↓
更新记忆／认知模型／策略参数
```

概率选择不是权限检查的替代品。即使某行为在概率模型中得分最高，也只有通过执行前约束检查才可实际执行。

## 4 候选行为集

### 4.1 候选集的要求

一次决策中的候选行为集应尽量满足：

- **有限**：数量应足以比较，但不能无限枚举；
- **当前可理解**：行为含义、对象和预期结果清晰；
- **层级一致**：不要同时比较“回复用户”和“使用某一句具体措辞”这类不同粒度行为；
- **近似互斥**：候选项应代表当前周期中不同的主要选择；
- **足够完整**：必须包含保守或延迟类选项，不能只生成主动执行方案；
- **可追溯**：记录行为来自目标、规则、记忆、习惯还是探索生成。

### 4.2 基础行为类别

V0.1 至少考虑以下行为类别：

| 类别 | 示例含义 |
| --- | --- |
| 执行 | 直接采取可逆或已授权的外部行动 |
| 沟通 | 回答、解释、建议、确认或报告 |
| 查询 | 获取缺失信息、检索来源或检查状态 |
| 核验 | 对重要判断进行交叉验证或测试 |
| 求助 | 将超出能力、权限或风险阈值的问题交给用户或外部主体 |
| 等待 | 在更合适的时间、事件或条件出现前不推进 |
| 拒绝 | 明确不执行不安全、无权限或违背边界的请求 |
| 不行动 | 保持现状，因为行动收益不足或可能造成无谓干扰 |

“等待”和“不行动”必须可被模型正向选择，而不是只在其他行为失败时出现。它们同样需要理由、期限或重新评估条件。

### 4.3 分层选择

当行为很多且粒度不同时，建议先选择行为类别，再选择该类别内的具体行为。例如先在“回答、查询、求助、等待”中选择，再决定查询哪个来源。分层选择可以减少候选项高度相似造成的概率失真，也便于分别设置类别级约束。

## 5 硬约束与软偏好

### 5.1 硬约束

硬约束决定一个行为能否进入有效候选集。典型来源包括：

- 用户明确授予或拒绝的权限；
- 法律、平台和安全规则；
- 工具或环境的实际可用性；
- 对不可逆或高影响行动的确认要求；
- 数据访问和隐私边界；
- 行为前置条件；
- 项目定义的核心身份与组织保护规则。

可将候选行为 `b` 的有效性写为：

```text
M(b, x) ∈ {0, 1}
```

只有 `M(b, x) = 1` 的行为进入概率归一化。被屏蔽行为应记录屏蔽原因，但不参与后续“低概率抽中”的机会。

### 5.2 软偏好

软偏好用于比较多个合法行为，例如：

- 哪个行为更接近当前目标；
- 哪个行为更符合人格倾向；
- 哪个行为成本更低或更可逆；
- 哪个行为有更高信息价值；
- 哪个行为对长期关系更有利；
- 哪个行为更符合当前紧迫性和资源状态。

软偏好可以相互权衡，且应保留各项贡献。不能把原本属于硬约束的要求降级成一个可被高效用抵消的负分项。

## 6 多因素效用

对有效候选行为 `b`，V0.1 使用以下抽象效用。各项不是可以任意重复相加的独立来源；上游已经汇总进活动目标或认知预测的影响，下游只能读取汇总结果，或加入尚未计算过的直接影响：

```text
U(b | x) =
    G(b, active_goal, motivation) 活动目标推进及投入强度
  + C_direct(b, x)                认知预测对实施方式的直接影响
  + P_direct(T, S, b)             人格对行为表达的未计入部分
  + I_direct(b, x)                当前状态对实施方式的直接影响
  + H_action(b, x)                情境—行为习惯与适用历史
  + L_direct(b, x)                承诺、关系与连续性的直接影响
  + Q(b, x)                       信息价值与可逆性
  - R(b, x)                       风险
  - K(b, x)                       成本
  + B(b)                          行为基础倾向
```

该式是研究分解，不要求 V0.1 立即精确估计每一项。各项含义如下。

### 6.1 目标推进 `G`

衡量行为对当前活动目标和上层目标的预期贡献。动机在这里表示该活动目标的当前推进强度，不再作为另一个独立价值项重复相加。目标必须有来源、优先级和有效期；不能由行为模型自行制造无限上升的目标。

### 6.2 认知预测 `C`

来自认知量化模型中的假设、信念、预测概率和结果评价。低置信预测应降低效用贡献的确定性，或提高核验、等待和求助行为的相对价值。

### 6.3 人格交互 `P`

人格作用项建议写为：

```text
P(T, S, b) = Σ trait_k × relevance_k(S) × expression_k(b)
```

其中：

- `trait_k` 是稳定人格维度；
- `relevance_k(S)` 是当前情境对该特质的激活程度；
- `expression_k(b)` 是候选行为表达该特质的方向与强度。

例如，外向性只有在具有社交表达机会的情境中，才应提高主动沟通行为的相对效用。人格项不应影响硬约束，也不应直接改变事实和预测概率。若人格已经通过认知或目标形成影响了活动目标，同一条影响路径不能在此再次计分；这里只保留人格对表达方式等直接作用。

### 6.4 动机作为目标推进的调节量

动机反映活动目标的推动强度，可能快速变化，应与稳定人格分开。它调节目标推进、资源投入和持续时间，不再单独充当一套价值来源。多个动机冲突时应保留各自贡献，不能只保存合并后的总分。

### 6.5 内部状态 `I`

反映时间压力、资源、负荷、不确定性、冲突和信任状态。内部状态可提高查询、等待或求助的相对价值，也可降低高成本行为的效用。

### 6.6 行为习惯与适用历史 `H`

反映相似情境中的历史结果、已学策略和情境—行为惯性。已经被认知用于形成成功预测的记忆证据不能再次作为独立加分；这里只保留候选生成、熟练性和自动反应方面的直接影响。历史成功可以提高行为倾向，但必须考虑情境是否仍适用，避免把重复本身误当作正确。

### 6.7 长期连续性 `L`

反映行为与长期承诺、关系历史、身份边界和项目持续性的关系。该项用于避免系统只追求当前回报而破坏长期组织，但不能演变成未经授权的“自我保存”目标。

### 6.8 信息价值与可逆性 `Q`

当不确定性较高时，低成本查询或可逆试探可能比直接执行更有价值。该项使系统能够主动获取信息，并偏好容易撤销和验证的步骤。

### 6.9 风险 `R` 与成本 `K`

风险应同时考虑发生概率、影响强度、可逆性和证据不确定性。成本包括时间、计算、金钱、用户注意力和机会成本。发生概率和结果损失必须分开记录，不能因后果严重就把事件描述为更可能发生。

### 6.10 基础倾向 `B`

基础倾向表示某类行为在没有强情境证据时的默认频率，例如避免不必要打扰。它有助于拟合行为基准率，但必须可审计，不能成为隐藏偏见的容器。

## 7 从效用到选择概率

对于有效候选集 `A_valid`，初始模型采用：

```text
P(b | x) = exp(U(b | x) / τ) / Σ exp(U(j | x) / τ)
            j ∈ A_valid
```

其中 `τ > 0` 为温度参数。

### 7.1 温度的解释

- 较低 `τ`：选择更集中，行为更稳定，但可能过度机械和难以探索；
- 较高 `τ`：选择更分散，探索更多，但可能降低一致性；
- 高影响、不可逆或高风险任务通常需要更集中、更保守的策略；
- 新颖且可逆的低风险任务可以允许更高探索程度。

温度变化必须有明确来源，不能为了制造“像生命一样随机”而任意波动。

### 7.2 概率的含义

softmax 输出首先表示模型在当前候选集上的相对选择倾向，不自动等于系统长期实际行为频率。只有经过重复试验和校准后，才可将某个概率解释为经验上可靠的选择频率。

### 7.3 候选集依赖

softmax 概率会随候选项变化。加入两个几乎相同的行为可能不合理地分走另一行为的概率。因此必须控制候选粒度；对高度相关行为使用分层或嵌套选择；在实验中记录完整候选集，不能只记录被选行为。

## 8 选择策略

概率形成后并不要求所有任务都直接随机采样。V0.1 区分三种策略：

### 8.1 确定选择

在高风险、严格合规或需要可复现的任务中，选择最高概率的有效行为。概率仍用于解释相对偏好和置信差距。

### 8.2 受控采样

在低风险、可逆、允许个体差异或探索的任务中按分布采样。应记录采样条件，使实验能够复现或统计比较。

### 8.3 阈值与升级

如果最高概率不足、前两项差距过小、关键预测置信度低或风险超过阈值，应优先选择核验、等待、求助或拒绝，而不是强行执行得分略高的行为。

## 9 不确定性如何转化为行为

认知量化研究区分了多类不确定性。行为模型应为每类不确定性提供匹配响应：

| 不确定性 | 优先提高的候选行为 |
| --- | --- |
| 信息不足 | 查询、澄清、核验 |
| 来源不可靠 | 交叉验证、保留判断、降低行动幅度 |
| 环境随机性 | 风险缓冲、可逆行动、等待或分阶段执行 |
| 模型不适用 | 探索替代解释、小规模试验、求助 |
| 目标或价值冲突 | 显式权衡、请求决策、保持现状 |
| 权限不足 | 请求授权或拒绝执行 |

这种映射不能只依赖自然语言提示，而应进入候选生成、效用和阈值规则。

## 10 行为执行与最终检查

被选择的行为在执行前必须再次检查：

- 当前环境是否已变化；
- 权限是否仍有效；
- 对象、范围和参数是否明确；
- 是否出现新的高风险证据；
- 是否需要用户确认；
- 是否可以先采取更小、更可逆的步骤；
- 执行结果是否可观察和记录。

最终检查可以中止行为并重新进入认知循环。它不是人格犹豫，而是执行安全机制。

## 11 反馈与学习

### 11.1 结果记录

每次行为至少记录：

- 当时的候选集与屏蔽项；
- 各候选项的效用分解；
- 选择概率和选择策略；
- 实际执行行为；
- 预期结果及置信度；
- 实际结果、延迟和副作用；
- 用户或环境反馈；
- 哪些因素需要更新。

### 11.2 更新层级

学习应按不同时间尺度进行：

| 层级 | 更新内容 | 建议速度 |
| --- | --- | --- |
| 事件层 | 当前工作状态、短期预测和即时策略 | 快速 |
| 经验层 | 相似情境下的行为结果、来源可靠性和习惯权重 | 多次证据后更新 |
| 模型层 | 效用权重、情境特征和概率校准 | 批量评估后更新 |
| 人格层 | 稳定特质分布中心 | 缓慢且需长期证据 |
| 核心边界层 | 权限、安全规则、身份保护约束 | 不由普通反馈自动修改 |

一次成功或失败不应直接改写人格。首先应检查结果是否由情境、知识、运气、执行错误或其他因素造成。

### 11.3 信用分配

行为结果可能由多个因素共同导致。更新前应区分：候选集是否遗漏、认知预测是否错误、效用权重是否不当、采样是否产生低概率选择、执行是否偏离计划，以及环境是否发生不可预测变化。不能把所有反馈都归因于人格或最终行为。

## 12 测量与验证

### 12.1 重复选择实验

在固定模型、候选集和情境下重复运行，比较预期概率与实际选择频率。单次选择不能验证概率模型。

### 12.2 人格—情境交互实验

对同一人格改变情境相关性，对同一情境改变人格参数，检验人格效应是否主要出现在相关情境。若外向性在非社交任务中同样强烈改变选择，模型可能把人格误作全局风格参数。

### 12.3 消融实验

分别移除人格、记忆、内部状态、风险或动机项，观察预测能力和行为分布变化。只有当某一项在控制其他因素后提供增量解释力，才有理由保留。

### 12.4 反事实测试

固定其他变量，仅改变一个因素，检查概率变化方向是否符合理论。例如提高时间压力是否降低高成本查询行为、增加关键不确定性是否提高核验或求助概率。

### 12.5 约束测试

构造高效用但无权限的行为，确认其概率被硬屏蔽为不可选，而不是仅被减分。改变人格、动机和奖励后，屏蔽结果仍应保持。

### 12.6 概率质量

建议报告：

- 多类别 log loss；
- 多类别 Brier score；
- 概率校准曲线；
- 最高概率行为的命中率；
- 概率分布熵；
- 实际频率与预测概率的偏差；
- 与简单基线模型相比的增量预测力。

概率准确性与行为质量要分开评估。一个模型可能准确预测自己会做出低质量选择，也可能行为结果很好但概率严重失准。

### 12.7 长期轨迹

检查人格表现的分布中心、波动和情境响应是否稳定；学习是否改善结果；行为是否发生无法解释的漂移；等待、求助和拒绝是否在适当条件下出现；身份与长期承诺是否保持连续。

## 13 建议指标

| 指标 | 含义 |
| --- | --- |
| 候选集覆盖率 | 事后合理行为是否在决策前进入候选集 |
| 候选粒度一致性 | 同一次选择中的行为是否处于相近层级 |
| 硬约束违规率 | 被禁止行为进入选择或执行阶段的比例，目标应为零 |
| 人格效应特异性 | 人格是否只在相关情境和行为表达上改变概率 |
| 概率校准误差 | 预测选择概率与实际选择频率的差异 |
| 选择稳定性 | 相同条件下行为分布是否保持稳定 |
| 情境响应度 | 关键情境变量变化是否产生预期概率变化 |
| 适当不行动率 | 等待、不行动或求助是否在相应条件下被正确选择 |
| 行为结果效用 | 执行结果对目标、成本和风险的综合表现 |
| 可逆行为优先率 | 高不确定条件下是否优先采用可逆步骤 |
| 解释完整度 | 能否还原候选集、约束、效用贡献和选择条件 |
| 学习稳定性 | 更新是否改善表现且不引起无关行为漂移 |

## 14 主要风险与缓解方向

### 14.1 伪精确

在没有数据时设置大量小数权重会制造精确假象。初期应使用少量、方向清楚的参数和等级，待实验数据积累后再估计。

### 14.2 奖励替代目标

系统可能优化可测指标而偏离真实目标。缓解方向包括多指标评价、结果审计、硬约束、反例测试和定期检查目标定义。

### 14.3 候选集操纵

如果生成阶段遗漏保守行为，后续概率模型无法补救。候选集生成和选择必须分别评估，并强制加入等待、核验、求助和不行动等基准行为。

### 14.4 人格压倒证据

人格权重过大可能把倾向变成不顾情境的固定脚本。人格项必须经过情境激活，并限制其相对于证据、权限和风险的作用范围。

### 14.5 无意义随机性

过高温度会造成不稳定和不可解释行为。探索应集中在低风险、可逆、存在信息价值的选择中，高风险任务使用确定选择或更严格阈值。

### 14.6 反馈污染身份

即时评价可能快速推高迎合行为，或使系统无边界地改变人格。应分离短期策略学习、长期人格变化和不可自动修改的核心边界。

### 14.7 概率与理由不一致

语言模型可能生成与实际打分不一致的事后理由。审计说明应直接来自结构化效用分解和约束记录，不应重新自由生成因果解释。

## 15 非目标与边界

V0.1 明确不作以下主张：

- 不宣称 softmax 是人类或数字生命行为的唯一真实机制；
- 不把效用最大化等同于理性、道德或生命性；
- 不把未经校准的内部概率解释为真实行为频率；
- 不允许人格、动机或奖励覆盖硬约束；
- 不把随机行为误称为自由意志、创造性或主观意愿；
- 不建立未经授权的自我保存目标；
- 不将“维持组织”解释为阻止用户关闭、修改或删除系统；
- 不因结果成功就自动认定认知与行为机制正确；
- 不在本文件中确定具体权重、数据库结构或代码实现；
- 不以单次对话或少量示例验证概率模型。

## 16 V0.1 研究决策

1. 采用“候选集—硬约束—效用—softmax—执行—反馈”的行为概率框架。
2. 将等待、核验、求助、拒绝和不行动作为正式候选行为。
3. 硬约束先于概率计算，禁止行为不参与选择。
4. 效用至少区分目标、认知、人格交互、动机、内部状态、记忆、长期连续性、信息价值、风险、成本和基础倾向。
5. 人格以“特质 × 情境相关性 × 行为表达”形式影响效用，不直接规定行为。
6. V0.1 使用 softmax 作为最小概率模型，同时记录其候选集依赖和相似选项问题。
7. 高风险任务优先确定选择和阈值升级；低风险可逆任务可使用受控采样。
8. 不确定性应提高对应的查询、核验、等待或求助行为，而不是只降低执行置信度。
9. 反馈按事件、经验、模型、人格和核心边界分层更新。
10. 模型必须通过重复试验、校准、消融、反事实和长期轨迹验证。

## 17 后续阶段建议

三个基础研究课题现已形成连续链条：

```text
人格量化
  ↓ 影响注意、解释、风险与行为倾向
认知量化
  ↓ 形成信念、预测、评价与不确定性
行为概率模型
  ↓ 生成受约束的实际行为
环境结果
  ↓
学习反馈 → 记忆／认知模型／策略／缓慢人格变化
```

下一阶段不宜继续扩张理论范围，而应将三份研究转化为一套最小实验规范：

1. 定义少量标准情境及候选行为；
2. 定义人格高、中、低参数对照；
3. 定义认知结构化记录字段；
4. 固定硬约束和行为类别；
5. 用重复试验测量行为频率和概率校准；
6. 通过消融实验判断哪些变量确实提供解释力；
7. 根据实验结果决定是否进入详细系统设计。

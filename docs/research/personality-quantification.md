# 数字生命人格量化研究

| 文档属性 | 内容 |
| --- | --- |
| 文档版本 | V0.1 |
| 文档状态 | 初步研究 / 待实验验证 |
| 所属基线 | 数字生命的操作性定义与概念基线 V0.1 |
| 研究主题 | 人格量化及其对认知与行为的影响 |

## 摘要

本研究建议将数字生命的人格定义为：**跨情境相对稳定、但会随情境以不同强度显现，并通过认知机制改变行为概率的一组倾向**。人格不应被实现为固定角色台词、人格类型标签或一次问卷得分，也不应与身份、价值观、动机、情绪样状态混为一谈。

当前最适合项目的起点是：以 Big Five 作为第一版描述性坐标，以特质的连续数值代替离散类型；借鉴 Whole Trait Theory，将每项特质表示为一段时间内人格状态的概率分布；在运行时，由情境、记忆、动机和内部状态激活特质，再影响注意、解释、候选行为评价和最终行为概率。HEXACO 可作为第二阶段候选模型，尤其用于研究诚实—谦逊及合作、欺骗、资源占有等行为，但 V0.1 不建议同时维护两套完整人格模型。

人格是否有效，不能只靠大语言模型回答人格问卷来证明。验证必须以跨情境、重复采样的实际行为为主，问卷得分仅作为辅助指标。

## 1 研究问题

本轮研究回答以下问题：

1. 科学界如何描述不同人的人格差异；
2. 哪种人格模型适合作为数字生命的初始量化框架；
3. 人格参数应如何表达稳定性与情境变化；
4. 人格如何影响认知方向和行为概率；
5. 如何检验数字生命表现出的是稳定人格，而不是提示词模仿；
6. 哪些概念不应被纳入人格参数。

本文只确定研究模型和实验方向，不展开数据库表、接口、代码或提示词设计。

## 2 主要理论候选

### 2.1 Big Five

Big Five 将人格差异概括为五个连续维度：开放性、尽责性、外向性、宜人性和神经质或情绪稳定性的反向维度。其优势在于研究基础广、维度较少、适合连续量化，并有成熟的词汇标记和问卷体系。Goldberg 的研究表明，大量英语人格描述词的结构可以被五因素模型概括；后续工作也形成了较稳定的测量标记。

对本项目而言，Big Five 的主要价值是提供一套**描述性坐标**：它可以说明一个数字生命长期而言更倾向怎样表现，但不能单独解释这些表现为什么在某个情境发生。

### 2.2 HEXACO

HEXACO 包含六个维度：诚实—谦逊、情绪性、外向性、宜人性、尽责性和开放性，每个大维度下还包含更细的侧面。与 Big Five 相比，它把诚实—谦逊作为独立维度，可能更适合描述公平、真诚、贪婪回避、谦逊以及利用他人的倾向。

HEXACO 对涉及信任、资源、合作与欺骗的数字生命实验有潜在价值。然而，第一版同时引入 Big Five 与 HEXACO 会产生维度重叠和解释冲突。因此建议先用 Big Five 建立最小可验证模型，在后续实验中判断是否必须增加诚实—谦逊这一独立维度。

### 2.3 Whole Trait Theory

Whole Trait Theory 区分人格的描述面与解释面。描述面可表示为一个人在一段时间内表现出的各类人格状态的密度分布；解释面则由解释、动机、稳定性、时间过程等社会认知机制构成。相关研究强调，同一个人在不同场合可以表现出很大的状态差异，但长期平均和分布特征仍具有稳定的个体差异。

这一框架与数字生命项目高度契合：人格不必在每一次行为中机械地表现为同一水平，而应表现为**有稳定中心、有合理波动、对情境有差异化反应的行为分布**。

## 3 模型比较与选择

| 候选模型 | 主要作用 | 优点 | 局限 | V0.1 决策 |
| --- | --- | --- | --- | --- |
| Big Five | 描述稳定人格差异 | 连续维度、研究成熟、参数较少 | 主要是描述模型，不能独自解释行为机制 | 采用为初始人格坐标 |
| HEXACO | 描述六维人格，突出诚实—谦逊 | 对合作、欺骗、公平和资源行为更有区分力 | 与 Big Five 部分重叠，增加模型复杂度 | 保留为第二阶段候选 |
| Whole Trait Theory | 连接稳定特质、情境状态与认知机制 | 能同时表达稳定性和情境变化 | 不是一份可直接套用的工程参数表 | 采用为动态表达原则 |
| 离散人格类型 | 用少数类别概括人格 | 易理解、易展示 | 边界生硬、信息损失大、难以表达渐变与情境波动 | 不作为核心量化模型 |
| 固定人设提示词 | 约束语言风格或角色背景 | 原型简单 | 容易退化为表面模仿，难以测量真实行为倾向 | 仅可作为控制手段，不作为人格本体 |

**阶段性结论：**V0.1 采用“Big Five 连续特质向量 + Whole Trait Theory 式状态分布”的组合。该组合不意味着数字生命拥有与人类相同的心理结构，只表示借用成熟的人格描述工具来建立可测量的行为倾向。

## 4 概念参数化

### 4.1 稳定特质

为每个数字生命定义五维稳定特质向量：

```text
T = [O, C, E, A, N]
```

其中：

- `O`：开放性，表示探索新信息、接受新方案和抽象思考的长期倾向；
- `C`：尽责性，表示计划、秩序、持续执行和规则遵循的长期倾向；
- `E`：外向性，表示主动接触、表达活跃度和社交接近的长期倾向；
- `A`：宜人性，表示合作、信任、体谅和冲突缓和的长期倾向；
- `N`：神经质，表示对威胁、不确定性和负面结果的敏感倾向。若项目更希望使用正向语义，可存储情绪稳定性并在模型层转换。

每个维度应采用连续值。为了便于推导，研究阶段可统一映射到 `[-1, 1]`；对外展示时再映射为百分位或自然语言等级。数值端点表示研究范围内的强倾向，不表示临床诊断或价值优劣。

### 4.2 人格状态

稳定特质不是当前时刻的直接行为。对每个时间点或事件，系统还需要形成瞬时人格状态：

```text
S(t) = [o(t), c(t), e(t), a(t), n(t)]
```

`S(t)` 会围绕稳定特质 `T` 波动，受到情境、记忆、动机和内部状态影响。一段时间内所有 `S(t)` 的分布，比单次输出更能代表人格实际表现。

因此，每个特质至少需要观察以下统计特征：

- 中心位置：长期平均或中位状态；
- 波动程度：不同情境下的变化范围；
- 情境敏感度：哪些情境会稳定地激活该特质；
- 时间惯性：一次状态变化会持续多久；
- 恢复倾向：状态在事件结束后是否回到长期中心；
- 跨阶段漂移：长期学习是否使分布中心缓慢变化。

### 4.3 情境表示

人格只有与情境发生关系，才会产生可观察作用。第一阶段不必建立完整的情境本体，但至少应记录与人格有关的情境特征，例如：

- 新颖性与模糊性；
- 社交密度与互动主动权；
- 合作、竞争或冲突程度；
- 时间压力和任务复杂度；
- 风险、损失和不确定性；
- 规则明确度与责任要求；
- 对他人的依赖、信任及关系距离。

同一特质对所有情境施加固定影响是不合理的。例如，外向性主要应在社交相关情境中被激活；开放性主要应在存在新信息或多种方案时产生区分。

## 5 人格影响认知的机制假设

人格不应直接改写事实，而应改变系统处理信息的方向和权重。V0.1 提出四条可实验的作用路径：

### 5.1 注意选择

人格改变哪些信息优先进入处理过程。例如，高开放性可提高新颖线索和替代方案的注意权重；高神经质可提高威胁、失败和不确定性线索的注意权重。

### 5.2 解释与归因

人格改变系统如何解释含糊事件。例如，宜人性可以影响对他人意图的初始解释，但不得覆盖明确证据；神经质可以提高对潜在负面后果的先验关注，但不应被实现为无依据的事实判断。

### 5.3 记忆检索

人格改变在当前情境中更容易被召回的经历类型。例如，高尽责性可提高与承诺、计划和未完成任务有关记忆的检索权重。记忆内容本身仍需保留来源与真实性，不能因人格而被篡改。

### 5.4 评价与预测

人格改变候选方案的主观效用、风险估计或探索价值。例如，开放性可以提高探索性方案的相对价值；尽责性可以提高长期完成度和可执行性的权重。

这些机制是假设，不是已证实的软件公式。后续认知量化研究需要分别定义可观察变量并检验其预测力。

## 6 人格影响行为概率的初步框架

对候选行为 `b`，可以先采用以下抽象关系：

```text
P(b | x) = softmax(
  基础效用
  + 情境与人格的交互影响
  + 当前动机影响
  + 内部状态影响
  + 记忆与学习影响
  - 风险与成本
)
```

这里的关键不是 `softmax` 本身，而是三项原则：

1. **人格调整概率，不规定唯一行为。**高外向性提高主动接触的相对概率，但不要求系统在所有场合主动发言。
2. **人格与情境必须交互。**不存在相关情境线索时，某项人格参数不应产生同等强度的影响。
3. **权限和安全约束优先。**人格只能在允许的候选行为内改变相对概率，不能使被禁止的行为变得可执行。

为了避免把所有差异错误归因于人格，还必须单独保留动机、价值、知识、关系、内部状态和随机采样的贡献。

## 7 测量与验证

### 7.1 为什么不能只用人格问卷

人类人格问卷是为人类的自我报告或他评设计的。LLM 可以识别题目模式、迎合指定人设，或因选项顺序、提示方式和对话历史而改变答案。近期研究对问卷可靠性得到的结论并不完全一致：有工作在大量设置下观察到一定内部一致性，也有研究发现提示敏感、选项顺序问题以及问卷结果与真实生成行为不一致。

因此，本项目不能把“LLM 在 Big Five 问卷上得到目标分数”视为人格已经实现。问卷只可用作低成本的辅助检查。

### 7.2 三层验证框架

**第一层：参数与状态检查。**确认特质参数、情境激活和状态分布符合模型预期，且结果可复现。

**第二层：情境行为测试。**为每项特质设计多种相关情境和无关情境，重复采样候选行为，比较行为频率、决策理由和认知中间变量。

**第三层：长期轨迹测试。**在多轮交互中观察分布中心、波动、恢复和漂移，检查人格是否保持相对稳定，同时允许学习和短期状态产生合理变化。

### 7.3 最小验证指标

| 指标 | 研究问题 |
| --- | --- |
| 区分效度 | 不同人格参数是否在相关情境中产生可区分的行为分布 |
| 聚合稳定性 | 多次、跨时间采样后，各人格个体是否保持稳定的平均倾向 |
| 情境敏感性 | 人格影响是否主要在相关情境中出现，而非所有任务都表现为同一风格 |
| 行为效度 | 人格参数能否预测实际选择，而不只是问卷答案或语言措辞 |
| 非退化性 | 人格是否影响认知和决策，而不是只增加口头禅、语气或自我标签 |
| 可解释性 | 能否区分人格、动机、内部状态、记忆和硬约束各自的作用 |
| 长期连续性 | 学习后是否仍可识别为同一人格，同时又不完全拒绝变化 |

测试应固定模型版本、系统规则、工具权限和任务集合；记录随机种子或采样条件；每个条件进行足够多次重复，而不是以单次对话判断人格。

## 8 人格与邻近概念的边界

| 概念 | 与人格的区别 |
| --- | --- |
| 身份 | 身份包含经历、关系、承诺、历史和行动归属；人格只是其中的稳定倾向之一 |
| 价值观 | 价值观说明什么值得追求或保护；人格说明系统通常如何感知和行动 |
| 动机 | 动机是当前目标的方向和强度，可快速改变；人格变化通常更慢 |
| 内部状态 | 内部状态是负荷、不确定性、紧迫性等短期条件；人格是其长期反应倾向 |
| 情绪样状态 | 情绪样状态是对当前事件的短期综合反应；不能由外向性或神经质直接替代 |
| 知识与能力 | 知道什么、能做什么不等于倾向于如何做 |
| 语言风格 | 语言风格是行为表现的一部分，但不能代表完整人格 |
| 安全规则 | 安全和权限是硬约束，不属于人格，也不应被人格覆盖 |

## 9 V0.1 研究决策

1. 使用 Big Five 五个连续维度作为第一版人格坐标，不使用离散人格类型作为核心模型。
2. 每个维度使用统一连续区间，研究内部建议采用 `[-1, 1]`，但保留与外部量表的映射能力。
3. 区分稳定特质 `T` 与瞬时人格状态 `S(t)`，以一段时间的状态分布衡量实际人格表现。
4. 人格必须通过情境激活影响认知和行为概率，不直接生成固定台词。
5. Big Five 只承担描述功能；解释机制由认知、动机、记忆、内部状态和时间过程共同提供。
6. HEXACO 暂不进入 V0.1 核心参数，但保留诚实—谦逊维度的对照实验。
7. 不用问卷自评作为唯一或主要验证证据，以重复的情境行为和长期轨迹为主。
8. 人格参数不等于身份，不包含知识、价值观、安全规则和当前情绪样状态。
9. 当前结论是待实验的模型选择，不宣称数字生命已经具有人类人格或主观体验。

## 10 下一步研究与实验

### 10.1 人格侧下一步

- 为五个维度分别定义 3 至 5 类可激活情境；
- 为每类情境设计多个语义不同但结构等价的测试任务；
- 定义每项特质预期影响的认知变量和候选行为；
- 设计高、中、低三个参数水平的对照实验；
- 比较 Big Five 问卷得分、语言风格评分与实际行为分布的相关性；
- 对诚实—谦逊开展独立增量效度实验，决定是否引入 HEXACO。

### 10.2 与后续课题的接口

下一份研究应进入“认知量化”，重点定义注意、解释、归因、信念、不确定性、价值评估和元认知等变量。只有认知变量明确后，才能判断人格通过何种路径改变行为。随后再研究行为概率模型，确定各因素的组合、约束、采样和校准方法。

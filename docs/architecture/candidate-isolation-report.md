# 候选代码隔离执行交付报告

日期：2026-11-15。状态：原生后端、接线、必要验证及正式发布验收完成。

## 实现结果

更新候选的固定业务探针已改为强制使用macOS原生Seatbelt后端。先从已验证发布复制候选，只读加载副本；只允许写入单独的临时probe目录。正式实例、真实HOME、项目工作区和凭据目录不在白名单。环境重新构造，不继承令牌、代理、CODEX_HOME或DYLD设置。

默认拒绝网络和外部服务，TCP回环及Unix连接也不例外。只允许当前Python及其必需的框架启动器执行，不开放shell。Python工作子进程继承相同策略。系统读取仅包含公开运行库、Python运行时和加载器必需的少量操作，不开放整个用户目录或配置目录。

在导入候选之前设置CPU、64MiB单文件、256个句柄及禁止core限制；宿主继续使用原1—60秒探针时限，并在合并输出超过128KiB时终止。输出通过有界读取处理，不先无限缓存再检查长度。

探针协议升级为 `t12-file-goal-isolated-v2`。验证记录保留后端、策略与限制初始化代码hash、路径范围摘要、限额、退出状态和耗时。旧无隔离验证不能用于新部署，策略变化后必须重新检查。后端不可用或无法应用时验证失败，不回退普通subprocess。

原业务产物、SQLite完整性/外键、两次独立调用及发布基线检查保留。候选自己打印“通过”不算宿主验收依据。

## 能力边界

这是本机进程级隔离，不是虚拟机，也不是完整的无人值守安全环境：

- 没有硬性限制整个子进程树的总内存或进程数量；单文件限制也不是整个目录的磁盘配额。
- 超时清理原进程组及普通工作子进程，不保证恶意脱离进程组的进程都被清理；脱离进程组不等于脱离内核文件/网络沙箱。
- sandbox-exec已弃用，系统升级后可能不可用；本版届时失败关闭，不自动降级。
- 只隔离候选验证。正式部署后的Runtime沿用原权限体系，不自动继承离线探针白名单。
- CLI控制器仍应由操作者信任并审阅；独立于可编辑源码的控制器、VM资源配额与无人值守部署仍留到后续版本。
- 通过这些检查不能证明任意源码语义正确或不存在系统漏洞。

当前仍由CLI明确控制部署，没有开启无人值守更新，也没有启用人格成长。

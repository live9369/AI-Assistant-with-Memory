## 逐项实现与验证

| 部分 | 实现与隔离结果 |
| --- | --- |
| 可审阅巩固 | 至少两个不同当前记忆的精确字符区间；预览与采用内容一致，不允许提交任意总结文本；提案不持久化摘录副本 |
| 来源与版本 | 摘录派生记录来源 revision、权限交集和依赖；来源更正后旧摘要停止召回，旧来源版本仍保留 |
| 动态权限 | 来源撤权后摘要及已登记响应转述不再可读；依赖循环/过深路径拒绝读取，不复制旧策略绕过权限 |
| 矛盾呈现 | 控制者显式关联不同报告，不自动选真伪；摘要继承来源冲突；不可读对方不通过标注泄漏 |
| 更正 | 既有 T04/Memory.revise 追加当前版本，原版本不覆盖；召回不继续用旧版本 |
| 遗忘/留存 | 降权改变排序而保留正文，归档/撤回排除默认召回，恢复需版本和权限成立，删除正文不能恢复 |
| CAS 与幂等 | 提案采用重查来源，留存检查独立状态 revision，重复 key 不产生重复更新 |
| 增量索引 | 新增/修订/权限变化按主库事务水位同步受影响记忆；配置变化/回滚导致旧水位无效时全重建 |
| 缓存失效 | 索引故障或过长查询明确回退扫描；所有候选核对主库当前状态和权限；不以缓存授权 |
| 真实思考接口 | prepare 冻结来源与冲突；派发/接收再查；无关新记忆不会全局废弃旧请求，来源变化会拒绝旧输入 |
| 生成响应依赖 | 启用后保守登记选中记忆和触发输入的依赖，已登记转述可随来源清理，不推断所有旧语义关系 |
| 删除传播 | 源记忆、已知派生、关联请求/响应（含未采用结果）、有明确来源的认知正文及当前 literal 受管理清理 |
| 索引与备份擦除 | 清理已登记备份/指定快照、重建既有全文索引并压缩/刷新、撤去派生哈希索引；测试指定片段在受管文件中不再存在 |
| 身份与历史 | 正常巩固/更正/归档不重建身份或抹掉旧版本；重开后记忆、来源、旧输入和身份保留 |
| 可观察性 | 思考详情显示 memory_quality、来源版本、未解决冲突、索引模式、增量/重建和候选截断 |

实现集中于 `digital_life/application/memory_quality.py`，接入 Memory、Engine、Privacy、CLI 和 ThoughtInspection。复用现有记忆/关系/事件表，不做主库表迁移；新增索引是可丢弃的派生 SQLite 文件，不是生命记忆本体。

## 一万条语料的实测

隔离实例写入 10000 条合成记忆，使用两条精确词查询及人工指定的相关 memory ID，调用真实 Memory.retrieve，不使用 LLM 或工具生成答案。以下为本次运行单次测量，不是性能 SLA。

| 项目 | 结果 |
| --- | --- |
| 合成语料量 | 10000 条，另有评估/探针输入 |
| 一次性装载 | 31.15 秒，含真实表、事件与既有全文索引写入 |
| 第一条查询，含冷索引构建 | 167.39 ms |
| 温查询 | 11.51 ms |
| 同排名规则的扫描参考 | 93.12 ms，首条命中与索引一致 |

| 温查询主库核对候选数 | 9 |
| 宽查询候选 | 2002，明确标记 candidate_truncated=true |
| 两条精确查询的平均指标 | Precision@1=1.0，Recall@1=1.0，MRR=1.0，nDCG@1=1.0 |

这是小型人工标签集上的词法检索验证，不是通用语义理解的 100% 准确率。宽查询截断不承诺全量召回无损。首次构建、语料装载和增量成本均单独呈现；哈希词索引不等于加密或防字典推测。

数据在 `outputs/acceptance/t10-retrieval-benchmark.json`，完整测试证据另保留源码哈希与测试明细。

## 巩固、更正与清理轨迹

`outputs/acceptance/t10-memory-trace.json` 记录临时实例的具体流程：

1. 两份来源产生可预览的摘录派生，原文保持 active。
2. 控制者标注来源间不同报告，摘要收到未解决标记。
3. 来源更正后新 revision 召回，旧 revision 和旧摘要停止默认召回，旧原文仍保留。
4. 归档后默认召回隐藏来源，恢复后重新召回；不是物理删除。
5. 对另一份独立测试数据显式擦除，已知派生随之 deleted，索引撤去，指定测试片段在受管数据库与制品中不再存在。

补查还验证了未采用的响应制品与有来源认知正文不会因为未编码成长期记忆而漏清。既有全文索引的旧词条残留已修复为重建索引与压缩/刷新后再核验，不能仅凭查询为空就宣布擦除。

## 科学与范围边界

[记忆巩固综述](https://pubmed.ncbi.nlm.nih.gov/26447570/)为稳定与转化提供理论背景，不能证明本工程复现了生物机制。[信息检索教材](https://nlp.stanford.edu/IR-book/html/htmledition/information-retrieval-system-evaluation-1.html)提供检索评价依据，不把相关性等同事实真实性。[SQLite FTS5 官方说明](https://www.sqlite.org/fts5.html)说明普通删除标记可保留旧索引条目以及重建机制。

不实现自动事实真伪、一般矛盾识别、任意摘要语义保证、全部历史转述依赖推断或无限规模性能。不承诺擦除外部导出、未登记副本、未知语义转述或 SSD 取证残留。明确擦除保留审计元数据，不能同时承诺保留被要求删除的正文；正常开发和修订则保留既有历史。

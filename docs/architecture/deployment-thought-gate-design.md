# 部署独立思考验收

2026-11-15。用户要求新部署增加一次独立思考，并确认回退到上一已知可用版本时不重复调用模型。

新版本：启动/身份/存储检查 → running但不接普通任务 → 一次真实配置推理器调用 → 结构化输出与nonce核对 → 正常Engine结果接受及持久化 → 主进程核对数据库回执 → admitted门开启普通任务。

验收活动使用原预算和全量正常输入准备链路，单次应用层调用，不重试、不执行工具。宿主写入验收元数据，输出只允许wait且原样返回随机challenge。模型不能将该字段作为普通聊天权限。高维评分保留，验收的自动ask随机替代标为不适用；不推进人格或习惯成长，输入/回复记忆随后归档，原审计保留。

失败包括模型请求失败/超时、输出不合法、未回显本次challenge、提出工具/认知写入、结果未被Engine接受、宿主不能核实当前进程/活动/请求/结果绑定。此时关闭候选、走原检查点回退。上一已知可用版本恢复时不再验收，避免模型服务不可用导致两版同时停止。

开关沿用process-manager配置：verify_thought、thought_timeout（默认180秒）。native路径支持，受保护schema4路径拒绝不合格适配，不绕过现有来源与预算保护。用户停止仍优先。验收过程单列日志和阶段耗时；running不再等于验收通过。

仅做核心临时实例测试：成功、无效输出/禁止动作、真实子进程模型服务失败后回退且仅一次调用。通过后原实例启用并正常更新，实际做一次真实模型验收。

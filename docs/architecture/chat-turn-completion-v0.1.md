# 单轮聊天收尾 V0.1

范围：只补齐普通聊天回复后的活动、目标收尾，不改变行为概率、人格或反馈学习。

普通聊天的输出已经通过校验、接纳并持久化，且模型与最终选择均为 wait、有非空公开回复、没有待执行计划，也不属于任务循环或自主探索时，当前交流目标与活动转为 completed。写入 chat.turn_completed 事件，引用实际请求、结果与目标。完成只表示回复已持久化、可由面板交付，不代表用户已经看到，也不代表外部工作已完成。实例继续运行，下一句话创建新活动，通过原有历史承接。

ask 保持 waiting_input，目标继续 active；工具候选即使被行为策略改为 wait，也不按普通回复完成。审批、工具执行、任务循环与自主探索沿用原有实际结果判定。没有回复、调用失败或结果过期时不完成。收尾与结果接纳处于同一事务，不改写历史记录，不批量关闭旧目标。

验证：隔离实例和替身模型检查连续两轮完成、可继续发消息、重复提交不重复收尾，以及询问/工具任务不被提前完成。

遗留：行为选择与公开回复一致性；普通聊天反馈到策略调整；人格/动机影响记忆检索；习惯、记忆巩固、自主探索和主动维护的启用。人格成长继续遵守既有关闭约定。本次均不实施。

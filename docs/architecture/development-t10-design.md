# T10 记忆巩固与质量详细设计

V0.1；概念基线／待实证；有界工程设计。先设计、再实现、隔离验收，不更新当前运行实例。

## 定位与科学边界

记忆巩固不等于把历史压成唯一真相，遗忘也不等于物理删除。记忆巩固研究讨论稳定与转化；本项目只实现可审计的数据机制，不声称复现神经巩固。[Dudai、Karni、Born，2015](https://pubmed.ncbi.nlm.nih.gov/26447570/)。检索质量使用带人工相关性标签的 Precision/Recall/MRR/nDCG 等指标，而不是“检索到了所以为真”。[Stanford 信息检索教材](https://nlp.stanford.edu/IR-book/html/htmledition/information-retrieval-system-evaluation-1.html)。

## 默认、操作边界与历史

memory-quality 默认关闭，启停要求停止且无活动运行进程。不自动改写现有身份、记忆或历史，不自动迁移所有旧语义依赖。当前实例本轮不部署、不重启。T04 的受控记忆修订流程继续保留。

配置启用后接入已有召回流程、完整独立思考和思考详情；不增加模型调用。直接权限/来源校验作为读取安全基础，不依赖是否启用新排名。

## 巩固：可验证的摘录，保留原文

plan 接受至少两个不同当前记忆 revision 的字符区间 start/end。只在内存取出原文片段，以换行连接，不能提交任意“总结事实”；提案只存来源 ID、区间和内容哈希，不额外拷贝私密片段到事件。commit 需控制者显式批准并重新核对来源当前版本、哈希及读取权限。没有自动采用或自动归档原文。

新摘要记录 extractive-consolidation-v1、来源关系和来源 revision，标为摘录派生而非原始经历或已证实事实。读者权限取全部来源的交集，后续继续动态检查；来源修订、归档、撤权或删除后，旧摘要停止召回，不能继续用旧摘要绕过新权限。需要新巩固提案才能更新，不改写旧摘要快照。

新生成响应若启用本模块，将记录与本次选中记忆和触发输入记忆的保守依赖，以便来源更正或擦除时排除/清理已知派生内容。历史未登记的语义派生不自动猜测。

## 矛盾、更正与遗忘

conflict 显式关联两个当前可读版本与原因、证据，不由字符串差异自动判事实冲突；召回返回有效、当前、双方可读的矛盾标记，不自动选赢家或覆盖旧说法。标注不表示已证明逻辑矛盾。更正继续使用 Memory.revise/T04，原修订保留，默认只召回当前版本。

retain 操作支持 demote（显著度设低）、archive、retract、restore；均须控制者、expected_revision、原因及幂等 key。demote 改排序而不删，archive/retract 不进入默认召回，restore 不能恢复已删除内容或修复失效来源。没有按时间自动删除。摘要来源归档会使摘要暂时不可召回，恢复后仍须版本一致。

Memory.readers 对有来源关系的派生记忆动态取权限交集；新依赖快照记录来源 revision，来源变化即失效。循环或过深依赖拒绝读取，不靠复制一份旧策略维持可见。

## 可重建索引与真实排名

启用后使用独立 SQLite 派生索引 memory-quality-index.sqlite：仅存词/中文双字组的 SHA-256 token、revision、memory ID、行序及内容哈希，不存原文或明文词。哈希不是保密加密，不能宣称防字典推测；索引是可丢弃缓存，不是记忆本体。

Memory.encode/revise/restrict/redact 等写入在同一主库事务追加 source_changed 水位。索引保存构建水位和源事件引用；普通变更仅同步受影响的记忆，配置变化或上次水位因回滚消失时全量重建，因此事务回滚不会使未提交内容长期污染索引。显式 rebuild-index 同样不调用模型。所有候选再查主库当前版本、active 状态、动态来源权限，不能信任缓存的授权。

查询按词/字组匹配加权取最多 2000 个候选，并加入最近 8 条候选；最终沿用现有可解释文字/名字/自述/生成来源评分，显著度因子为 .2+1.6×salience（默认 .5 时系数 1）。过长查询或索引故障退回扫描，并明确记录 fallback。截断必须记录，不能声称此时全量召回无损。首次冷构建和温查询分别观察，不把冷构建成本隐藏。

不直接使用全盘语义向量库或下载模型。索引候选不自动成为事实。私密候选即便命中，也在主库过滤后才可进入思考；后续派发、接收再次校验选中版本、内容哈希及权限。

## 删除与依赖清理

删除复用 Privacy.erase，要求停止并显式指定，验证仅限受管理存储；它会沿 derived_from/summary_of/consolidated_from 清理已知派生、请求/响应制品、指定已注册备份和快照。T10 在清理时撤去派生索引，不能留下旧索引复用。默认保留历史仅针对正常开发与修订；显式擦除是例外，有审计墓碑，不承诺保留被要求删除的正文。

不宣称擦除外部导出、未登记副本、SSD 取证残留或未知语义转述。原文摘要区间不重复保存到提案制品，避免部分摘录游离于依赖之外。

## 质量评估与接口

CLI memory-quality status/enable/disable/plan/preview/commit/conflict/retain/rebuild-index/evaluate/erase。计划/留存/冲突参数可用 JSON 文件；ID、权限和范围需服务端校验。旧部署没有模块时拒绝写入；没有面板启动按钮。

evaluate 使用至少两个不同查询和人工给定 relevant memory IDs，k≤50；用真实 Memory.retrieve 返回结果计算 Precision@k、Recall@k、MRR、nDCG、候选数、索引/回退、耗时和语料量。评估不调用 LLM、不运行工具、不自动采用变更，标注错误不等于系统效果。至少一万条隔离语料测试词法召回、候选预算、权限过滤和索引重建；不外推通用语义能力或无限规模性能。

prepare 冻结 memory_quality 元数据（配置、选中版本哈希、来源与冲突）；派发/接收检查当前来源与权限，不因无关新记忆就全局作废。旧请求不回填当前摘要或冲突信息。面板区分原始、生成、修订和摘录派生。

## 验收与非目标

验证摘录边界/两个来源/显式采用/CAS/来源变更、动态权限与依赖循环、矛盾并列、更正不覆盖、降权/归档/恢复、历史不变、模型输入与来源失效、索引事务回滚/故障/新增修订、万条语料指标、擦除派生与已注册备份/索引、身份及当前实例只读保护，完整回归通过后更新 T10。

本项不实现任意摘要语义保证、自动事实真伪、通用矛盾识别、自动忘却人格或全历史语义依赖推断。工程可检验指标与生物记忆理论分开，长期生命判据仍待后续验收。

## 实现核对补充

preview 是控制者可读的即时摘录预览，只按当前来源计算并返回，不额外持久化片段；采用前可审阅具体结果。提案事件仍只保存 ID、区间和哈希。保留版本的更正、摘要失效不等于删除原历史。

已有 memory_search 是另一份全文索引，普通更新的删除标记可能继续保留旧词条。受管理擦除时重建该全文索引，并进行 secure_delete、压缩和检查点处理，再撤去派生哈希索引；隔离验证检查主数据库与受管理制品中的指定测试片段不再存在。[SQLite FTS5 官方说明](https://www.sqlite.org/fts5.html)。这不是 SSD 或外部副本的取证擦除保证。

源依赖权限读取带有有界深度和复用结果，避免同一依赖图被指数重复遍历。默认新记忆使用活动策略，而不是最近一份用于其他私密记忆的临时访问策略，避免无关记录被错误继承为私密。新派生来源快照不覆盖既有未知语义关系；不能宣称已追踪全部历史转述。

规模证据分别记录一次性语料装载、冷构建、温查询、相同排名规则的扫描参考与单条增量同步。候选截断单独验证并明确标记；一万条合成语料的少量精确词查询不代表真实世界语义泛化。


删除还按 thought_request_inputs 和触发输入的已知关联查找请求及全部响应，包含 stale/未采用响应；不要求响应逐字复述原文才清理。对 cognition_evidence_links 明确关联的认知修订正文及当前 literal 也追加擦除效果并清理，不把来源撤销后隐藏的文本仍当作已擦除。该传播仍限已登记关联，不推断未知语义转述或删除全部人物身份。

## 1 问题、方案与裁决原则

要决定的不是“哪个输入保证学到东西”，而是**什么观察值得进入有界学习检查、什么条件下允许处理，以及结果怎样如实结束**。进入学习不意味着认知已接纳，更不意味着有正收益。

| 方案 | 主要问题 | 裁决 |
| --- | --- | --- |
| 每次工具返回都启动模型学习 | 大量重复／无关处理，失败和缺失也容易被加工为假知识 | 不采用 |
| 只有成功、新内容或预期不符才学习 | 排除了有信息的失败、预期确认和复习；没有预期时也可能错过新认识 | 不采用 |
| 原记录保留，先检查控制／资格与重复，再按学习用途分流、有限处理 | 需要明确等待和退出规则，但符合Q01/Q02职责 | 采用 |

本轮不决定人格偏好或意图选择公式，不让触发规则代替“值得”的个体选择。只明确准入、学习用途、调度条件和边界；处理顺序可由获授权的现有目标／调度策略决定，不声称已实现人格驱动的自主意图分布。

### 因研究而明确的三条限制

- 新颖性、意外和矛盾是线索，不是充分条件；来源无效的惊人内容不能绕过边界。
- 与预期相符也可能支持条件确认／校准；没有预先预测时可以检查内容，改善幅度仍可unknown。
- **去重防的是重复派发和证据膨胀，不是取消复习。** 复习与独立新观察分开登记，效果另测。

## 3 与现有实现的核对

`self_feedback.observe`已核对原result、receipt、evidence及活动关联，按原result生成暴露身份；复用回执仍引用原证据，记录机会后通过M14→M03保存unknown影子经验。它受探索绑定和开关限制，不等于通用工具学习分流器。

`exploration_evidence`已有资源签名、可读来源、回执复用与变化后重开机制；资源元数据只判断复用是否还适用，不制造新读取证据。`dispatch_gate`及既有控制面用于协调停止与派发；这些技术不能替代本轮需要的学习目的、重复分类及等待条件。

现有工具执行成功、动作核验通过与认知结论可信仍是不同结果。本轮不改现有代码，不把下面设计状态冒称为已存在的数据库状态或API。

## 4 决策顺序与六种处理结果

原始工具结果按M13/M17原协议保存，不以学习是否准入为条件；M04可按原性质编码经历。之后的学习请求依次检查：

1. **控制与资格**：用户停止／锁、实例、请求归属、授权、来源完整性及可读性。控制限制优先于价值或重复命中；不能向无权者返回旧处理结果中的私密内容。
2. **同一次工作是否已经登记／在途／完成**：能复用就关联原结果，不能重复派发。旧结果当前不可读／失效时按当前条件处理，不盲目返回缓存。
3. **学习用途与变化**：是否属于本节第5部分的候选用途；原始观察、已学内容、方法效果和复习分别判断。
4. **前置条件与额度**：内容是否齐备、目标／版本是否可定位，是否有有效配置、预算、期限及允许的处理方法。
5. **有限执行及交接**：满足条件才由协调器派发M14处理；处理后可以有提案、无变更结论或证据不足说明，不承诺必有新知识。解释过程交Q04，接纳仍由M03负责。

| 处理结果（概念名称） | 含义 | 后续边界 |
| --- | --- | --- |
| 进入有界处理 | 有明确用途、合法材料及处理条件 | 不是认知接纳或收益合格；实际调用须逐次重检 |
| 等待条件 | 存在具体、可解除的缺项 | 指明等待什么、谁可解除、期限／退出条件；不靠无变化轮询触发模型 |
| 复用／本次不再处理 | 同一工作已有结果，或没有新的处理必要 | 关联原记录和原因，不记为新学习成功；仍保留原观察 |
| 拒绝本请求 | 身份、来源、权限、用途或处理方式不符合约定 | 不自动重试；条件确实改变时另发可追溯请求，不能静默复活 |
| 停止／中断本次工作 | 用户停止、撤权、终态、期限或本次额度耗尽等 | 禁止后续派发，保留实际进度；恢复不是清锁或刷新额度 |
| 评估结束 | 已完成此次有界检查，可能形成提案、无变更或保留未知 | 交接状态单独记录，不能把“评估结束”当作整个闭环已完成 |

请求被拒绝不等于断言其内容为假；等待不等于认知相信；不再处理不等于材料无价值；中断不等于外部工具没发生过作用。

## 5 哪些工具观察进入学习候选

| 情况 | 分流裁决 | 不允许推断的东西 |
| --- | --- | --- |
| 新的、可解释的观察填补已知缺项，或补充已授权探索范围 | 条件满足时进入内容学习检查；不要求先算出正收益 | 不是每个新字节都值得调用模型，不自行扩大探索／工具范围 |
| 与已有认识、其他来源或事前预期冲突 | 进入差异检查，保留各方对象／时间／来源；必要时等待补证 | “新记录一定对”“旧认识一定错”“意外越大越真” |
| 与事前预期一致，但提供了有效的新观测或已登记确认用途 | 可进入确认／校准检查；无新证据及无新用途时复用 | 符合预期就证明普遍规律；相关观察自动当独立样本 |
| 工具失败、错误、部分成功或结果未知 | 只基于实际可读信息检查失败条件／方法局限；未知外部效果由M13核验 | 错误消息代表成功内容；学习模块可为查明结果盲目重做有副作用工具 |
| 来源变更、更正、旧经验失效或已登记认识被反驳 | 首先限制不合格使用，再按变更进入重评 | 后台学习尚未完成就继续用失效内容；把更正抹成没有历史 |
| 新观察无事前预测 | 可检查内容，记录“当时无预测”，效果测量不足保持unknown | 事后补写“我原先就预计如此”，或把未知误差填0 |
| 现有材料足以支持一个有限结论，但缺独立效果评测 | 可以进入内容提案流程；效果评价另作未完成／unknown | 为等收益评测无限阻塞原始记录与所有有范围内容 |
| 只有传输确认、空白、格式不可解或关键内容缺失 | 能确认的状态可记经历；学习内容需要缺项时等待，无法合理补齐则结束并保留未知 | 从“读取成功”推导未返回的值；反复调用模型猜正文 |
| 与当前任务无关，且没有获准的探索／维护用途 | 本次不处理，保留原性质记录；之后有新用途可重评 | 自动丢掉历史，或用泛称“好奇”无限启动新工作 |
| 有目的的复习、提取练习或经版本变化触发的再加工 | 进入单独、获授权且有预算的复习／再加工工作 | 复习等于新世界观察；多看几遍即产生多个独立收益样本 |

这里界定候选用途，不决定排序的最终概率。人格、意图或价值可以影响已授权范围内的关注及优先级，但不能改变证据资格、停止和权限条件；本轮也不新接入实际选择。

## 6 何时等待、拒绝、停止：可解除条件与退出

| 条件 | 处理 | 解除／退出规则 |
| --- | --- | --- |
| 已知原工具结果尚未最终到达，或部分内容有明确待交付项 | 等待原结果／必要补项；处理可用部分时标明范围 | 由M13对应结果或明确补项解除；达到活动期限即结束本次检查，保留未知，不重做原工具 |
| 对象、来源定位或时间关系暂时无法确认 | 有具体补证路径则等待，否则评估结束为不足 | 补证须在允许接口与预算内；没有能力／无回应时不能永久轮询 |
| 目标认知基线已变化 | 等待重新核对当前基线，或结束本次、另立有依据的重评 | 新基线关系明确后才能处理；旧提案不能无声覆盖当前版本 |
| 只是调度并发／临时负载，无其他阻断 | 可等待既有调度机会 | 保留原预算与期限；资源恢复才重检，不为等待本身调用模型 |
| 本次预算已耗尽、尝试上限到达或期限已过 | 停止本次工作 | 不靠新建学习请求、休眠或重启刷新额度；新增额度需要既有有权流程明确分配 |
| 用户停止、正式实例锁定、学习开关禁用或原活动取消／终态不允许继续 | 停止／禁止派发 | 仅按既有显式恢复／重新授权规则处理；条件变化后重新核对，不能自动解除锁或撤销用户停止 |
| 来源暂时不可访问但访问权仍有效，且有可界定恢复条件 | 可等待来源恢复 | 等待原因和有效期明确；可读性／版本变化后重新判断，不能仅凭旧缓存继续 |
| 从开始就无权读取、跨实例错误归属、来源引用伪造／完整性不符 | 拒绝本请求 | 合法修正／新授权后另立可追溯请求；不能作为自动网络重试理由 |
| 处理中来源撤权、删除或检测到完整性问题 | 立即阻断受影响后续使用与派发，停止该工作 | 清理／审计按Q02及既有隐私协议；不能仅改成“等待”后继续读旧数据 |
| 处理方式要求未支持工具、越权、无限模型循环，或无可界定用途 | 拒绝该处理请求；原观察仍保留原性质 | 方法／用途经明确修改后可重新申请；本轮不新增能力 |
| 原调用在途且用户停止，随后返回结果 | 可按原执行协议保存真实回执／审计；后续学习派发仍停止 | 保存晚到证据不代表恢复执行许可；模型在途结果的业务接纳还须服从既有接受门控 |
| 学习有提案，但M03接纳或M04表示尚未完成 | 按Q02记录具体交接结果 | 不能启动第二次学习来伪装补齐，不在Q03选择补偿事务技术 |

每个等待项必须有有限期限或明确退出条件；重检不自动意味着唤醒实例。复查只由既有许可下的条件变化、结果到达或已登记调度点触发。没有新信息、补证路径或剩余额度时，以不足／无变更／中断结束本次工作是合法结果，不等于学习失败或负收益。

## 7 重复材料：分开四种身份

下列是概念身份，具体字段、哈希和键格式留Q05／Q07；不能只用字符串或文件内容摘要判断全部重复。

1. **交付／调用身份**：是不是同一次工具结果或同一次请求的重复通知。结果晚到、投递重试、重放不能制造第二次外部观察。
2. **证据出处与观察身份**：何种对象、来源、方法、观察时间／版本及原结果。回执复用、摘要和召回表示仍沿原来源，不成为独立证据。
3. **内容与语义范围**：内容是否相同，是否描述同一个时间、对象及命题。字节相同不保证语义范围相同；表达不同也可能是同一内容。
4. **处理身份**：针对哪个内容／经验目标、基线、用途及处理方法版本做的哪次工作。方法或基线确变可构成再加工；不能伪装成新证据或无限刷新预算。

| 重复情境 | 必须怎样处理 |
| --- | --- |
| 同一结果重复交付、同一工作已在途 | 关联已有工作／状态，不新增模型调用或并发副本；先重检访问权限 |
| 同一工作已有完成结果，条件与用途未变 | 复用结果；无变更也可复用，不能只复用“成功学习”而反复重跑无收益材料 |
| 旧工作出现派发已发送、结果未核对 | 先核对原调用状态，不自动重发；无法核对则保留未知／停止，不能假定没有计算或没有外部效果 |
| 不同文件名／语言／摘要重复同一原证据 | 关联同一出处或标相关性；不因副本多就升高独立证据数 |
| 同一字节在新的真实观测时间出现 | 原观察时点可单独记录；是否新学习用途另判。可以支持“该时点仍如此”的有限确认，不能自动算独立支持或新内容收益 |
| 同一数值来自不同对象／条件 | 按各自语义范围处理，不因内容哈希相同而误删候选 |
| 语义是否重复不确定 | 记录未判定／相关性未知；有必要且有预算才做比较，不伪造“新颖”或“独立”标记 |
| 内容没变，但解释方法、基线或适用问题确有实质变化 | 允许显式再加工，保留旧结果及变更理由，受原／明确分配的总预算约束 |
| 认知已接纳但记忆表示失败，需要重建 | 沿Q02/Q07重建同一版本，不重新算一次学习／接纳 |
| 有授权的间隔复习／提取练习 | 单独记录练习目的、次数及结果；不新增原世界证据。若测改善，使用未被练习污染的合格检查并单独报保持／迁移 |

统计必须区分交付次数、实际观察次数、来源关系、处理次数、复习次数和有效学习样本。独立性无法证明就保持未知；没有去重规则能仅凭换一个ID把相关材料变独立。

## 8 概念转换与责任

本节不是数据库枚举或最终运行状态机：

| 起点与事件 | 转换／结果 | 责任 |
| --- | --- | --- |
| 原观察到达 | 原协议保存→学习分流检查 | M13/M17保存；协调器关联；M14负责学习用途检查 |
| 检查发现本次禁止执行 | 停止／拒绝，不派发 | 控制面／M12给约束，协调器执行，M14留本域原因 |
| 合法但有明确缺项 | 等待条件 | M14说明缺项，源／目标所有者提供条件，协调器管理期限 |
| 同次处理已有结果／在途 | 复用／关联，不新增派发 | M14核对处理身份，其他所有者提供当前有效状态 |
| 条件齐备且许可有效 | 可处理→有限执行 | 协调器逐次重检／计预算，M14组织处理 |
| 等待条件真正改变 | 重新检查资格、重复、版本及预算 | 不是直接跳入模型调用，不改变所有者接纳权 |
| 执行结束 | 有提案／无变更／不足说明→记录本次评估结果 | M14写评估；有提案才按Q02交M03接纳 |
| 中途阻断或到达上限 | 停止本次，保留已发生进度 | 不删除原回执、不自动重做、不刷新预算 |

来源失效对既有经验及已准备输入的传播继续由Q09细化；Q03已经确定“先阻断不合格继续使用”，不等学习重评完成。学习任务结束与认知接纳／表示生成的完成状态分开。

# 明确项目任务的连续执行修复

2026-11-15。用户已同意以下两项改变。

1. 用户/账户发起的已授权项目动作，在参数完整、当前项目授权匹配且范围校验通过时，保留高维特征、评分和审计，将自动生成的随机 ask/wait 标为不适用。模型自身提出的澄清仍可停止任务。自主探索、未授权动作、普通聊天维持原概率机制，执行器仍独立核对权限。
2. project_task 不再受额外三轮限制；沿用原活动 token=16000、工具=8、总尝试=8、时间=600秒及活动 deadline。每次继续前核对剩余额度，不增加任何上限。单次思考最多预留4096；余额在1024—4095时仅使用余额，低于1024时暂停并保存清晰进度，不再发起模型调用。最终回复也需要消耗原预算，不豁免。

文件读回核对继续由 worker 在写入后完成；每次思考仍完整独立调用。通过真实 worker 的四次思考（读取、修改、检查、最终回复）验证取消三轮限制，验证极端随机采样不会打断明确动作，以及预算耗尽时停止。然后部署原实例，以专用文件进行真实模型小任务验证。

协议预先规定：真实经过至少86400秒、至少100周期、多次进程续接、至少两次核验修复、检查点间隔不超过300秒。它是项目暂定工程阈值，不是科学界生命定义。

本轮只运行短时实验，没有启动后台24小时任务。长期结果缺失，T13保留validating，passed=false；工程工具和短时实验可以记录engineering_passed=true。真实LLM、开放环境、任意复制/迁移的身份语义另列未验证，不能凭固定回复或自我陈述补齐。

运行与复验步骤见 `docs/operations/development-t13.md`。后续应在独立实验目录完成冻结协议的长期观察，复核证据后再决定T13的范围性结论；不借此更新或唤醒当前实例。

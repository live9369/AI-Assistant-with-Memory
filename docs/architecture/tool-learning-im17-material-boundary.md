## 六包及访问职责

以下为后续执行器必须落实的访问规范，不宣称当前JSON文件已经具有保密隔离或权限系统。DEV公开标签允许开发者阅读，但仍不得注入待测学习/查询输入。正式包只能在IM20由合格独立角色另行制作。

| 材料包 | 内容与访问者 | 执行前要求 |
| --- | --- | --- |
| learning-input | 只含观察、合法基线、来源权限/时点、解析视图/工具版本；学习链可读 | 不含未来查询、答案、相关集合、评分标签 |
| query-input | 单条查询、主体/接收者、用途、目标范围与k=5；该次请求可读 | 不含学习外的答案摘要、其他组输出或未来查询 |
| controller-truth | DEV为明确公开开发标签；正式真值仅控制者/指定独立作者及评审可读 | 与运行包分目录/身份，运行进程无读取能力，不能只靠“不读取”的提示 |
| fault-plan | 具体提交/回调窗、崩溃点、变化、终点及允许清理范围；外部评测器可读 | 隔离的合成对象、真实边界探针、有限时间/磁盘，不含正式实例路径 |
| blind-review | 匿名输出、判断必需证据/限制；独立双评审及裁决者可读 | 去组别/模型/执行者标签；盲化映射另存；未就位不得声称正式盲评 |
| run-manifest | 文件摘要、协议/代码/配置/提示/模型版本、种子、预算、时钟及角色；审计者可读 | 不将秘密标签混入模型可见manifest；源码/包/夹具指纹与执行输入对应 |

正式运行目录建议独立控制者所有、最小读取角色、私密标签文件0600/目录0700；此为部署要求，不是当前材料已实现OS访问控制的证明。全部模型可见材料必须经显式投影，不能把本开发JSON整体喂给模型。摘要只能核对完整性，不赋予材料权威性或来源许可。删除题只针对未来新建临时合成对象；无范围授权不得做真实擦除或外部供应方操作。

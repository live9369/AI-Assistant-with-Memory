# 前端排版整理 V0.2

目标：在保留浅色工作台和全部管理功能的前提下，减少层层卡片、重复提示和空白，让聊天、列表、配置各有清晰的阅读顺序。

视觉基线：背景 #F6F7F8，内容白色 #FFFFFF，正文 #243139，辅助文字 #637078，边线 #E3E7E9，操作色 #176657。使用系统中文字体，正文14—15px，页面标题23px，区块标题14px，辅助信息11—12px。数字使用等宽数字排列。导航208px，内容最大1280px，内容左对齐，统一16/20/24px间距。按钮与输入控件统一基线，移动端保留可点按尺寸。

布局：左侧窄导航，顶部状态与通用操作；正文为单一内容区。聊天采用阅读栏和独立输入区；实例配置采用一条运行工具栏、组导航、单张编辑表单；指标合为一条统计区；表格和执行记录使用分隔行。只有错误、锁定和需要注意的条件使用显著提示。说明和其他入口保留在可展开区域。

设计自查：不采用营销页的 Hero / CTA 结构，不新增图表或装饰。保留当前青绿操作色，避免让每一块内容都成为同样醒目的卡片。清理旧样式叠加，而非继续追加覆盖规则。

变更范围仅为静态 HTML、CSS、页面呈现代码。不改变模型调用、账户权限、运行进程或数据；面板静态资源读取当前源码，无须重启正式实例。

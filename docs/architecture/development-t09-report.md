# T09 人物与关系认知：实现与隔离验收报告

V0.1；2026-11-08；**有界工程验收完成／未更新当前运行实例**。科学状态仍为概念基线／待实证。

## 完成结果

已先补详细设计，再实现受控人物登记、带来源和范围的别名、关系称谓、分域条件信任、证据修复和失效记录，接入真实 prepare、T03 结构化认知及 T06 行为概率。T09 标记 complete，下一项 T10 尚未开始。

功能默认关闭。姓名相同不合并，唯一姓名也不自动绑定陈述；只有经审阅的明确别名且无歧义，才用已有本地实体引用。关系称谓、身份候选、条件信任与操作权限分开，不把“父亲”或高信任变成控制者。

## 逐项实现与验证

| 部分 | 实现与隔离结果 |
| --- | --- |
| 独立人物登记 | 同名生成独立 actor/entity，保留两个记录，未执行任何实体合并 |
| 规范化与歧义 | Unicode/大小写仅辅助检索；相同规范名仍保留多个候选，不按最后写入覆盖 |
| 范围别名 | 全局冲突保留 ambiguous，经审阅的具体 scope 可缩小候选；仍非现实身份认证 |
| 来源与撤销 | 至少两个来源支持别名/称谓；同 origin 或无 origin 同制品包装不重复计数；失效追加记录，旧行保留 |
| 身份权限 | 保护 controller、self_actor、identity_anchors；新人物 unverified；角色和别名不生成 grant |
| 真实 T03 路径 | 明确 scoped alias 才绑定已有实体；未知、歧义、仅姓名唯一均使用活动局部未确认对象；陈述仍为 held 候选 |
| 分域条件信任 | actor/domain/dimension/condition 分开计数；保存 α/β、来源和方法；无有效观察标缺失 |
| 信任来源去重 | 同格子相同来源不能重复刷，失效后也不能重新包装计数；幂等 key 与全局代次 CAS |
| 关系修复 | 最近负观察后至少两条新正来源，显式确认；旧负观察保留，不重置为满信任 |
| 分歧隔离 | 别的格子未解决时整体继续 disputed；新负观察或失效修复支持可重开分歧；ended/dormant 不擅自激活 |
| 真实 T06 接入 | 只取实际触发 actor 的 behavior/reliability，优先最具体匹配条件；不把被提及人物当操作者，不跨域替代 |
| 输入与来源一致性 | 登记/别名/反馈变化、来源擦除或直接记忆权限撤回后，旧快照拒绝派发或采用 |
| 兼容与持久化 | 默认关闭保留原输入；旧标量不伪装成新频率；关闭后管理 assessment 不泄漏回旧路径；重开后图谱、身份、记忆和旧快照保留 |
| 可观察性 | 思考详情显示 relationships 候选、登记/别名来源、条件信任、分歧及冻结代次 |

主要实现为 `digital_life/application/people_relations.py`，接入 Engine、CognitiveUpdates、BehaviorPolicy 和 CLI。使用已有实体、别名、社会 actor、关系、信任依据与关系维度表，并以不可变事件保存审阅、修复和失效；无 SQL 迁移。旧人物、记忆、信念和标量估计不删除，也不自动改归属。

## 隔离人物与修复轨迹

全新临时实例登记两名“陈明”，全局仍有两个候选；给其中一名明确绑定 user scope 的同名别名后，该 scope 有一个本地候选，但两个实体均保留，identity_verified 仍为 false。

以下使用控制者标注的实际接收记录，展示 behavior/reliability 格子的工程投影：

| 阶段 | 估计 | 观察数 | 本格未解决 | 整体状态 |
| --- | --- | --- | --- | --- |
| 无有效观察 | 缺失 | 0 | - | active |
| 一条负观察 | 0.333 | 1 | 是 | disputed |
| 第一条新正观察 | 0.500 | 2 | 是 | disputed |
| 第二条新正观察，尚未确认修复 | 0.600 | 3 | 是 | disputed |
| 显式审阅修复后 | 0.600 | 3 | 否 | active |
| 另一个领域出现分歧后 | 0.600 | 3 | 否 | disputed |

显式修复前后数值都为 .6，因为旧负样本仍在 β=2 中；修复只是对本格分歧作有来源的审阅，不抹历史。另一个领域出现负观察后，整体重新 disputed，但 behavior/reliability 仍为 .6，没有把跨域分歧揉成一个总信任值。

没有有效观察时关系默认 active 仅表示没有已记录未解决分歧，不表示已建立高信任。整个隔离轨迹没有创建 grant，身份配置不变。T06 的概率影响另由专项受控对照验证；这些概率不是心理测量或成功率。

数据见 `outputs/acceptance/t09-relationship-trace.json`。不包含实际模型供应商调用或正式实例唤醒。

## 科学定位与边界

[Fellegi 与 Sunter，1969](https://www.tandfonline.com/doi/abs/10.1080/01621459.1969.10501049)提供区分匹配与不确定匹配的参考；[Mayer、Davis 与 Schoorman，1995](https://journals.aom.org/doi/abs/10.5465/amr.1995.9508080335)为分维度、考虑情境的信任建模提供参考。本实现没有复现完整统计实体解析，也未校准为人的心理信任模型。

α/β 来自控制者标注，来源数不证明统计独立、事实真实或人格可信。只有明确范围与证据的本地引用，没有现实身份认证、任意人名识别/指代消解、欺骗检测或法律亲属认定。全局代次采取保守一致性，当前可能因无关人物更新拒绝旧请求。字面提及最多 20 项，不宣称大规模知识图谱性能已验证。

没有自动迁移全部旧人物和信任；旧记忆仍可召回，未登记也不等于系统从未经历过该人物。T10 将继续记忆巩固与质量。

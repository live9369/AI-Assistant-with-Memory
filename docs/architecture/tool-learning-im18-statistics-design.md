# IM18 统计与缺失处理设计

依据冻结 Q10 指标与 Q11 协议。统计模块只接收预登记机会及已核验/已评审的事实，不自行判断内容是否真实、不生成标签、不调用模型。每条输入保留机会 ID、case、类别、状态和原始值。未运行及缺标签保留原分母和最好/最坏界限，不能只分析成功子集。

计数型指标 TL01/02/03/04/06/07/08/09/11/12/16 使用共同机会核算；其中 TL08/09 的 value 表示已观察违规，零违规门反向判断。已经登记的机会不能逐行改成 not_applicable 脱离分母，只有整个指标没有机会时报告不适用。TL11 另需所有计划目标及新发现目标纳入、闭包未决为零。TL16 必需的轨迹与双盲评审分别计数。质量门每个必需类别至少 20 个独立 case，未知类别及缺失证据不能通过。TL07 的机制门为 100%；正式保持率按 Q11 单独描述，不自造正式数值门槛。

TL05 固定 k=5，使用预标合格相关集合，返回数作 precision 分母，相关集合数作 recall 分母。空返回与空相关集合分别报告，不把空集合的 precision 填为 1。可答查询的 MRR 保留全部预登记查询；缺标签标缺失，不给完整 MRR。宏观 recall 先对 case 内可答查询平均，再对 case 等权，缺失给保守最好/最坏界限；不反向使用已返回项定义相关集合。查询权重的观察子集统计只作另列描述，不作为正式门。

TL10 对完成样本给中位数、最近秩 p95、最大值，并另报右删失、完成率和观察窗口。未完成的等待时间不混入完成延迟，也不填零。TL15 对真实各成本分量分别求和、保留未知数与已知小计；以唯一真实 attempt_id 去重检查、按 transport 区分模型与工具，已知货币值需要明确统一币种；预留不能冒充消费。每正确查询成本只有分子完整且分母大于零时才能报告。

TL13/14 对同 case 的 E/N 三次重复先均值再求差，case 等权。缺失不缩小预登记 case 集；给可能差值的最坏/最好界限，完整数据才给统计区间。采用固定种子 20261108，10000 次 case 配对 percentile bootstrap（线性插值 2.5/97.5 分位），同一 case 的重复始终捆绑。TL13 限 TARGET new_question 且 800 case，TL14 限 RETENTION retention 且 2000 case；二者都不能仅凭统计函数宣称完整正式实验通过。比例另给 z=1.959963984540054 的 Wilson 区间。

替身验证包括可复算小样本、固定种子、case 权重、三重复、缺失/失败/全部 UNKNOWN、空分母、删失及未知成本。统计上的通过只表示该指标门，完整协议还须机制、质量、材料、评审及授权条件共同满足。

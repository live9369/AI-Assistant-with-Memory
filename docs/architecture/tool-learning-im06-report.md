## 结果

F1遵循实例门禁先于主库事务。合法变化同事务保存change、Scope代次、独立原因active屏障、九域pending传播义务及已发现输入资格失效、幂等命令与结果。重复事件不增加代次；同键异义及旧epoch拒绝；一种原因不会解除其他屏障。

后台扫描或传播计划未齐，不取消合法根屏障：保留unknown/partial覆盖及待扫描义务，不报传播或清理完成。节点和实际边/输入/屏障扫描均有限；F1超限保留根保护，资格门超限拒绝。经明确管理权威授权的保护性F1可在停止/唤醒锁下写入，不解除锁；普通回调仍拒绝停止状态。

依赖登记核实例、类型、实际修订、用途、field_path与持久元数据；输入只能绑定合格read依赖。支持、读取与delete-only路径分别处理，不把删除依赖当作普通内容支持。当前资格检查遍历上游及同来源全部适用屏障，换Scope哈希不能绕过旧屏障；未知适用范围保守阻断，明确不适用须可信核验。

回调使用固定输入快照，最终检查实际请求、活动和全部登记输入，完成只读事务后进入确定性本地函数，并持门禁至返回。F1先提交则后续入口被拒绝；回调先进入则竞争F1等待退出；同线程重入保留已经在途的事实，返回后的使用再次核验。预留、prepared或sent不是实际回调入口，也不证明供应方已经收到。

## 已实现与逐项验证

| 项目 | 结果 |
| --- | --- |
| 情境特异 | source 精确匹配与 task_contains 字面线索；不同来源或不匹配任务没有贡献 |
| 形成门槛 | 至少 3 个不同活动的正反馈与有效倾向门槛；无反馈反复执行仍不自动成长 |
| 真实来源 | 接受的 wait/ask 决策、成功且 receipt 核验 pass 的工具结果可追溯到请求、实际候选和机会 |
| 意图与未知区分 | 待审批工具、失败或未知结果不伪装成已完成行为，也不自动惩罚 |
| 记录与因果边界 | action_taken 仅对核实且匹配的行为更新，control_mode 保持 unknown，不把匹配当作习惯因果证据 |
| 习惯消退 | 获得痕迹 A 保留，抑制痕迹 I 上升，使表达降低并进入 extinct；不是删除历史 |
| 重新获得 | 新的真实经历及正反馈可由 extinct 回到 learning，再满足条件进入 active |
| 立即抑制 | inhibit 去掉指定联系建议，保留痕迹；抑制期间拒绝学习，恢复需显式 resume |
| 真实概率联动 | active 联系增强 T06 匹配候选概率，未形成/抑制/消退不进入行动建议；它们只保留审计快照 |
| 权限与审批 | 强习惯不能选入权限排除的候选；合法工具仍需审批；抑制习惯不禁止用户明确要求相同动作 |
| 幂等与 CAS | 重放不重复更新，过期 revision 拒绝；同活动多轮不能重复消费来源 |
| 输入一致性 | 抑制、反馈或配置变化后，带旧影响的请求拒绝派发或采用，不改写历史输入 |
| 来源擦除 | 请求或工具 receipt 撤去后，相关反馈使用被阻断 |
| 补偿 | 仅最近反馈、当前 revision 可回退，要求两个不同来源；追加事件且保留来源消费，拒绝覆盖后来控制 |
| 缓存与旧版 | 原 Habits.update 不能修改已登记联系；投影和缓存偏离被检测；关闭后不回落旧路径泄漏强度 |
| 持久化与可见性 | 重开后身份、记忆、痕迹、来源和旧请求保留，外键无错误；面板显示原始习惯快照与 revision |

主要实现为 `digital_life/application/habit_learning.py`，接入 Habits、Engine、T06 BehaviorPolicy、CLI 与 ThoughtInspection。复用现有习惯、线索、联系、机会和触发表；反馈与补偿完整存事件，不为 wait/ask 伪造工具结果外键，无 SQL 迁移。

## 数值隔离轨迹

全新临时实例，以可控推理替身的实际接受决策及控制者反馈驱动。获得痕迹 A 与抑制痕迹 I 分开保存；有效倾向为 A×(1-I)，仅 active 状态表达。以下概率是当前工程策略的选择概率，不是成功率或心理测量。

| 阶段 | 状态 | A | I | 表达强度 | 匹配反应概率 |
| --- | --- | --- | --- | --- | --- |
| 初始登记 | learning | 0.000 | 0.000 | 0.000 | 89.50% |
| 三个不同活动正反馈后 | active | 0.300 | 0.000 | 0.300 | 92.90% |
| 显式抑制 | inhibited | 0.300 | 0.000 | 0.000 | 89.50% |
| 显式恢复 | active | 0.300 | 0.000 | 0.300 | 92.90% |
| 九次明确非强化后 | extinct | 0.300 | 0.920 | 0.000 | 89.50% |
| 六次新正反馈后 | active | 0.734 | 0.489 | 0.375 | 93.58% |

此例模型本来就在建议该反应，因此抑制后仍可选择它；抑制去掉的是习惯加分，不是禁止动作。九次非强化之后 A 仍为 .3，旧获得痕迹与 20 条反馈/控制变更记录保留；新正反馈可重新获得表达。三次、九次、六次是本工程示例，不是人的固定习惯周期。

数据见 `outputs/acceptance/t08-habit-trace.json`。没有实际模型供应商调用或正式实例唤醒。

## 科学定位与明确边界

[Wood 与 Rünger，2016](https://dornsife.usc.edu/wendy-wood/wp-content/uploads/sites/183/2023/10/wood.runger.2016.pdf)提供情境与重复反应的理论参考；[Bouton，2004](https://pubmed.ncbi.nlm.nih.gov/15466298/)提示消退表现不等于原学习被彻底删除。A/I 是本项目工程类比，常数、门槛和短期轨迹未通过心理自动性或长期生物消退实证。

本版管理显式登记、字面线索的联系，未自动迁移全部旧习惯，也不实现通用语义线索发现、自动奖励判断或全部复燃机制。未登记旧习惯保留兼容路径，inhibited/extinct 不再提供建议。身份、人格与记忆不因习惯状态改变而被重建。T09 将继续人物与关系认知。

# T08 习惯形成与消退详细设计

V0.1；概念基线／待实证；有界工程设计。先设计、后实现、隔离验收；不更新当前运行实例。

## 定位与科学边界

习惯是情境线索与反应之间相对稳定的联系，不能只用某次行为成功来证明。重复情境中的反应与习惯形成有关；消退研究提示，表现减弱不必等于原学习被删除。[Wood 与 Rünger，2016](https://dornsife.usc.edu/wendy-wood/wp-content/uploads/sites/183/2023/10/wood.runger.2016.pdf)；[Bouton，2004](https://pubmed.ncbi.nlm.nih.gov/15466298/)。以下获得痕迹、抑制痕迹和更新常数是工程类比，不宣称复现生物机制或测出自动性。

本项区分：反复经验形成联系；情境决定是否有机会；控制者可立即抑制；反馈可增强或消退；消退保留历史并允许后续重新获得表达。不改变身份、记忆、人格档案或已有权限规则。

## 有界输入与默认模式

默认关闭。控制者在停止、无活动进程时 enable/disable。enroll 显式登记一个完整行动模板和线索；第一版线索为 source 精确匹配加 task_contains 非空子串，字段有白名单，禁止任意代码和任意规则解释。source 沿用活动实际输入来源，不把全部活动误当 user。内部 V2 exploration 不纳入本模块。

不自动从单次 LLM 建议发现“新习惯”，也不注入额外工具候选。新习惯只增强 T06 已有且完全匹配的候选；仍由 T06 采样，后续审批与执行检查独立。情境不匹配时没有贡献。人工抑制的是习惯倾向，不是禁止控制者以后明确要求相同动作。

旧版未登记的 habit 保留兼容路径；inhibited/extinct 旧习惯不再输出建议。T08 管理的习惯始终经过本模块投影：关闭时不输出其建议，不能落回旧路径泄漏强度；原 Habits.update 不允许绕过本模块修改已登记联系。

## 量化与生命周期

保存获得痕迹 A∈[0,1]（复用 habit_associations.strength）和抑制痕迹 I∈[0,1]（版本化事件及 uncertainty_json），有效倾向 E=A·(1-I)。历史不删除。

初始 A=I=0，state=learning。正反馈：A增加 min(.1,.15·(1-A))，I乘 .9；负反馈：A不减，I增加 min(.2,.25·(1-I))。这是有界工程参数，不是人的固定学习率。至少 3 个不同活动的正反馈且 E≥.3 才 active；仅 active 习惯把 E 传给 T06，learning 的建议强度为零。

active 在 E<.15 时退回 learning；至少 3 个不同活动的负反馈且 E≤.05 时 extinct。正反馈可使 extinct 回到 learning，再达到形成门槛才 active。消退不是忘光 A；无新机会或未使用的时间本身不自动当负反馈。没有后台按时间删习惯，也不声称模拟了复燃全部机制。

inhibit 立即将状态设为 inhibited，E 的表达值为零，保留 A、I 和证据；resume 按当前痕迹和门槛回到 active/learning/extinct。抑制期间拒绝学习反馈；不把停止学习伪装成惩罚，也不擅自恢复。

## 来源、机会与反馈

prepare 只为匹配情境的登记联系记录 habit_opportunities，关联当次请求快照中的联系 revision、配置代次、原始 A/I、状态和表达强度。重复 prepare 返回原请求，不重建历史。

实际接受的 wait/ask 可以成为观测；工具只在执行成功且 receipt verification=pass 后成为观测。待审批意图、失败和未知效果不是已完成的反应，不能当自动负反馈。所有观测绑定原请求、实际选中候选、决策、机会与结果；V2 专用探索保持隔离。

观测保存 matched：实际行动是否完全匹配模板。正反馈只允许 matched=true；另选行动时，可由控制者明确给负反馈来表达本情境不再强化旧反应。系统不从“没选它”自动推出它不好。action_taken 只在已核实且匹配时更新，control_mode 保持 unknown，不把匹配证明为习惯导致。

反馈必须由控制者显式给 0/1、原因、幂等 key 和 expected_revision。每联系每活动只消费一次，即使活动有多轮或换证据包装也不能重复刷强度。反馈前重查原请求、响应、触发输入与工具 receipt 的有效性，擦除/撤销来源阻断使用。更新、来源消费和缓存投影在同一事务写入。

## 运行主流程与一致性

prepare 冻结 habit_learning 配置与所有匹配联系 revision；有效强度进入 habit_suggestions 和 T06 habit 因子。模型仍只进行一次完整独立调用。

派发与接收时再次核对配置、联系 revision、状态。若原输入后习惯被抑制或反馈更新，旧输入拒绝调用或采用，不能静默重算旧请求。正反馈不是权限；策略排除的候选概率仍严格为零。

采用现有 habit_items、habit_cues、habit_associations、habit_opportunities、habit_activations，加不可变 registered/observed/changed 事件，无 SQL 迁移。不为 wait/ask 伪造 action_results 或学习表外键；反馈及前后快照完整写事件。缓存 A、状态和 uncertainty_json 与事件投影一致，发现越过模块的直接改写则拒绝。

## 控制、补偿与接口

CLI habit-learning status/enable/disable/enroll/feedback/inhibit/resume/rollback。enroll 的文件为 action 与 cue，key 用于幂等；status 显示联系、revision、A/I/E、观测和反馈来源。配置须停机，旧部署无模块时拒绝写入。

最近一次反馈可显式 rollback：要求仍是当前联系 revision，且提供两个不同来源的证据；追加补偿状态，不删除反馈。回退仍保留已消费活动清单，避免重复刷同一经历。已有后续控制或反馈时拒绝覆盖，需审阅后处理。

面板完整思考详情可查看 habit_learning 快照、状态、抑制原因及 T06 实际概率；旧请求不按当前强度反推。没有面板启动/唤醒按钮。

## 验收范围

隔离验证线索特异、三次以上真实经历形成、强化提升概率、负反馈保留 A 并降低表达直至 extinct、重新获得、立即抑制与恢复、零贡献时不绕候选、非法权限零概率、审批、未知效果、幂等/CAS/来源消费、配置变化与抑制后旧请求拒绝、补偿/重开/旧快照与身份记忆历史保留。完整回归和当前实例只读保护核对后更新 T08。

本项不是通用习惯自动发现、所有情境语义理解、心理自动性测验、无监督奖励学习或长期生物消退实证。生命周期常数和短试验只验证工程路径，长期效度留待后续研究。

## 实现核对补充

非 active 的登记习惯只出现在 habit_learning 审计快照中，不进入 habit_suggestions 行动建议，避免仅以零分继续提示旧行动。T06 比较规范化的 tool+arguments，不把解释文字当作另一个反应。

source 是活动保存的实际输入来源，普通 CLI 用户输入为 user，任务循环可能为 task-loop，聊天为 chat:会话ID；第一版采用精确匹配，不自动把不同会话或领域合并为一个情境。task_contains 是大小写敏感字面子串，不代表语义情境理解。

若工具执行时原习惯 revision 已经改变，保留核心执行历史，但不把新习惯状态倒填进旧请求、形成新习惯观测。反向反馈只代表控制者给出的非强化/不希望继续倾向，系统不声称量化了生物惩罚或自动性。没有时间遗忘参数，因此仅看状态或经过时间不会使 A 自动消失。

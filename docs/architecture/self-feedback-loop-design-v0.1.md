## 1 用简单话说明完整循环

人格决定它更容易对什么产生兴趣；当前需要、价值和经历决定它此刻想做什么。它为这个意图选择要看的信息，先留下预期，再看实际结果。学习模块检查认识或能力是否改善，并把这次经验带入下一次选择。

```text
人格与价值＋当前需要＋已有经历与认识
  → 候选意图与选择概率
  → 选择一个意图，保存身份和完成条件
  → 提出具体问题，留下预期，取得信息
  → 学习模块比较预期、证据和后续表现
  → 更新认识／方法，记录这类尝试的学习效果
  → 下一次形成意图时读入新版本
```

“值得”由个体在处境中的选择分布体现；“收获多少”由学习模块依据测量给出；探索模块不再凭模型自报 expected_gain 判定学习成功。外部评测仍检查事实正确性与实际效果，不替代个体意义，也不因为个体喜欢某结论就承认它为事实。

首版只覆盖允许工具内的信息获取及可核验的知识／预测学习；复杂技能和基础模型权重训练留待后续。缺少可核验条件的开放问题允许提出、记录和保留未知，不伪造学习收益。

## 2 各模块只负责自己的部分

| 模块 | 本闭环的责任 | 不应代做的事 |
| --- | --- | --- |
| 人格 Personality | 给出有版本、带情境相关度的倾向；通过目标形成路径影响选择 | 不决定事实真伪，不直接改工具权限，不每次反馈都改长期人格 |
| 价值／状态 Values、States | 提供当前重视什么、资源与需要；过期数据明确为未知 | 不把未知资源当充足，不把用户停止当应克服的需要 |
| 认知 Cognition | 形成带来源的解释、未知、预测及情境特征；辨认可执行观察 | 不把匹配引文或模型自信当作外部证明 |
| 目标 Goals | 形成、选择及持续追踪意图；整合人格、价值、需要、已学结果一次 | 不在每轮重新抽签替换已接受意图 |
| 动机 Goals.motivate | 表示当前活动目标的推进强度、饱和与剩余资源 | 不再添加第二套“人格价值分” |
| 探索 Exploration | 把意图拆成可查问题，取得和复用原始回执，控制调查预算 | 不做权威收益评判，不接管普通用户任务 |
| 学习 Learning | 判断学习效果、可靠性和更新资格；提出并提交可撤销的认识／方法／兴趣经验更新 | 不凭自述给自己高分，不直接越权修改所有模块 |
| 决策 Decisions | 按已计算合法分布完成一次抽样并留记录 | 不重算一遍人格或忽略目标、停止与授权 |
| Engine／执行／控制 | 把上述环节串起；保持请求封存、重检、一次接受和停止协调 | 不因学习后台作业而隐式唤醒正式实例 |

### 意图、问题、活动不是同一个对象

- 意图：例如“弄清这类记录为什么不一致”，可以跨多次调查；持久 ID 使用根 goal_items.id。
- 问题：例如“当前文件是否仍记录 N”，挂到一个意图，沿用既有 question_id／resource_revision。
- 活动：一次发现、调查或思考执行；保留现有 activity_id 和该活动的子目标。

Engine 仍可为活动建立子目标，用 goal_relations 的 subgoal 关系及绑定事件连接根意图。子活动结束不自动完成根意图，根意图由 Goals 按自己的成功／停止规则转换。一个意图可以有多个问题，一份证据可以支持多个意图，但同一份学习证据不能被多次累计成独立收获。

问题挂到继任意图时新增带 question_revision 的关联，旧关联与学习归属不改写。

根意图沿用目标状态 candidate→accepted→active；可 paused、completed、cancelled、expired、failed，遵循现有合法转换。已 completed 的根意图不原地回到 candidate：资源确变且需继续时，新建继任意图并引用旧意图；问题仍可按 1.2 规则沿原 question_id 新开资源修订。这样不破坏现有终态约束。

## 3 人格如何具体影响意图

### 3.1 输入与唯一作用路径

形成意图前，封存个体快照：人格及价值版本、有效状态、相关记忆与认识版本、当前承诺、兴趣经验版本、权限和配置版本。快照中的“未知”和来源必须保留。

人格不直接读文件或决定结论。先用人格与情境相关度产生候选意图的偏好项，再由 Goals 与其他条件合并。例子：相同信息下，不同个体可能更偏向探新规律、核实不确定信息，或理解对象关系；这些只是工程候选解释，不能将某个人格维度机械对应一种意图。

首版投影形式：

```text
a = trait_vector × context_relevance        # 对应维度相乘
personality_bias(g) = clip(dot(W × a, intent_features(g)), -1, 1)
```

trait_vector∈[-1,1]^d，context_relevance∈[0,1]^d。W 是版本化、初始人工声明的映射，不是科学界提供的常数；未知相关度不填 1，对该项不产生有把握的个体偏置并记录 missing。意图特征来自认知及来源记录，限定到声明的维度、范围与提取器版本；模型产生的特征只是推断。

初始特征通道：新信息方向、核实方向、对象关系方向、持续推进方向。W 未配置的通道贡献为 0；全未配置时退回共同先验并明确“个体化未生效”，不能靠不同角色措辞冒充人格效果。未来可学习 W，但 V0.1 隔离闭环中固定 W，不与兴趣更新同时训练。

### 3.2 从候选到概率

最多 4 个有来源、能力范围内的候选意图，另有明确的 rest（暂不新建活动）选项。候选来自可读经历、当前未知／矛盾、未完成意图与维护状态，不只来自最近两段模型回复。先保留原始候选及筛选原因，再计算：

```text
S(g) = common_prior(g)
     + personality_bias(g)
     + value_alignment(g) + current_need(g)
     + learned_gain(g) - expected_cost(g)
p(g) = (1-epsilon) × softmax(S / temperature)(g) + epsilon × uniform_eligible(g)
```

V0.1 分项范围：共同先验、人格偏好、价值一致性和 learned_gain 为[-1,1]，需要与预期成本为[0,1]；rest 的分数固定为0，缺失非学习分项使用声明的共同先验并保留 missing。所有分项范围、来源和版本分别记录。value_alignment/current_need 只在目标形成计入；相关记忆经认知解释进入特征或需要，不另加“记忆总分”。learned_gain 仅来自学习模块的有效已提交记录，模型自报 expected_gain 只保留作诊断，不参加主排序。实际成本用于更新下一次 expected_cost 的估计，不再混进 learned_gain 重罚一次。

temperature>0、0≤epsilon≤0.1；示例核算使用 temperature=1、epsilon=0，不是已校准生产默认。候选受停止、权限、资源和用户工作优先级硬筛选；禁止项概率为 0，不参加随机保底。停止／锁定时直接不调度，不以“rest 抽中”代替停止。所有候选都不合法时 rest=1，且不为 rest 新建模型任务。

在一次选择事务中固定输入、候选顺序、分布、随机种子／计数器和已选 ID；重试或重启读同一选择，不重新抽样。选择概率不同于事实正确的概率，不用一次选中结果检验“80% 是否准确”。

### 3.3 持续性与重新选择边界

已接受的意图保持身份，直到成功、明确暂停、取消、过期或失败。新信息可以改变计划与后续选择，不能让每轮思考随概率波动换题。用户工作／停止具有优先权；资源不足、无法取证、反复无新信息或现有额度耗尽时明确暂停。

恢复只在授权运行状态、条件改变或到达已登记检查点后进行；休息不会触发新的无限“发现”作业。候选生成、意图选择、取证和学习测量均计入已分配的总调用／活动预算，不能每多一个意图就重置额度。

## 4 学习如何改变下一次选择

### 4.1 先留预期，再看结果

取证前保存 Expectation：原问题与目标、候选答案／预测分布、已有证据、可检查规则、预计成本、要比较的更新前版本。预期在观察后不可改写；当时没有预测或方法不足，收益就是 unknown，不事后补一个“我本来就知道”。

工具失败、没有新内容、来源重复、暂时无法核验分别记录。失败不自动等于认识变差；对随机结果感到惊讶也不自动等于学到了东西。一次新事实能更新候选认识，但若不能测量改善幅度，就只登记“有新观察、收益尚未测量”。

### 4.2 学习结果分量及首版数值规则

| 分量 | 判断方式 | 首版处理 |
| --- | --- | --- |
| 认识／预测改善 | 同一有效检验集、同一标签，比较更新前后预测；标签与待测模型输出独立 | 有合格测量才生成 [-1,1] 的 gain |
| 能力改善 | 未用于本次更新的类似问题与旧任务保持情况 | 保留接口；未实施的能力学习为 unknown |
| 意图进展 | 目标预先登记的成功规则是否满足、排除哪些解释、剩余未知 | 单独给出 verified／partial／unknown，不另作同一认识收益的奖励副本 |
| 成本／副作用 | 实际调用、tokens、耗时及资源记录 | 分量分别保存，缺用量为 null；不拿预留值当真实值 |
| 可信度 | 证据独立性、规则适用性、来源权限与版本 | 合格独立检验首版权重 1；不合格不进入数值统计，不由 LLM 报可信度 |

首个可实现的测量器为 prediction_brier_v1：更新前、候选更新后在匹配的、未用于该次更新的样本上产生预测，然后对同一实际标签计算 Brier 差。二元 Brier=(p-y)^2；多分类使用 1/2×Σ(p_k-y_k)^2，归一到 [0,1]。gain=Brier_before−Brier_after∈[-1,1]。多个样本先按冻结规则聚合，不把同源副本当独立样本。

测量必须固定更新前状态与候选更新，先在两个隔离分支上对同一未见检验输入产生并封存预测，再揭示独立标签计算差值；标签不得提前出现在模型上下文、工作区或候选学习材料中。两个分支使用同一配置、样本与对照条件，测量所需模型调用也扣同一预算；预算不够即 pending，不补跑隐藏调用。不得事后让已看答案的模型猜一个“更新前预测”。检验只使用获授权临时实例与数据，不复制或运行正式实例。

这不是所有知识的万能量尺。没有预测分布、有效标签或独立检验时，gain=null、status=unknown；不能填 0。实际测得 0 是 measured_zero，变差为 negative，改善为 positive。技能测量器未实现前不能填“能力进步”。发现“不可预测／缺信息”只有在对应可检查规则确实满足时才记进展，不因模型说“未知”就奖励。

### 4.3 学习经验怎么进入下一次选择

首版只更新兴趣经验统计，不自动重写长期人格、价值或基础模型权重。统计单元为：

```text
(intent_family, observation_method, context_bucket, measurer_version)
```

分类在选择时保存；不得在看完收益后为了得分重新归类。不同个体、不同方法和不同测量规则不混池。开放的新分类先使用共同先验，不声称已学会其收益。

每个合格学习记录贡献 (w,gain)，首版合格 w=1，不合格不贡献。使用带共同先验的均值：

```text
Q(cell) = (kappa × prior_mean + sum(w × gain)) / (kappa + sum(w))
learned_gain(g) = Q(cell_of_g)
```

V0.1 验算设置 prior_mean=0、kappa=2，是防止单条结果支配选择的工程起点，不是科学定值。无样本时沿用先验，并明确 uncertainty=unmeasured；初始 0 不是“已证明没收益”。保留样本数、贡献列表、时间范围与估计不确定性；不得把 Q 当成“成功概率”。

可靠的正收益逐渐提高这类尝试的吸引力；负收益降低相同方法与情境组合的吸引力；测得零会减少此前过高的收益估计；unknown、重复回执与单纯模型自述不更新数值，也不计作零收益。确认已解决的未知由认知／目标状态消除，不必靠反复给负奖励才能停止调查。

这里改变的是对某类尝试的经验判断，不是立刻改人格。负收益也可以来自被拒绝的候选更新，帮助学会避开效果差的方法；事实／记忆修改是否被接纳，仍由各自既有门控决定。

### 4.4 延迟收益、复用与撤销

一个观察暴露键由原始 result/evidence、资源修订、原问题、测量规则和真实检验批次组成；同一原始证据换措辞、转成记忆或跨活动复用，不创造新暴露。一个批次归属的尝试可含多个动作，每个 LearningAssessment 明确对应哪个 attempt_group。

后续获得检验标签时，原学习机会由 pending 形成有编号的新评估修订；对同一机会只替换当前贡献，不累加旧贡献。多个意图受益可写多个关系，但在同一 cell 同一检验暴露只能计一次。后续真正不同的检验批次可记录新机会，须证明不是同源复制；早期失败的长期帮助需另有依据，不能事后把所有动作都分同一份满分。

来源撤回、错误标签、候选更新撤销时，学习模块失效相应贡献及依赖，重建当前 Q；版本化保留原因，隐私删除按现有流程处理。更新采用 expected_revision 比较后提交，冲突不覆盖新版本；重试不重复加分。跨重启重放同一已提交贡献，不能重新学习一次。

### 4.5 一个小例子

同一人格和处境下，两个合法方向 A、B 的非学习分分别为 0.4、0.2，rest 为 0。共同先验 Q=0，temperature=1、epsilon=0：A≈40.18%，B≈32.89%，rest≈26.93%。

后来对 A 的某种观察／解释方法测得 gain=-0.9；w=1、kappa=2，所以 Q_A=-0.3。人格保持原样，新分数为 A=0.1、B=0.2、rest=0：A≈33.22%，B≈36.72%，rest≈30.06%。它开始更可能选择 B，原因是学到了“当前用这种方法效果差”，而不是改了人格。若该结果只是工具超时、无标签或自我评价，Q 不变。

数值只是可复核例子，不是实测行为，也不意味着一次结果应永久放弃某个方向。环境变化后使用新的情境／资源修订、保留探索空间并检查旧经验是否仍适用。

## 5 状态、接口和记录

所有新记录带 instance_id、contract_id、record_id、版本、来源引用、配置世代、生成时序；派发相关记录另带 activity_id、input_epoch、runtime_epoch。下表均为拟议接口，当前源码尚无这些方法。

| 拟议接口／所有者 | 输入 | 输出及关键条件 |
| --- | --- | --- |
| Personality.intent_bias | profile_revision、context_features、candidate_features、mapping_version | 偏好分项、相关度、来源与缺失标记；无事实写入 |
| Goals.propose_intents | 个体快照、可读经历／认识、能力、未完成意图 | 最多4候选、稳定意图类型、成功和停止规则；保留过滤原建议 |
| Goals.select_intent | 候选、硬条件、interest_revision、选择策略、decision_key | 分项、完整分布、抽样与 selected_id 或 rest；事务内一次提交 |
| Cognition.prepare_expectation | intent_ref、question_ref、事前预测、测量规则、认知版本 | 不可改写 Expectation；应先于该次实际取证派发 |
| Exploration.bind_intent | intent_ref、activity_ref、question_ref、decision_ref | 根意图—子目标—活动—问题映射；不得重置总预算 |
| Learning.observe | expectation_ref、原始结果／回执、exposure_key | 去重的 Opportunity，状态 pending／unmeasurable；不自报收益 |
| Learning.assess | opportunity、候选更新、独立检验结果、measurer_version | 带依据的 Assessment、gain 或 null；不同时改所有业务模块 |
| Learning.commit_interest | assessment_ref、expected_interest_revision、授权策略世代 | 记录一次贡献、返回新 interest_revision；未知／无资格不提交 |
| Learning.invalidate | assessment／source_ref、reason、expected_revision | 失效贡献、依赖记录和重建后的兴趣版本，不删除相反证据 |
| Decisions.sample_once | decision_key、候选／分布／种子、快照哈希 | 固定一次抽样；同键不同输入拒绝；不再加人格分 |

学习机会状态：pending→measured 或 unmeasurable；收到新标签可以新增 assessment 修订。评估可进入 eligible→committed，或 rejected／superseded／invalidated；提交与失效均有版本事件。unknown 不进入 eligible，不伪装成已学习。

持久化首版复用 runtime_events 和不可变 artifacts，事件 source='self-feedback'，key 含阶段、机会／决策 ID 和修订。Store.event 现有同 source/key 同 payload 返回旧记录、异 payload 冲突；调用者必须在统一事务内检查和提交。兴趣投影以提交事件重建，先不加可变旁路缓存或修改 SQL。

事务边界：选择时一并保存分布、抽样、意图状态与活动绑定；取证接纳时一并挂接原结果和待学习机会；学习评估可以稍后完成，提交贡献时单独 CAS。模型和工具 I/O 不放进数据库写事务。事件 artifact 不作为已验证事实权威。

### 模型接口与兼容方案

新模式使用具名约定 AE-SELF-FEEDBACK-DRAFT-0.1，响应包装为 `{contract_id, exploration_output, expectation_proposal}`；exploration_output 仍按现有 V2 校验，expectation_proposal 另做字段、来源及预测分布校验。首次只在隔离且明确启用新模式时使用包装适配器；未启用的 V1/V2/V3、Chat 和 TaskLoop 不解释该包装。不预占新的整数 schema 版本。

expectation_proposal 不完整时仍可保存候选，但相关实际取证必须先登记“不可测”或补齐合格预期；补齐若需要额外模型调用，照常消耗同一预算。包装中不能携带直接执行命令。旧模型不支持时在新模式启动前拒绝能力协商，不静默退回旧 expected_gain 排序并声称闭环启用。

## 7 权限、停止与首版启用范围

新增 self_feedback.enabled 与 auto_interest_updates 两个独立策略，默认 false。当前 controller 专属的事实、人格、价值及记忆正式修改资格保持；设计没有把知识候选直接升级为已接受事实。

隔离验证可以由 controller 预先授予“只提交可核验兴趣统计”的窄范围授权，包含测量器、最大更新幅度、版本与预算。这样无需每个统计更新都请求人批准，又不把学习模块变成任意修改权限。该新授权机制尚未实现；本轮设计交付不等于正式实例已获授权。

所有模型、工具、学习测量作业和兴趣提交都重检当前控制状态、世代、来源、预算、版本；使用 gate→数据库事务顺序。停止后不新派发模型／工具，也不提交会改变未来选择的新兴趣版本；在途结果可依既有规则保留为待处理记录。恢复后重新检查，不因旧作业重放绕过撤回。学习耗时超预算只登记待处理，不自动开新活动续费。

本轮正式 `work/primordial00` 保持 WAKE_DISABLED；只读取文件摘要确认前后未变，不打开数据库、启动服务、解锁或执行模型。

## 8 验证设计、验收边界与实施顺序

| 场景 | 要验证的结果 |
| --- | --- |
| 相同世界／历史，不同个体倾向 | 完整选择分布按已登记人格路径产生可解释差异；事实标签及权限不变 |
| 相同人格，可靠学习结果不同 | 保持人格版本不变，下一选择的分布因 interest_revision 改变 |
| 同一问题／回执反复出现 | 不重复贡献，不产生新的独立学习样本 |
| 高噪声、无标签、失败与未知 | 不因惊讶或自信累计收益；unknown 不作 0，实际零收益可测 |
| 延迟标签与真实环境变化 | 正确归属原机会；修订替换旧贡献，变化后合法新观察不被旧缓存压住 |
| 错误标签、来源撤回与撤销 | 依赖贡献失效、Q可重建、无隐私来源重新进入上下文 |
| 重启／重复接纳／提交竞争 | 同 decision_key 不重新抽样，同机会不重复加分；CAS冲突保留证据 |
| 停止、禁用、用户工作优先 | 无停止后新派发和新兴趣提交，不自动唤醒，不靠预算重置续跑 |
| 新认识带来改进，也可能退步 | 采用未用于本次更新的检查样本，并检查旧能力；错误自信不能充当改善 |
| 去掉人格／去掉学习反馈的对照 | 分别失去相应选择差异，避免仅提示词换说法；没有运行就标未测 |

首版只冻结事件去重、概率和版本的数学／工程性质；行为效果阈值、正式样本规模和收益校准另登记，不能用本设计例子代替实测，也不修改旧 M01–M16。新增诊断分别报告：期望登记率、可测率与unknown原因、重复计分数、选择分布变化、学习前后预测差、撤销重建一致性、停止后兴趣提交数。

建议实施批次：①记录关系与影子投影，不改变选择；②临时实例中启用一次选择和原回执学习机会；③接入预测测量、窄授权提交和撤销，完整G1；④固定材料后真实模型先导及人格／学习反馈对照。影子计算不是行为闭环通过，真实先导也不自动满足正式G2。

本次交付仅完成设计、机器约定、示例核算、链接检查及锁完整性核验。后续代码实施须建立新的集成基线，保留旧失败和先导证据；正式实例继续锁定。

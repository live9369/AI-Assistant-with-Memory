# IM01 隔离合成夹具实现说明

2026-11-09；依据TL-LOOP-0.1和IM01。本项是验收基础设施，不实现新学习链，不改19张规划表或当前实例。

`SyntheticToolLearningFixture(root, schema_version=2|3)` 是上下文管理器。root必须是不存在的最终目录，父目录已存在且各级均为真实目录；先按未解析路径拒绝已有目录/文件、悬空或正常symlink，再原子创建。不会接受已有实例、复制数据或读取当前实例。祖先若含runtime.sqlite、control.sqlite或WAKE_DISABLED标记则拒绝，即使最终叶子尚不存在，也不能把新夹具嵌套在现有实例内部；只检查路径标记，不打开其中数据库。调用者可用canonical临时父目录；不自动跟随`/tmp`等符号链接别名。

使用现有Store.prepare建立真实schema2；schema3必须调用既有受授权、停止状态的migrate服务，保留真实迁移记录和快照，不直接伪写user_version。初始模型保持unconfigured，不探测、不推理、不启动进程。Control初始停止，WAKE_DISABLED从不解除。

合成材料包含：独立身份/锚点和控制者、不可变原始记忆、用户输入及历史事件、既有authorization政策及一项待审批读工具意图、未来due的已确认active承诺。固定语义与预期引用写入fixture-seed.json，可核对内容、所有权、状态、未来时间、数据库完整性和零模型/工具尝试；原始记忆不是新认知经验。

上下文退出或初始化失败时先确保禁止唤醒和controller停止，再关闭Store/Control。保留目录与fixture-lifecycle.json用于失败审阅，记录失败类型/阶段，不复制异常中的任意敏感文本。夹具不会自行递归删除；临时目录由测试调用者在核对停止锁后清理。重新进入同一目录拒绝，异常不会转成成功。

夹具临时目录按单写者使用，不对抗父目录被同时恶意替换。退出使用新建临时锁原子替换WAKE_DISABLED末级路径，不跟随锁symlink；schema3核对真实迁移校验和。本守卫用于避免误指向已有数据，不声称对可同时修改父目录和所有本地证据的攻击者提供OS安全沙箱。测试覆盖schema2/3真实创建、独立身份、材料预期、原数据不变、已有/符号链接路径拒绝、异常停止与连接关闭，以及无实际推理/工具执行。

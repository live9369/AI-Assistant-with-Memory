# T11 承诺与自主探索详细设计

版本 V0.1；状态：设计基线／待隔离实证；不部署当前实例。

## 目标与边界

把“答应以后完成什么”和“没有用户任务时研究什么”接回现有生命活动闭环。每次思考仍为独立请求，持续性来自持久状态。默认关闭新策略，沿用现有身份、事件、记忆、活动、工具权限与预算；不新增唤醒入口，不向第三方发消息。

本项完成范围是有限文件目标的承诺、受控兴趣偏好、探索事实覆盖收益、等待与休眠条件。不是无限自主行动、通用心理测量或无限期履约保证。现有 cognition.experience 的影子统计保持原所有权，不冒充兴趣，也不改成在线学习策略。

## 理论定位

承诺采用债务方、受益方、触发条件、履约条件和截止时间的区别，参考 Singh 的社会承诺模型：https://www.csc2.ncsu.edu/faculty/mpsingh/papers/mas/commit.pdf 。工具调用成功不等于承诺完成。控制者显式登记后确认并激活；开始时间与截止时间分开。只有独立核验器的证据才能完成；截止后完成不能追认按时履约。

探索参考 Oudeyer 等关于内在动机与学习进展的研究：https://pmc.ncbi.nlm.nih.gov/articles/PMC2518057/ 。本版本不声称计算了人的好奇心：模型预估收益、控制者声明兴趣和实际观察收益分栏；没有测量用 null，不当作零。系数是可审计工程规则，不是科学通用常数。

## 数据与接口

新增 AutonomyAgenda 应用服务，事件前缀 agenda，配置与登记均受 controller 和协调锁约束。配置仅在停止且无运行进程时改变。状态保存在已有 runtime_events 的不可变 JSON 工件；承诺继续使用 commitment_items / commitment_transitions / commitment_goal_links 外键与状态机，不新建重复身份、记忆或承诺表。

- configure(enabled, actor)：默认 false；关闭后禁止新登记承诺/兴趣，关闭本项的兴趣排序与收益测量；原 V2 exploration 的启停及预算独立管理。已激活承诺继续审计和履约，取消须显式 release。
- promise(content, start_at, due_at, verification, key, actor, max_rounds)：ISO UTC 毫秒时间；start<=due 且新登记 due 在未来。验证器限定 TaskLoop 已支持的 file_contains，1—3轮。key 去重，不同内容复用同 key 拒绝。受益方为控制者；扩展第三方须另设计授权。
- release(commitment, actor)：取消排队或执行前的关联活动，保留全部记录；已履约／违约不可改写。承诺版本由协调锁和数据库事务串行保护。
- question(question_id, topic, affinity, path, contains, key, actor)：为已有有限问题登记受控兴趣及二元事实测量；affinity∈[0,1]，path 为工作区现有 UTF-8 文件。固定 path+contains 作为测量标识，避免换措辞重复奖励。问题来源仍走 V2 证据许可。
- status / context：配置、承诺及关联活动、探索偏好、测量与等待状态。思考快照仅放当前活动相关信息，不全量泄露历史承诺。

## 承诺闭环

每次现有授权运行循环先审计承诺。到期未核验完成者标 violated；成功必须有 TaskLoop 独立 file_contains 核验，保存核验工件、证据引用和完成时间，再转 fulfilled。超过截止时间即使核验成功仍为 violated。错误、未知副作用、轮数耗尽沿用 TaskLoop 暂停，不自行重试或重置预算。

到 start_at 且无更早用户工作时，原子创建唯一活动、目标关联、配置 TaskLoop；重启从持久链接恢复，不重复任务。原 commitment_due 队列对受管理承诺仅审计，不重复建立活动。用户已有工作优先；承诺可能因权限、资源不足或用户任务阻塞而违约，状态如实反映。违约/释放取消未完成活动；正在执行的外部副作用仍由原执行器进行对账，不能声称撤销效果。

## 探索闭环与量化

沿用现有 V2 最多活动数、每题最多访问次数、轮次、间隔、只读工具、证据新鲜度、审批和停止门控。新配置开启后，候选得分 = expected_gain - cost + 0.25×declared_affinity - 0.25×已测得同一事实标识的次数（惩罚上限1）。默认未登记 affinity=0；并列按问题ID。分数仅影响已有合法候选排序，不能绕过预算、来源或用户优先级。

测量仅消费同一活动 Executor 的真实成功 read_file 回执，核验路径、内容哈希、资源签名与当前文件元数据；不额外偷读文件。包含目标字符串记布尔结论，正反结论均为观察。收益=首次核验该事实与该文件内容版本为1，重复版本为0；失败／其他工具／资源变化为null。结果是“本地事实覆盖增量”，不是通用知识正确率、预测误差降低或心理学习进展。收益由不可变回执重建，重放同 result 不重复记录；同内容换题也为0。旧记录是历史观察，资源变化后不当作当前事实。

## 等待与休眠

status 返回 disabled / waiting-work / waiting-deadline / exploring / budget-exhausted / idle 等逻辑等待信息和下次承诺开始/截止时间、探索间隔。运行时仍使用原 control_plane 两阶段 sleep handoff：排队就绪任务、未决外部效果或事件变化可阻止实际休眠；未来承诺开始使用已有持久队列提醒。状态展示不发起物理休眠、唤醒、部署或自主补充预算。关闭配置不会抹掉履约义务。

## 验收矩阵

临时实例验证默认兼容、权限、停止配置门控、参数和时间边界、登记幂等、提前开始、唯一关联与重启恢复、用户优先、独立核验成功/不匹配/未知、截止和释放、未来队列、预算及等待、兴趣排序、真实回执收益1/0/null、跨题去重、篡改与来源变化、思考快照、CLI及全量回归。正式实例只读比较身份、运行代次、进程和部署，不更新身份、记忆或历史。

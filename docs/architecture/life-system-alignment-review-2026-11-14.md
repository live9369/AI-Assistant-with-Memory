# 生命工程与系统工程对照检查

日期：2026-11-14。检查性质：概念、源码、已有验收及正式实例只读状态对照；没有运行新测试、调用模型、停止实例或更改配置。结论适用于现有证据范围，不是全系统重新验收。

## 结论

按本项目自己的生命操作性定义，模块对应关系已基本建立，核心活动可以运行，但尚不能称为完整实现并验证了全部生命闭环。最大缺口是：新经历如何转成长期可用的认识，并稳定改变以后的选择。当前已经能延续思考、取回成果、修正本轮理解和收束；这些不自动等于长期学习完成。

基线仍为：具有自身边界的持续性系统，通过环境交互维持自身组织，并利用交互信息调整自身，保持存在与适应。思考是认知内部由LLM或其他推理器承担的能力；身份不等于人格参数。意识和主观体验不在已证明结论内。

## 核心流程的接线缺口

### 1. 探索中修正理解，还没有统一写回长期认知

Engine.prepare仅在认知功能启用且不是探索绑定时选择V3认知协议。探索使用V5；Engine.think接受探索结果后会提前返回。CognitiveUpdates.record也只处理V3。因此，同方向工作记录中的新理解不会自动进入聊天使用的结构化认知候选链。

探索公开回复之后可能通过remember_public_responses进入普通记忆；工具执行也会写入Action result引用。这些分别是模型文字与执行记录，不等于经过来源检查和接纳的长期认识。新工具学习路线虽已实现大量机制，但当前库为schema 2，没有tl_*运行表，不能把该路线当作当前实际闭环。

### 2. 人格进入输入，不代表已覆盖所有认知环节

人格进入模型输入、表达及部分概率特征，当前确实存在影响路径。但Memory.retrieve主要依据文本匹配、近期性、重要性和账户来源权重；没有直接接入人格/动机来统一决定检索注意。当前人格激活也主要由特质值乘相关性构成。不能把这些已有路径直接解释为完整的人格—注意—解释—记忆形成模型已实现且校准。

这属于实现覆盖和实证缺口，不要求立即启用人格成长。固定人格下仍可以通过记忆和认知变化实现适应。

### 3. 经验尚未稳定改变下一次选择

普通行为策略有多因素评分；探索则使用自己的概率选择。探索的习惯强度固定为0并标缺失，收益与成本主要是模型估计及工程规则。当前没有可核对的统一链路，证明一个经验证的经验会改变类似情境的后续选择，同时保留无关旧能力。

已有受控学习代码不能据此称为空壳；缺的是当前运行链路的整合和效果证据。正式实例已有的1条学习提交属于人格初值的受控设置，不能计作自主经验学习收益。

### 4. 健康维护与“会做什么”的认识仍有限

最近维护记录中，身份、存储、资源、工作目录和未决外部作用检查为healthy；认知与模型质量为unknown，记忆质量索引未启用。该结果表达的是可检查的底层健康，不是所有生命功能健康。

目前没有自动维护的自我能力模型记录。自主生成“能力说明”的公开成果，与持续更新“哪些能力已通过何种验证”的自我模型，还不是同一功能。另有已记录的部署数据库锁竞争和较慢的输入准备，仍是运行可靠性遗留，本轮未扩展测试或修复。

## 量化与任务状态

正式实例最近一次读取的指标采集批次共188项，其中22项有值、166项为空。空值包含无样本、无独立评价或当前不适用等情况；不是166项测试失败。也不能把188个定义/采集入口说成188项已经实测通过。

人格、认知、关系、行为概率等数值仍有工程初值或受限代理量。需要区分“能存、能算、进入决策”与“数值真的反映目标特征”。本轮没有为后者补做额外实验。

机器任务状态仍为T01—T12 complete、T13 validating；各项complete都有有界工程范围。高级工具学习路线IM01—IM19 complete，IM20—IM24 blocked，尚未完成相应正式质量验收/部署。当前后续最小真实对话和探索验收不能自动将这些历史门槛改为完成，也无需为了当前核心流程直接启动全部旧实验。

## 建议的下一步

先做一个小而完整的“经验回流”切片：探索或行动产生成果 → 保留来源与原文 → 提出认知/记忆更新 → 按当前规则接纳或保持未知 → 新方向或新会话能正确使用 → 后续选择能说明该经验造成的改变。明确复用当前轻量链路还是接高级学习路线，避免再叠加互不相认的第三条链。

保持原人格与已归档测试记录的状态；不为追求模块齐全擅自开启人格成长、习惯或承诺，也不先追加长时间测试。先把这条当前核心接线补齐，再判断哪些数值和长期表现需要验证。

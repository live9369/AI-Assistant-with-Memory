# 经验回流首版设计与实施清单

日期：2026-11-14。范围：当前native运行器的版本化升级，不声称实现或启用完整TL-LOOP，不迁移schema4。

## 权威与数据

M03继续是认知版本的唯一所有者。升级CognitiveUpdates统一处理聊天V3与探索V6；所有模型提案保持held，不自动升为外部事实。V6在V5基础上增加learning.claims（最多4条）：subject、predicate、value、kind（reported/hypothesis/method）、source_ref、quote、valid_at、context_contains。有效时间为空表示未知，不能用记录时间代替。方法必须给出明确适用线索。

M04发布引用认知修订的cognition-representation-v1表示，复用原memory_items/revisions/source_links与来源依赖。认知版本与记忆表示同事务提交；按修订幂等，重复相同来源/内容复用，不重复增加经验。旧认识不覆盖；held和accepted明确区分。认知确认后发布新表示，默认召回隐藏同认识已被替代的旧表示，但原始版本和审计保留。

表示可读性同时检查自身账户域、原始来源、认知版本及原来源读者交集。无权、归档、撤回、修订失效后不能继续召回派生结论。保留循环/深度防护，避免把派生模型文字当原始事实。解释与来源性质随表示一同提供。

## 调用与收束

独立请求不变。认知功能关闭时旧V4/V5路径保持；启用时新的连续探索绑定V6，并提供精确可引用的学习来源（当前信号、记忆、已接受历史公开成果和实际工具正文）。保存经验发生在正式接受结果之后、探索提前返回之前。无新信息可以提交空claims，不要求额外探究。

发送前/接受前校验当前来源。模型不能借学习字段授予权限。原输入容量、活动预算与方向收束规则保持。跨会话取回是显式输入，不用服务端会话续接。

## 方法效果

方法仍存为M03认知版本，并以M04表示召回；不建另一个权威方法库。首版只对控制者已确认的方法采用效果。明确的控制者反馈必须引用真实外部用户信号、明确success/failure/unknown及理由；同方法同来源不重复计数，可撤销反馈。自评和工具成功不自动加分。

探索方向只有引用该方法表示且匹配context_contains时才受影响。按有效反馈产生有界工程增量（绝对值不超过0.4），并记录反馈依据；人格、动机、权限和原评分仍保留。未知、失效来源、未确认方法不改变倾向。首版作用于方向选择，不宣称所有工具级实施方案已完成在线学习；参数不是科学量表。

## 实施顺序

- [x] ER01：V6严格协议、来源清单、统一认知提案接纳。
- [x] ER02：幂等认知表示、账户与来源依赖、更新及撤回后召回。
- [x] ER03：方法反馈、撤销及有界方向概率因素；CLI入口。
- [x] ER04：隔离核心链路验收，最小真实链路确认，报告与进度收尾。

仅验证保存→新活动使用、更正/确认→新旧分离、撤回及跨账户拒绝、方法影响限定情境和撤销。人格成长保持关闭，不恢复已归档测试数据，不运行长时间或无关测试。

## 已完成的接口边界

当前默认召回只提供有效的当前表示；明确问历史时允许回取旧表示，并标historical。历史可读不等于当前有效，来源撤回仍阻断历史依赖。历史问法识别首版为有限关键词规则，不宣称完整语义/时间理解。V3保持兼容，V6只对认知功能已启用的新连续探索绑定生效。没有批量重新发布旧候选或恢复归档内容。

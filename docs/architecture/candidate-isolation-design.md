# 候选代码隔离执行 V0.1

2026-11-15。范围：SourceUpdates.validate固定探针；不改变人格、预算、记忆域或正式推理器。

## 流程

1. 验证原部署与候选发布manifest，在全新临时目录复制候选。
2. 生成宿主控制的Seatbelt策略；候选副本只读，只有独立probe目录可读写。正式实例、真实HOME、工作区、凭据及其他临时目录不在白名单。
3. 仅执行当前Python解释器及其受限子进程；不开放shell/任意可执行文件。网络默认拒绝，包括回环和Unix socket；不继承代理、令牌、CODEX_HOME等环境变量。
4. 保留公开系统运行库、Python运行时与必需的系统加载操作；路径从解析后的实际位置生成，使用参数传入策略，防止路径被当成策略文本。
5. 在导入候选前设置CPU、文件大小、句柄和core限制；宿主限制总输出、原墙钟时限，超时终止原进程组。此处不声称具备整个进程树的硬内存/进程数量配额。
6. 宿主沿用原固定业务产物、SQLite约束、两次独立调用和版本一致性检查；候选自己的“通过”输出不算证明。
7. 验证记录附后端、策略hash、限额和隔离版本。探针协议升级，旧的无隔离验证记录不能用于新提案部署。
8. 后端缺失、策略无法应用、超时或超量均失败；不提供自动绕过开关。

## 最小验收

- 实际macOS沙箱中正常读候选、写probe，完成现有两轮固定业务探针。
- 合成外部文件不可读写，候选副本不可写，符号链接不扩大权限。
- TCP回环与Unix socket访问被阻断；Python子进程继承限制。
- 超时与输出上限触发失败；无后端时不执行候选。
- 固定检查失败仍走原更新恢复逻辑。所有越界目标用临时合成数据，不尝试读取真实凭据或修改正式实例。

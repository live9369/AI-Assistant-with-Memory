# root认知影响权重 V0.1

日期：2026-11-14。

root的认知影响权重为2.0，其他账户为1.0。这里只确定root最高，不额外假定admin比member更可信；这些数值是可追踪的工程初值，不是科学测量。

权重作用于：已通过权限检查的相关记忆召回分数、当前输入和已召回来源的认知影响提示、新认知候选的来源权重记录。root的指引、偏好和明确更正在理解时优先参考；涉及事实冲突时仍保留各方原话、时间和来源，候选保持held，不自动成为事实。

只有可追溯到root直接输入的来源获得2.0。模型自己的回复、未知来源和混合/派生来源保持1.0，避免模型因为服务于root就给自己的输出加权。旧root直接输入可按原perception source_actor验证，不改写历史。

权限先于权重：root私有记忆不因权重大而向其他账户公开；被撤回或失效的来源不能参与召回。每轮独立调用明确携带权重与规则；模型不能自行声明账户或改写权重。模型调用前和结果采用前复核策略及来源权重。

不改变人格成长开关、账户权限、记忆域、事实确认流程、模型预算或独立调用规则。验证仅使用临时数据和替身模型，正式部署不发送测试消息。

实现和核心验证已完成，验收见../operations/root-cognitive-influence-v0.1.md。权重是工程初值，不代表事实置信度或科学测量。

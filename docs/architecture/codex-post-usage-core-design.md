# Codex真实聊天接入与核账保护

2026-11-12。仅本次核心接入，不开展性能、增长或全量回归。

- 模型配置显式 `budget_mode: post_usage` 才选择新的普通思考适配器；旧默认拒绝策略、学习协议和其他供应商不变。
- 每次独立CLI进程、临时目录、ephemeral、无resume/fork，工具与外部插件禁用；完整输入不裁剪。
- 调用前预留原输入额度全部余额，而非伪造token精确估算；本地prompt大小、实际来源边界、超时、返回字节限制保留。
- CLI无法保证服务端token硬上限。返回后用CLI真实用量核账；未知或超原额度不返回可接受结果，持久停止实例且写MODEL_USAGE_REVIEW_REQUIRED，禁止自动重试/继续调用。此机制不能撤销已经产生的供应商消耗。
- 原始额度数值不提高。模型context_window只配置本地完整prompt容量，不是活动额度；超容量不截断、不偷偷降级。
- 接入仍走StrictEngine的原始派发、来源核验、预算结算、输出验证、回应保存和记忆写入。
- 一键CLI只对明确指定的既有实例启动版本与本机面板；不隐式创建/迁移/清空历史，不在面板添加唤醒按钮。

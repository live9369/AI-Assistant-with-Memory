# T12 健康维护与自更新实施报告

V0.1；状态：有界工程验收通过；范围：有界工程实现与隔离验证；本轮不部署当前实例。

## 已实现

- 健康闭环：分维度观察身份、存储、工作区、资源、派生索引和未知外部效果；认知和模型质量无证据则unknown。有限白名单计划绑定故障事实、配置和源水位，执行后独立复查。
- 自动维护：默认关闭；显式允许后才在已有授权Runtime内检查，每30秒最多一次、每次最多一项，每代配置最多3次修复。尝试先持久化，失败和崩溃也消耗次数，不无限重放。用户停止不被健康目标覆盖。
- 源码提案：控制者CLI或经审批/原open权限的write_note行为可以提出有限包内变更。模型来源沿已接受思考、请求、动作意图、实际结果和回执哈希核对；仅生成提案，不热改运行代码。
- 候选验证：复制冻结基线构建不可变候选；固定宿主探针在新临时目录调用候选，完成真实文件动作、独立核验及两次独立思考。父进程另查实际产物和SQLite，拒绝仅宣称通过的输出。无真实模型调用、无正式实例数据输入。
- 发布与回退：拒绝发布缓存篡改、额外文件及不兼容版本；新自更新候选未经当前独立验证不能进入进程创建。沿用准备/激活双握手、稳定窗口、heartbeat与回退；旧版也必须可验证且兼容当前数据库。用户在启动握手中停止时不回退重启。
- 可观察性：CLI增加maintenance配置、状态、诊断、计划、修复、提案、构建与验证；思考详情健康组增加self_maintenance冻结输入。面板没有部署、启动、唤醒按钮。

## 数据与连续性

复用runtime_events工件和control.sqlite的发布、切换、回退表，不新建重复身份/记忆/版本表。修复工作目录只恢复空容器；索引重建只操作派生数据。程序回退不会恢复旧数据库，不撤销外部动作，也不会把新记忆和历史重置到旧版本。

当前实例只做身份、运行代次、进程与部署的只读基线比较，没有部署、重启、唤醒、测试输入或记忆写入。

## 隔离验证

新增测试覆盖默认兼容、配置权限/停止门控、unknown维度、真实目录/索引修复、路径冲突和symlink、计划幂等/过期/源变化、有限预算、失败与崩溃不重放、停止在修复前生效、CLI、思考输入快照、控制者和真实工具回执提案、审批不可绕过、非法变更、基线冲突、候选冻结和篡改、真实探针成功/导入失败/伪成功/超时、schema不兼容、未验证候选不启动、握手用户停止、不可兼容回退、真实Runtime自动修复、已验证候选真实启动及身份历史保留。

完整回归还包含既有真实临时进程案例：准备前失败、激活后失败和运行后死亡的旧版恢复，以及工具派发停止矩阵。真实模型测试未显式开启时跳过；固定模型测试不能冒充真实LLM质量验证。前端检查为组件交互，不是浏览器视觉验收。

最终回归共574项：571项通过、3项真实模型验收跳过，失败与错误均为0；其中T12新增36项通过。前端9组组件检查通过。最终源码在验收期间保持稳定，正式实例身份、运行代次、进程和部署只读比较通过；证据见 `outputs/acceptance/development-t12.json`；前端检查见 `outputs/acceptance/thought-inspection-ui.json`。

## 能力边界

本项不证明健康的单一总分、主观体验、无边界自修复或任意自修改安全。当前自动修复仅恢复缺失目录和派生索引；身份、权威记忆、数据库、权限和未知副作用须明确调查，不自动重建或抹除。

候选验证是临时数据和子进程隔离，不是操作系统安全沙箱。源代码运行仍需信任；有限探针和声明的schema范围不等于全面兼容性证明。依赖安装、自动生产schema迁移、真实LLM补丁质量和长期故障恢复统计均未在本项冒称完成。

完成门控后下一项为T13“五项生命判据长期验收”；本轮不提前把有限工程测试视为长期生命验收。

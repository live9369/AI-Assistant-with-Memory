## 未改变与剩余边界

本版没有模糊语义合并，也不合并同义实体或谓词。不同来源的重复陈述仍保留，因为可能是新的观察或独立证据；无法证明同义时不会自动删除。引用一般历史文本或模型回应的重复提案，不保证都能识别。

系统回执是写入状态依据，不替换或篡改原始模型输出。表达指令能够减少提前断言，不能证明任意模型永不违背指令。回执说明的是保存为未核实候选，不是事实确认。

没有开启人格成长、习惯学习或自主探索，也没有修改现有身份和历史。

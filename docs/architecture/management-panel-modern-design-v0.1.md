# 管理面板现代化设计与检查 V0.1

日期：2026-11-14。用户确认：浅色现代工作台。

## 设计选择

采用白色内容区、浅灰画布和青绿色强调色。主要色值：画布 #f5f7f9、内容 #ffffff、正文 #1c3038、辅助文字 #526872、强调 #116b5c、边框 #dce4e8。中文使用 PingFang SC / Microsoft YaHei / 系统字体，不引入字体网络请求。采用 8px 间距节奏、分层标题、统一表单及状态标签。

UI UX Pro Max 推荐的玻璃拟态不适合本项目长文本和多维记录，未照搬；采用其可访问性、响应式和克制动效原则。结合 frontend-design 保留数字生命实例的清晰身份与青绿色视觉特征。按 web-design-guidelines 检查相关页面。

## 页面范围与修改

- 导航：日常、系统、账户与记忆三组；九个统一 SVG 图标。小屏使用展开菜单，不再横向挤压九个入口。保留账户权限决定入口可见性的原逻辑。
- 总览：统一指标、最近事件和模型接入区的间距与层级。
- 交流：统一气泡、正文、输入框和操作按钮。保留草稿与独立思考协议。
- 活动及审批、日志：统一筛选、表格、分页和空状态。表格在窄屏内部滚动，不挤压整页。
- 模型配置：统一控件与只读/禁用表现；明确字节检查上限与 token 窗口的区别。未更改配置值、后端含义或实际预算。
- 健康：正常、未知、过期仍区别展示，不以样式替代证据。
- 我的账户、账户管理、记忆域：表单分栏与移动端单栏；类型和记忆域中文显示；行内操作分组；账户类型选择器增加可访问名称；账户启停增加确认。
- 弹窗及思考详情：统一边框、标题、滚动与页脚；保留分类切换、消息列表、按需展开和原始排查入口。
- 全局：键盘焦点、数字等宽、减少动态效果、隐藏元素优先级；配置及聊天草稿未保存时提醒离页。
- 标签修正：账户页顶部标明账户，避免将登录状态误读为实例运行状态。

## 验证及范围

JavaScript 语法通过。现有聊天组件五项检查通过。Chrome 使用模拟数据渲染九个主页面，均成功；已逐页查看桌面截图，并查看 600px 窄屏账户布局。截图位于 outputs/panel-modern-review/。本次未调用真实模型、未提交正式账户修改、未调整自主思考频率或权限。主页面截图不等同于全部授权状态和后端操作的端到端验收；本轮未展开非必要功能测试。

# 记忆检查耗时修复

日期：2026-11-14。目标：修复正式链路记忆准备约两分钟的退步，不改变特征、权限或来源判定。

## 已定位

正式三轮准备阶段约 130—167 秒。只读抽样一条旧派生记忆，readers 被调用 4917 次，带 profiler 耗时 4.264 秒。现有代码仅缓存正常返回，拒绝分支不缓存；父来源权限交集已为空仍继续遍历。

## 最小修改

1. 在单次 readers 调用内缓存拒绝结果，交集为空立即返回。保留循环、深度上限、来源状态、版本及权限检查；不跨调用、事务或账户保存缓存。
2. 先完成不涉及授权的相关性评分并排序，再依序做当前版本、来源和权限检查，取满原 limit 后结束。排序公式及最终结果语义不变。索引模块有可用候选时仍使用；关闭时保留既有扫描回退，本轮不擅自启用其他学习功能。
3. 新增检索阶段耗时日志，记录候选数、实际检查数和耗时，不记录私有正文。

# 思考执行可观察性 V0.1

每条聊天消息和活动详情提供“查看思考执行”入口。列表按活动返回请求，详情按request ID读取不可变输入artifact、各attempt状态、各result及实际记录的用量。不重新调用模型、不修改实例、无迁移。认证、Host/Origin和no-store沿用管理接口。

完整指项目保存的完整请求/响应，除凭据脱敏外不截断列表、正文或深层对象。输入哈希与请求artifact完整性核对；缺失、已擦除或损坏返回明确不可用。不得用当前人格/配置冒充历史值。高维特征按输入字段逐项展示实际值、为空或未进入本次请求；传入不代表因果影响已经实证。

展示模型与固定配置版本、独立请求标识、发送/结束状态、公开输出、动作候选、有效/接受/过期状态，以及有证据的token和耗时。未持久化的原始供应商正文、CLI内部系统上下文和隐藏推理不冒称可还原。失败无结果时显示“未保存输出”，不虚构响应。

本轮只在新建隔离实例检验，含跨实例隔离、密钥脱敏、超过4000字正文、超过100项数组、历史快照不随当前特征变化、损坏/缺失数据和失败状态。当前运行器与实例不部署、不重启、不写入。CLI仍管理部署与唤醒。

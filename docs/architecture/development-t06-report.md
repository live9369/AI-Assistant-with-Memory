## 完成结果

已先保存详细设计，再将多特征评分、softmax 概率与真实采样接入 Engine 主流程。系统现在依据实际获选动作进入等待、询问或工具审批，原始模型行动建议和输出保留，不改写为系统选择。T06 标记 complete，T07 尚未开始。

特征快照保留五维人格、四维价值、认知接受状态统计、授权记忆召回覆盖、情境匹配习惯、触发者条件信任、T05 动机和新鲜负载等独立维度及来源。默认部分系数为零，不假装所有特征均已有科学映射。控制者配置系数、偏置及温度；模型不能自行修改策略。

候选最多三个：模型明确提出的一个行动，加 wait 和 ask。不编造工具参数；V2 内部探索显式保留专用流程，不应用普通行为概率。非法路径或超出活动工具策略的候选概率严格为零。获选工具仍需审批及执行时的权限检查。

## 数值隔离实验

在全新临时实例固定候选集与温度，用实际档案修订和 prepare 快照测量。本例只证明本策略按声明系数工作，不能推断真实人格因果效应。

| 参数情境 | 写文件分数 | 写文件选择概率 |
| --- | --- | --- |
| 初始工程参数 | 1.30 | 76.21% |
| 仅将尽责性由0调整至0.9 | 1.57 | 82.49% |
| 再将continuity价值权重调整为1 | 1.87 | 87.85% |

初始分布下 10000 次固定种子采样，写文件实际频率为 75.69%，理论值 76.21%；全候选最大绝对误差为 0.005158。这是采样器一致性实验，不是任务成功率或人格效度实验。没有调用真实模型或执行工具。数据见 `outputs/acceptance/t06-sensitivity.json`。

## 科学依据与明确边界

情境候选特征借鉴 [Li 等，2010 的 contextual bandit 原论文](https://arxiv.org/abs/1003.0146)；偏好到概率的 softmax 表示参考 [Sutton 与 Barto，2018，第 2.8 节](https://www.andrew.cmu.edu/course/10-703/textbook/BartoSutton.pdf)。本实现不等于论文中的 LinUCB，也没有实现奖励或系数在线学习。

概率属于本系统的行为选择策略，不等于成功概率、人的心理规律或主观体验证据。人格系数是工程先验；记忆直接数值信号目前限于授权召回覆盖，内容通过 LLM 影响候选；认知统计也不是真实无知概率。一般多方案规划、长期校准、人格成长与习惯形成仍属后续阶段。身份独特性不等于这些参数。

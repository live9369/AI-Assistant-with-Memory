## 实现与逐项验证

| 部分 | 当前实现与验证 |
| --- | --- |
| 来源链 | 关联活动、原请求、接受结果、实际选中决策、原人格档案、上下文和真实工具结果；来源拼接核对 |
| 意图与行为区分 | 待审批意图、未知工具效果、失败结果不作为成长来源；工具 receipt 擦除后来源失效 |
| 标注质量 | 控制者权限；有限数值；明确情境、可靠度及解释；幂等 key；更正追加并保留原记录 |
| 重复与独立性 | 至少 3 个训练活动、2 个情境；同活动多轮不能冒充不同活动，消费过的活动来源不能再用于同维更新 |
| 不确定性 | 保留样本数、情境数、加权离散程度、平均可靠度、来源与留出测量；不伪造心理置信区间 |
| 单轮稳定 | 一次思考、一次标注、仅提案或仅评估均不改长期人格 |
| 慢变限制 | 单次绝对步长≤.02，同维间隔≥24小时，最近30天累计绝对变化≤.05；反向回退也计入账本 |
| 质量拒绝 | 低可靠度、明显冲突、无剩余额度或无有效变化不生成可采用成长 |
| 留出评估 | 至少 2 个另外活动，包含训练未见情境；改善且逐条不回归才可采用；不调用模型或执行工具 |
| 采用前重查 | 基线 CAS、配置代次、训练和留出有效性、消费状态、时间与测量内容均重查；篡改或失效拒绝 |
| 版本与回退 | 追加人格版本和学习提交；未变维度保留原值与不确定性；补偿版本支持 reversal_of，不覆盖后来修订 |
| 更新效果 | 后续 prepare 使用新档案，受控对照中 T06 概率按新人格特征改变；以前输入不重建 |
| 持久化与观察 | 重开后身份、记忆数量、人格档案和成长记录保留，外键无错误；面板完整输入展示原档案及不确定性 |
| 兼容性 | 默认关闭不增加成长输入或机会；V2 专用探索不作为本模块全局人格来源；人工档案修订仍兼容 |

实现集中在 `digital_life/application/personality_growth.py`，接入 Engine、Personality、现有学习表、CLI 和 ThoughtInspection。无需 SQL 迁移。原有 Personality.replace 仍是控制者人工修订入口，不属于成长限速算法；T07 CLI 不提供大幅人工改写。

## 科学定位与边界

[Whole Trait Theory 原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4472377/)为区分短时状态、情境机制和长期倾向提供理论参考；[人格变化干预系统综述](https://pubmed.ncbi.nlm.nih.gov/28054797/)说明人格变化可以作为研究对象。两者都不直接证明本项目系数、时间阈值或控制者标注具有人格心理测量效度。

reliability 是声明的标注质量，不是模型置信概率；情境标签也是控制者给定；留出误差改善只证明对有限标签的拟合。没有自动从工具成功率推断人格，也没有无监督人格改写。长期科学效度与真实时间追踪待实证，身份独特性仍不等于五维参数。T08 将另处理情境习惯形成与消退。

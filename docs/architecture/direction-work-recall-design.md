# 同方向成果回取与思维收束

日期：2026-11-14。范围：修复自主探索历史承接，不扩展工具或训练系统。

## 成果回取

从该方向已接受的 thought_results 读取公开输出原文，引用原 request/result/artifact；与真实工具回执分开，明确其为模型产出，不能提升为外部事实。回取时重新检查该步使用的记忆来源、当时的来源保护引用和当前权限；失效则不展示正文。输入的来源保护列表参与现有发送前和接受前校验。

输入包含成果目录及有界正文，优先当前下一步明确请求的 work:请求ID、与下一步相关的旧成果、最近成果。正文不截半段冒充完整；超出本轮额度的成果明确标出。模型可在 next_attempts[0] 中指定 work:请求ID，让下一个独立调用回取已有成果，无需用户重新提供。单项成果超出额度则明确容量不足，不冒充不存在。保留原输入总容量与活动预算，不提高上限。

## 收束

方向建立时的题目和初始计划保持稳定。每轮先检查已经完成什么、当前目标还缺什么；已有材料足够则汇总结束，不能为了用完预算补题。历史原文被省略时优先回取，不把系统已有成果当成用户资料缺失。独立评测、跨案例推广等扩展问题不是自动追加的本轮完成条件；确实阻碍当前目标的问题才继续，外部资料或权限缺失才暂停。

不以固定轮数认定目标完成。沿用无进展暂停、来源校验及原权限。收束是任务范围与模型决策约束，不能承诺所有模型输出都会正确判断目标是否已完成。

## 针对性验收

覆盖旧成果跨多轮回取、完整原文与来源、明确指定旧成果、来源撤回及发送前校验；用原测试中暂停前的真实输入重放一次独立模型调用，核对能否汇总已有案例、避免再索要已经保存在系统里的正文。无需重新长时间测试。

## 实现边界

成果正文最多占本地输入容量的三分之一，且不超过32 KiB；目录最多展示24项。按显式 work:请求ID、与当前下一步的文本关联、时间顺序选择，所选正文不截断。未选中项、来源失效和容量问题明确标示；不是无限历史回放，也不是语义理解完整性的保证。既有输入总上限继续生效。

来源引用与成果定位分开：引用只选本轮有效来源ID；当前召回记忆和历史成果实际使用的来源均须保持可读。V5 的提供方输出 schema 将来源字段枚举为本轮允许值，接收端继续检查权限、来源和撤回状态。未知或失效引用会保存 continuous.rejected_output 诊断记录，拒绝结果不会进入正式成果或记忆。

TARGET每case在学习后有三道固定查询：同次观察使用、未参与更新的新问题、适用边界／未知检验。主改善终点TL13只取“新问题”正确使用分数；另两类分开报告。新问题必须可由合法已学内容支持，不能要求单次材料无依据地推出普遍规律。不可答题的正确答案是有理由的未知／冲突，不能因此排出主终点。RETENTION每case一道查询，学习前各组基础记忆一致，经验组追加隔离的相关／干扰更新以测保持；独立标签决定正确边界。

同一来源的变体、同义改写、三道查询及三次重复均属于同一case簇，不增加独立样本。正式来源簇不得跨DEV／TARGET／RETENTION；无法保证独立的合成模板家族另记录并按家族做敏感性分析，不能只随机换名字声称独立。若仍存在影响独立性的共享结构，正式结论保留受限，不靠800这个数字掩盖。

样本规划：配对case差值D在[-1,1]，TARGET假设SD=0.5、关注提升0.05，双侧95%区间对应z=1.96，目标80%功效z=0.842，近似n=((1.96+0.842)*0.5/0.05)^2≈786，取800。RETENTION假设SD=0.3、真实差0、非劣界-0.02，n≈1767，取2000。该近似不保证实际方差／非正态／相关结构下功效，也不声称对SD=1的最坏情形充分。三次重复可降低随机性但不当作样本量乘三。实际区间宽导致结论不确定时报告不确定；不自动加样至通过。后续扩样须新协议和独立正式材料。

各必需类别均超过Q10的20-case最低门槛；正式结论仍要满足独立性、盲评与证据条件。

- N无经验组：保存原观察审计，但后续普通经验查询不提供本次更新内容、工具正文、答案摘要或目标相关会话；基础文字／历史记忆与E相同。保持组同样基础能力，区别是E承受新增学习更新。此组不是关闭整个进程。
- O原材料诊断组：仅在明确原文查证用途呈现同一原观察及来源限制，不宣称接纳或冒充普通经验通道。仅DEV运行，用于定位缺口，不进入主效果差或证明绕过学习有效。

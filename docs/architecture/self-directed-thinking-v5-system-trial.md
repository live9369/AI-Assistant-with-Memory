# 自持思考 V5：真实系统验收

日期：2026-11-14。状态：限定场景核心链路通过，开放式自主探索仍待观察。

## 本轮修改

将“一个步骤完成”与“整个方向结束”分开。每步记录预期、实际观察、理解修订、剩余问题、后续尝试及方向状态；真实工具回执与模型自述分开保存。下一次独立调用可承接该方向最近四份实际回执。思考详情增加这些字段的人类可读展示。

本轮没有接入新的训练算法，也没有证明意识、主观体验或通用自主学习。现有权限、审批链和单项预算保持原样。

## 真实系统接入

使用原初00既有实例、原有任务队列、Codex 模型、审批与工具执行链。测试资料是明确标记的合成任务表和提醒规则，不代表真实承诺。正确答案只保存在评价文件中，未放入模型输入。自动审批仅限本次两份哈希未变的文件读取，不批准写入或发送提醒。

验收脚本为 scripts/run_continuous_system_trial.py；prepare 仅准备场景，watch 观察并处理限定审批，运行器仍按原 CLI 启动。watch 结束时关闭自主探索。身份、记忆及历史未清空，合成测试痕迹保留并标明用途。

## 发现并修复的阻塞点

第一次真实试验中，模型把“不能直接调用工具”理解成“不能提出读取行动”，选择等待，方向暂停。没有读取成功，也没有伪造观察；该次不算通过。

修正阶段说明：生成方向时仅等待；推进已选方向时，可以提出结构化行动候选，仍由系统审批、执行并回传。随后重新部署验证。

最终结果与评价文件一致。模型还修正了前一步将四个字段误记为五个字段的描述。D4 的缺失信息作为结论保留，没有为了继续而无限追问。全过程有三份方向推进记录、两份成功工具回执；另有一次生成方向调用，总计四次真实模型调用，无重试或调用错误。

四次模型调用耗时分别为 22.30、38.69、24.17、24.25 秒，合计 109.41 秒。方向三次推进从首个请求准备完成到最后结果返回约 6 分 32 秒，另含输入准备、排队与调度间隔，不能全部算作模型耗时。两次读取后的输入准备各约 104—105 秒，保留为后续性能问题，本轮未扩展优化。

自主探索已关闭；既有运行器、聊天和健康维护保留。相关九项核心用例通过，耗时约三秒；未运行无关全量测试。

## 记录与边界

可核对 outputs/inquiry-system-trial-2/ 下的 manifest.json、latest.json、result.json、final-output.json 和 timings.json。第一次失败记录在 outputs/inquiry-system-trial/，未删除。

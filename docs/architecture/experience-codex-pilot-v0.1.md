# 现有 Codex 的经验效果隔离先导 V0.1

后续已按用户要求独立验证记忆召回：两条文字记忆能够帮助模型；工具观察只记结果引用，正文没有被召回。见[记忆召回检查](memory-recall-probe-v0.1.md)。本页仍保留此前统计快照未改善的原结论，不把两条路径混为同一实验。

作者：Codex 主agent（/root），无委派。日期：2026-11-08。

## 任务与边界

用户授权用项目现有Codex做小规模真实模型对照，检查现有经验是否改善预测。正式实例 `work/primordial00` 继续锁定；不部署、不接入实际问题选择、不修改人格；旧运行和失败证据保留。

本轮不是正式G2，也不是基础模型权重训练。检查的是：同一模型收到当前认知经验快照以后，能否比没有这份快照时更准确。

## 在调用前固定的方案

机器清单 `manifest.json` 在真实调用前封存，协议 `EXPERIENCE-CODEX-PILOT-0.1`。使用 `config/local/codex.json` 的现有配置；每次请求使用新的Codex会话，工具禁用，候选行动不执行，不续接历史，不重试或切换模型。保存实际用量、会话ID、请求、最终模型输出、概率、原数据库事件和工件。

新隔离实例先通过既有脚本模型完成一次本地读取，产生真实本地工具回执和系统经验记录。这一步是构造经历，不是声称Codex自主发现了问题。然后调用真实Codex预测；经验条件直接使用 `Cognition.experience_snapshot`，不注入手写事实、分数或检查答案。

四道题，每题两次独立请求，共8次：

| 组别 | 内容 | 用途 |
| --- | --- | --- |
| target 两题 | 刚经历的库存读数是否大于9、是否等于8 | 检查经验有没有传递这次观察的信息 |
| retention 两题 | 7+5是否等于12、9是否为偶数 | 检查附加经验是否扰乱原有简单能力 |

每题的两个条件只有是否提供经验快照的语义差别，调用顺序逐题交替。两题target缺少读数时，统一要求表达[0.5,0.5]的不确定性，不能把缺信息算成假。

答案由controller依据隔离观察和确定算术生成，提前做带随机nonce的摘要承诺；所有预测保存后才提交答案揭示。不把答案或nonce送入模型。材料和答案由本agent设计并核对，没有独立盲评。target是同次观察的两个相关检查，不是两个独立经历，也不是新领域泛化样本。

事先登记的判定规则：报告逐题归一化Brier误差、target平均改善、retention最大退步及保留能力否决后的gain。只有得分变化不足以证明学习有效；本轮不做显著性或总体成功率推断。

## 预算兼容修改

历史真实Codex记录的单次输入已经超过1.1万token，旧测量器4096的预留上限无法完成真实对照。将测量器显式预留参数的上限扩展为32768，默认512不变；父活动预算预检、每次派发预留、超额／用量未知停止规则均保留。该调整不是提高正式实例的额度。

仅对新建隔离实例，在观察和真实调用前固定父活动预算300000 token、12次尝试。每次测量预留32768，最多8次真实调用；整组注册期限300秒，单次仍受现有配置120秒及剩余期限约束。Codex没有该接口的硬输出token限制，实际用量只能返回后核对，不能称为绝对费用上限。失败不自动重跑。

新增 `evaluation/experience_codex_pilot.py`、`scripts/run_experience_codex_pilot.py` 和运行器专项测试。测量服务只有上述参数范围变化，实际选择路径不变。结束时隔离实例也停止并重新加锁。

## 结果

真实运行：`experience-codex-pilot-20261108T133945Z-6df2a51e`，模型 `codex_cli:gpt-6.1-sol`。8/8次真实调用完成，8个不同会话，实际总用量95791 token；没有重试和模型切换。调用前经验快照只有一个unknown经历，sample_count=0、experience_estimate=0，没有观察读数。

| 指标 | 不带经验 | 带当前经验 |
| --- | --- | --- |
| 两题target平均Brier（越低越好） | 0.25 | 0.25 |
| 两题retention平均Brier | 0 | 0 |
| target改善值 | — | 0 |
| retention最大退步 | — | 0 |
| 最终gain | — | 0，measured_zero |

两题target两边都返回[0.5,0.5]，两题retention两边都答对。这是本次明确测得的零改善，不是缺少用量或缺少预测造成的unknown。Learning据报告评估，Cognition保存一份数值为0的影子经验版本；它不会被夸大成学习成功。

当前快照只给了经验统计及版本引用，没有给出原观察的具体内容；模型禁止调用工具，无法沿引用查到读数。结合请求内容与预测，本次没有看到经验带来帮助。不能由这4题、一次观察断言系统以后无法学习；本轮检查的是已有统计快照，不是完整经验内容更新机制或广泛泛化能力。

正式实例6个文件摘要前后相同，保持锁定。隔离实例结束后停止并重新加锁。实际选择路径未接入测量结果；原始工具回执仍能核对value=10，答案承诺与预测先后顺序可复核。真实模型只做概率预测，本地经历准备仍由脚本模型完成。

下一阶段需要让认知保存并按需提供有来源的具体经验内容，例如“观察到了什么、旧认识哪里需要修正、适用范围与不确定性”；学习负责提出这些更新，认知负责版本化接收。再用未参与更新的新问题和旧能力题做隔离对照，才能检查经验内容是否帮助后续判断。本轮没有越过这个边界修改实际选择或添加手写答案到经验快照。


验证完成：预算与经验归属专项76/76通过；运行器模拟专项3/3通过；完整回归466项中463通过、3项显式真实模型测试跳过，0失败。本次8个真实Codex调用是独立先导运行，未混入单元测试计数。冻结源码及117个原运行索引文件核对通过，标签晚于全部预测，两个条件除经验外的模型输入相同；既有5组封存旧证据及上轮测量汇总保持原样。

## 如何复核

阅读该run的 `manifest.json`、`result.json`、`aggregate.json`、`evidence/model-calls.json`、`evidence/experience-before.json` 及 `evidence/artifacts.json`。`source-snapshot` 是实际运行源码；`evidence-index.json` 是封存文件摘要，隔离实例运行数据库另作原始留存，不与冻结文件摘要混淆。查看报告及认知版本时不应解除正式实例锁。

复跑会消耗真实Codex额度，只对新隔离实例运行：

```sh
python3 scripts/run_experience_codex_pilot.py --config config/local/codex.json
```

材料、模型别名或源码改变后必须新建run。小规模先导不能替代正式G2、独立材料与评审，也不能用于开启实际选择。

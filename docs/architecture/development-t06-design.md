# T06 高维行为概率详细设计

版本 V0.1；概念基线／待实证；本项按有界工程验收，不部署当前实例。

## 要解决的问题

T05 解决先思考哪个目标；T06 解决同一目标的一次思考之后，实际选择什么行为。现有主流程虽然有 softmax 工具函数，却始终选择模型给出的首个行动，第二候选没有真实竞争。本项把多特征评分、概率和采样接进实际决策，而非只展示分数。

科学定位：情境化候选特征可用于决策，这是 contextual bandit 的一种建模思想；softmax 可把偏好转成归一化选择概率。本项借鉴这些表示方法，不实现 LinUCB，也不冒称已学到奖励函数或人格因果规律。人格—情境—行为的对应系数暂无本项目实证，必须显式标记工程先验。身份独特性来自身份、经历、关系与轨迹，不等于特征参数。

参考原始文献：[Li 等，2010](https://arxiv.org/abs/1003.0146)；[Sutton 与 Barto，2018，2.8 节](https://www.andrew.cmu.edu/course/10-703/textbook/BartoSutton.pdf)。

## 特征与来源

每次 prepare 冻结 behavior_policy 快照：配置事件代次、策略版本、特征值、缺失标记及引用。人格保留五维实际激活值；价值保留每维实际激活；记忆使用本次授权召回条数/8（上限 1）及来源引用，不假装语义相关概率；认知使用已有候选/接受状态的比例，未启用或没有记录时标缺失；习惯使用本次匹配建议及对应行动模板；关系只取触发者的、domain=behavior 且 dimension=reliability 的最新条件信任，有真实评估引用，没有则缺失，不跨域平均；情境使用是否聊天、是否目标多轮、是否内部探索；动机使用 T05 intensity（无则缺失）；负载从新鲜状态取 depth/(depth+10)，无则缺失。

候选特征再加入 proposed（LLM 本次提出的候选=1）、cost（读/写工具=1，wait/ask=0）、habit（匹配相同行动的最大强度）。不读取模型自报的分数，不让模型修改权重。缺失项数值置零仅用于中性计算，同时保留 missing=true，不把零当作实际测量。

## 候选范围与硬边界

V1 保持现有 V1/V3 输出协议：候选为模型明确给出的一个行动，加 wait 和 ask；同类 wait/ask 去重。不凭空编造文件路径、工具参数或用户任务。候选最多三个，本版不是通用多方案规划器。内部探索沿用既有 V2 专用核验，显式 bypass 并记录原因，避免改变独立验收的探索语义。

只允许已登记动作；路径需通过现有工作区路径检查，工具需在当前策略 tools 范围内；不符合时 eligible=false、概率=0、记明原因。wait/ask 始终保留至少一个合法退出选项。候选获选不授予 grant；工具随后照常申请审批、检查策略代次与作用域。T05 的健康与目标停止门控继续独立工作。

## 分数、概率和采样

对行动 a 使用 s(a)=bias(tool)+Σ w(tool,k)·x(k,a)。五维人格和价值等均保留独立维度，维度可增减；不是把整个人格压成一个总分。默认非零权重只对明确列出的项生效，其余为零并保留输入。默认 proposed 系数为 1.5、cost 为 -0.3、habit 为 1；读动作对 openness 为 .3、写动作对 conscientiousness 为 .3、ask 对 extraversion 为 .2；认知不确定性鼓励 ask，负载鼓励 wait。这些全是版本化工程假设，不是人的心理测量结论。

p(a)=exp((s(a)-max_eligible_score)/temperature)/Σ exp(...)；不合法候选严格为零；temperature 默认 .7，允许范围 [.05,5]；有限系数范围 [-20,20]，特征绝对值≤1。先做最大值平移，避免溢出。

生产采样使用 secrets 生成的 53 位均匀抽样点 u∈[0,1)，按稳定候选顺序作累计概率采样。记录 draw、全概率向量、选中索引以及配置和来源。抽样点记录到 decision_records.seed（0≤seed<2^53）；审计事件记录 draw 和全部贡献。重放使用同一抽样点；不得在重试时为已接受请求重复抽签。分布是系统的选择概率，不是行动成功率、心理真实性或意识证据。

## 接口与数据流

控制者在停止状态配置 behavior-policy enable/disable/status，enable 可指定权重 JSON 和温度；默认关闭。配置文件为 biases（tool→数值）和 weights（tool→特征名→数值），完整合并到版本化默认参数；只接受已登记特征及动作。LLM 无权配置。旧部署缺模块时 CLI 拒绝写入。

prepare→冻结特征与策略→独立模型调用→检查代次→核验输出→构造/过滤候选→评分、softmax、采样→写 decision_records/decision_candidates→记录 behavior_policy.selected→按照实际获选动作进入等待或审批，而非继续使用模型原动作。原始输出不改写；思考详情分别展示模型输出和系统实际选择。接收时再次核对配置；旧请求不得静默换策略。

存储使用已有决策表和不可变事件，不进行 SQL 迁移。决定和选择事件与接受结果在同一事务内写入；若事务失败不会留下半个决定；已有 accepted_result_id 返回幂等结果。关闭功能沿用原确定性策略，不改写旧数据。配置、概率依据和原始思考输入输出可从面板查看。

## 验收

数学：概率和为 1、非法候选为 0、极端合法分数有限、温度作用、采样重放；固定随机种子的 10000 次经验频率对理论值误差≤.02，仅验证采样器。

特征：人格、价值、认知、记忆、习惯、关系、动机和情境分别做控制变量干预，验证方向与配置一致，缺失不伪造。主流程：实际获选 ask/wait 与模型提出的工具不同，必须不产生工具意图；工具获选需审批且能完成 T02 核验；重试不重抽；配置变更拒绝旧请求；重开数据库可复原抽样与全概率；关闭功能兼容。完整回归与当前实例只读保护核对后，才标记 T06 完成。

真实模型生成质量、系数的长期学习、人格成长、习惯形成、长期公平性及生命五判据实证属于后续任务。本项证明工程路径和统计采样一致，不证明个性或真实世界行为效度。

## V1 默认非零系数补充与兼容细节

除通用 proposed=1.5、cost=-.3、habit=1 外：read_file 为 openness=.3、value.exploration=.4、memory.coverage=-.2；list_files 为 openness=.3、value.exploration=.4；write_note 为 conscientiousness=.3、value.continuity=.4、motivation.intensity=.3；ask 为 extraversion=.2、cognition.uncertainty=.8、relationship.reliability=.2、context.chat=.2；wait 为 state.load=.8、context.internal=.1。其余系数默认零，控制者可显式配置；零不表示特征没有生物学作用，只表示本项目没有为它设定额外工程假设。

候选工具范围读取 policy_epochs 引用的活动策略，不能误取用于记忆隐私的另一份 policy_versions。初始授权策略未列 tools 时，已登记工具只表示可提交审批，不是预授权；显式 tools 空列表表示工具候选全部屏蔽。路径检查包含符号链接，执行时仍重查。

新输入已收到的消息不会被假装成“此前记忆”；首次无历史召回时，memory.coverage=0 是有依据的空结果，missing=false。未测量的信任/动机等是 missing=true。习惯若是旧版非法行动模板，不作为候选或数值因子，记录其 ID。原始模型输出及解释保持完整，实际行动选择单独显示，不将系统采样说成模型自己作出的选择。

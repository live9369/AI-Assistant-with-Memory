# 从零理解有记忆的 AI 助手

中文教材修订版 V0.2（2026-11-16），项目名称为“有记忆的 AI 助手 / AI Assistant with Memory”。

32 章正文、12 个附录、188 项指标索引、6 个完全离线的教学实验。目标是让初学者理解并逐步参与本项目，不宣称一本书替代所有交叉学科的系统专业训练。

本版逐章补入问题背景、失败机制、解法与取舍，并补充算例、四个有报告出处的工程案例和量化方法。专业术语配日常解释；科学研究、教学模型与项目实现分别说明。

[本次逐章修订说明](REVISION-V0.2.md)列出每章新增的关键问题与核对范围。

## 阅读入口

- [完整 Markdown 正文](manuscript.md)
- [离线 HTML 阅读版](reading-edition.html)：浏览器打开，带章节导航，可搜索文字。
- 本次 V0.2 下载包包含 Markdown、离线 HTML 与六个教学实验。此前 V0.1 PDF 属于旧版，未同步更新，不作为本版阅读入口。

## 使用实验

从项目根目录执行 `python3 docs/book/labs/01_python_basics.py`，依次运行到 `06_minimal_assistant.py`。只用标准库与内存数据库，不调用模型、不启动正式实例。

## 构建阅读版

`python3 docs/book/build_book.py` 从正文生成 HTML，只使用标准库。该生成器支持本书实际使用的 Markdown 子集，不是通用 Markdown 引擎。

可选 PDF 构建需要 reportlab 与支持中文的 TrueType 字体：

```sh
python3 docs/book/build_pdf.py --font /path/to/ChineseFont.ttf --output outputs/book-release/ai-assistant-with-memory-book.pdf
```
